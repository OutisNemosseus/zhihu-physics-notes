LaTeX 推导（随输入参数实时更新）

1. 静态过驱动电压
\[ V_{OV,Q}=\sqrt{\frac{2I_Q}{K}} \]
2. 偏置晶体管尺寸参数
\[ K_3=K_4=\frac{2I_{Bias}}{V_{OV,Q}^2} \]
3. 等效跨导
\[ G_m=g_{m1}+g_{m2} =K\left(V_{OV1}+V_{OV2}\right) =2KV_{OV,Q} \]
4. 小信号增益
\[ A_v = \frac{G_mR_L}{1+G_mR_L} \]
5. 非零输出工作点
\[ I_L=\frac{v_O}{R_L} \] \[ I_{D1}-I_{D2} = \frac12K\left(V_{OV1}^2-V_{OV2}^2\right) \] \[ = \frac12K \left(V_{OV1}-V_{OV2}\right) \left(V_{OV1}+V_{OV2}\right) \]
6. 关键直觉
\[ V_{OV1}+V_{OV2}=2V_{OV,Q}=\text{constant} \] \[ \Longrightarrow \quad g_{m1}+g_{m2}=\text{constant} \] \[ \Longrightarrow \quad A_v\approx\text{constant} \]
适用前提：M₁、M₂ 匹配，K₁ = K₂，偏置网络维持 VOV1 + VOV2 近似恒定，且两只输出管都保持导通。
