Python Semantic Colors — Privacy Policy

Applies to version 0.2.0. Updated October 29, 2026.

Local code analysis

This extension reads the current Python buffer in the Ace editor on online-python.com. It sends this buffer only to a locally running, extension-packaged basedpyright Web Worker to provide semantic highlighting, type hover and diagnostics. Code and analysis results are held in memory. The extension does not save them to persistent storage.

Editor interaction data

The extension responds to changes in the active code buffer and processes the current mouse hover position to request and place type information. These interactions are used only for the editing features, remain in memory on the device, and are not retained as activity logs or transmitted to external servers.

No external transmission

The extension does not upload code or analysis results to the developer, an AI service, or any external analysis server. It has no telemetry, advertising, accounts, or analytics. It does not sell or share user data. Its analysis components, type stubs and scripts are included in the installation package.

Website access

The extension operates only on https://www.online-python.com/ and https://online-python.com/. It uses the page's existing editor to read the active buffer and show analysis results. It does not request access to browsing history, cookies, local files or other websites. Code is used solely to provide the stated editing assistance.

Website execution is separate

Using the site's Run or Share features is handled by online-python.com under that site's own policies. This extension neither performs nor prevents the website's own data transmission.

Controls and retention

Use Pause to stop the analysis workers and remove semantic highlights and diagnostics. Basic syntax colors remain. Closing the page or uninstalling the extension removes this extension's in-memory analysis state. To stop all extension styling, disable or remove it and refresh the page.

Limited use

The extension uses website content and editor interaction data solely to provide its stated Python editing features. Its use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. It does not use this information for advertising, unrelated profiling, creditworthiness or lending decisions.

Questions

Use the developer support contact shown on the Chrome Web Store listing. This is an independent extension and is not affiliated with online-python.com, Microsoft, or the basedpyright maintainers.
