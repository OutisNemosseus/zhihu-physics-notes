# Week 0 - Proof Of Lab Kit Ordering

[下载本页 Markdown](https://raw.githubusercontent.com/OutisNemosseus/zhihu-physics-notes/main/docs/engr202/week-0-lab-kit-ordering.md){ .md-button download }

## Canvas 原始要求

- **截止时间：** Sunday, 11:59 PM
- **分值：** 5 points
- **提交方式：** File Upload
- **要求：** “Please upload a PDF of lab kit order from Tekbots.”

## 你需要提交什么

提交一份 **Tekbots 实验套件订单的 PDF 证明**。最合适的材料是 Tekbots 的订单确认页、订单确认邮件或正式收据。

PDF 中应当能看见：

1. Tekbots 商家或订单页面名称；
2. 已购买的 ENGR 202 lab kit；
3. 订单日期；
4. 订单号或确认信息；
5. 能识别这是你的订单的信息。

如果订单确认材料包含完整付款卡号、家庭地址等不需要公开的信息，先遮住这些内容，但保留姓名、商品、日期和订单号。

## 制作 PDF

### 如果收到的是订单确认邮件

1. 打开 Tekbots 订单确认邮件。
2. 选择 **Print / 打印**。
3. 打印机选择 **Save as PDF** 或 **Microsoft Print to PDF**。
4. 文件命名为：

```text
Tong_Su_ENGR202_Lab_Kit_Order.pdf
```

5. 打开保存后的 PDF，确认商品名称、日期和订单状态清晰可见。

### 如果只有网页订单确认页

1. 打开订单详情页。
2. 按 `Ctrl+P`。
3. 选择 **Save as PDF**。
4. 保存后重新打开并检查内容。

### 如果只有截图

把截图插入 Word 或 Google Docs，再导出为一个 PDF。不要直接上传多个零散图片，因为 Canvas 的要求明确写的是 PDF。

## Canvas 提交流程

1. 打开 [Canvas assignment](https://canvas.oregonstate.edu/courses/2061800/assignments/10612673)。
2. 点击 **Start Assignment**。
3. 在 File Upload 区域选择准备好的 PDF。
4. 检查文件名和预览。
5. 点击提交。
6. 回到 assignment 页面，确认出现提交时间或 submitted 状态。

## 提交前检查

- 文件格式确实是 `.pdf`；
- 能看到 Tekbots、lab kit 名称、订单日期和确认信息；
- PDF 页面方向正确，文字没有被裁切；
- 敏感付款信息已经遮住；
- Canvas 页面显示提交成功。
