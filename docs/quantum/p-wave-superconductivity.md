# What Is \(p\)-Wave Superconductivity?

> **Original Chinese title:** 什么是 p 波超导？  
> **Original Chinese version:** [Zhihu](https://www.zhihu.com/question/310590612/answer/2068782907011888069)

The labels \(s\), \(p\), and \(d\) describe how a wavefunction transforms under spatial rotations.

For ordinary atomic orbitals, the wavefunction belongs to a representation of the rotation group. For superconductivity, the same idea is applied to the **Cooper-pair wavefunction**.

If the orbital part of the pair wavefunction is unchanged by a three-dimensional rotation, it is an \(s\)-wave state.

If it transforms like an ordinary three-component vector, it belongs to the \(l=1\) representation and is called \(p\)-wave.

For angular momentum \(l\), the familiar representation has dimension

\[
2l+1.
\]

Thus

\[
l=0 \Rightarrow 1 \text{ component } (s),
\]

\[
l=1 \Rightarrow 3 \text{ components } (p),
\]

\[
l=2 \Rightarrow 5 \text{ components } (d).
\]

From a representation-theory viewpoint, suppose a function is expanded in a vector space

\[
\operatorname{span}\{v_1,\dots,v_N\}.
\]

After the rotation group acts, the transformed function should remain inside that representation space.

If the space can be decomposed into smaller invariant subspaces, the representation is **reducible**. If it cannot, it is **irreducible**.

So the language of \(s\)-, \(p\)-, and \(d\)-wave pairing is fundamentally a statement about how the Cooper-pair order parameter transforms under rotations.
