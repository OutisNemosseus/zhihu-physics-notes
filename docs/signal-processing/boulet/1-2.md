# 1.2 — 用平移交换关系判断系统性质

## 题意（重述）

Boulet p.44–46：判断四个系统是否无记忆、时不变、线性、因果和 BIBO 稳定，并说明理由。

\[
\begin{aligned}
\text{(a)}\quad &y[n]=x[1-n],\\
\text{(b)}\quad &y(t)=\frac{x(t)}{1+x(t-1)},\\
\text{(c)}\quad &y(t)=tx(t),\\
\text{(d)}\quad &y[n]=\sum_{k=-\infty}^{0}x[n-k].
\end{aligned}
\]

## 先画两条计算路径

定义 \(\tau_bx(t)=x(t-b)\)，离散时间用整数 \(N\)。

\[
\begin{array}{ccc}
x & \xrightarrow{S} & Sx\\
{\scriptstyle\tau_b}\downarrow && \downarrow{\scriptstyle\tau_b}\\
\tau_bx & \xrightarrow{S} & S\tau_bx
\end{array}
\]

右下角沿上面路径算为 \(\tau_bSx\)。只比较 \(S\tau_bx\) 与 \(\tau_bSx\)，不要把输入平移和输出平移混成一次代入。时不变性不要求线性；(b) 就是例子。

## (a) 反射加平移

令 \(Rx[n]=x[-n]\)，则 \(S=\tau_1R\)。反射把延迟变成提前：

\[
R\tau_N=\tau_{-N}R.
\]

于是

\[
(S\tau_Nx)[n]=x[1-n-N],\qquad
(\tau_NSx)[n]=x[1-n+N].
\]

两条路径一般不同，故不是时不变。重排输入样本是线性操作；输出 \(y[0]=x[1]\) 依赖未来，所以有记忆且非因果。重排不改变最大幅度：

\[
\|Sx\|_\infty=\|x\|_\infty,
\]

所以 BIBO 稳定。

## (b) 固定延迟的非线性比值

\[
(S\tau_bx)(t)=\frac{x(t-b)}{1+x(t-b-1)}=(\tau_bSx)(t).
\]

因此时不变。使用 \(x(t-1)\) 所以有记忆；只依赖当前与过去，所以因果。对常数输入 \(x=1\)，\(Sx=1/2\) 而 \(S(2x)=2/3\ne2Sx\)，故非线性。

系统在分母为零的输入上没有定义。即使限制到分母处处非零的有界输入，它也不 BIBO 稳定。例如

\[
x(t)=-1+\frac1{2+|t|}
\]

有界且 \(1+x(t-1)=1/(2+|t-1|)>0\)，但

\[
y(t)=\left(-1+\frac1{2+|t|}\right)(2+|t-1|)
\]

的幅度随 \(|t|\) 增长。

## (c) 乘以时间变量

令 \(M_tx(t)=tx(t)\)，则

\[
M_t\tau_bx=t\,x(t-b),\qquad
\tau_bM_tx=(t-b)x(t-b),
\]

\[
(M_t\tau_b-\tau_bM_t)x=b\tau_bx.
\]

交换关系失败，所以不是时不变。它是线性、无记忆、因果的。输入 \(x=1\) 有界，输出 \(y=t\) 无界，所以不 BIBO 稳定。

## (d) 向未来累计

换求和变量 \(m=n-k\)：

\[
y[n]=\sum_{m=n}^{\infty}x[m].
\]

这是**从当前向未来求和**，不是向过去求和。因此有记忆、非因果。求和具有线性，且

\[
(S\tau_Nx)[n]=\sum_{k=-\infty}^0x[n-k-N]=(\tau_NSx)[n],
\]

所以时不变。其冲激响应为 \(h[n]=u[-n]\)，不绝对可和；恒定有界输入会使求和发散，所以不 BIBO 稳定。线性与时不变的等式是在求和存在的输入空间上理解的。

## 全部结论

| 子问 | 无记忆 | 时不变 | 线性 | 因果 | BIBO 稳定 |
| --- | --- | --- | --- | --- | --- |
| (a) | 否 | 否 | 是 | 否 | 是 |
| (b) | 否 | 是 | 否 | 是 | 否 |
| (c) | 是 | 否 | 是 | 是 | 否 |
| (d) | 否 | 是 | 是 | 否 | 否 |

## Osgood 对应观点

§8.6，尤其 pp.501–502：时不变性写成与平移交换；§8.8，pp.509–511：因果性比较相同过去的输入。节省的是代入与判断的组织工作；其余性质仍需各自证明。
