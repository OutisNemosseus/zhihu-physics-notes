# 1.10 — 把六个系统拆成基本算子

## 题意（重述）

Boulet p.50：判断下列系统的无记忆、时不变、线性、因果和 BIBO 稳定性。

\[
\begin{aligned}
\text{(a)}\quad &y(t)=Dx(t),\\
\text{(b)}\quad &y(t)=\frac{t}{1+x(t-1)},\\
\text{(c)}\quad &y(t)=2t\,x(2t),\\
\text{(d)}\quad &y[n]=\sum_{k=-\infty}^{n}x[k-n],\\
\text{(e)}\quad &y[n]=x[n]+nx[n+1],\\
\text{(f)}\quad &y[n]=x[n]+x[n-2].
\end{aligned}
\]

注意 (b) 的分子是 \(t\)，不是 [1.2(b)](1-2.md) 的 \(x(t)\)；(d) 的求和指标也与 1.2(d) 不同。

## 共用比较图

\[
\begin{array}{ccc}
x & \xrightarrow{S} & Sx\\
{\scriptstyle\tau_b}\downarrow && \downarrow{\scriptstyle\tau_b}\\
\tau_bx & \xrightarrow{S} & S\tau_bx
\end{array}
\]

比较右下角的 \(S\tau_bx\) 与 \(\tau_bSx\)。算子 \(D\)、固定平移可以交换；乘以时间变量和时间缩放通常不能与固定平移交换。

## (a) 微分器

链式法则给出

\[
D\tau_bx=x'(t-b)=\tau_bDx,
\]

故时不变；微分也是线性的。导数需要邻近输入，故有记忆。按题目采用的过去差分极限

\[
Dx(t)=\lim_{\epsilon\downarrow0}
\frac{x(t)-x(t-\epsilon)}{\epsilon},
\]

它只用当前与过去，因此在允许的可微输入上因果。BIBO 不稳定：\(x(t)=\sin(t^2)\) 有界，但 \(x'(t)=2t\cos(t^2)\) 无界。

## (b) 显含时间的比值

\[
(S\tau_bx)(t)=\frac{t}{1+x(t-b-1)},\qquad
(\tau_bSx)(t)=\frac{t-b}{1+x(t-b-1)}.
\]

所以不是时不变。有延迟，故有记忆；只依赖过去，故因果。零输入得到 \(S0=t\ne0\)，故非线性，而且零输入已经产生无界输出，所以不 BIBO 稳定。分母为零处不定义。

## (c) 时间缩放再乘以时间

定义 \(A_2x(t)=x(2t)\)，则 \(S=2M_tA_2\)，且

\[
A_2\tau_b=\tau_{b/2}A_2.
\]

缩放会改变延迟量。明确计算两条路径：

\[
(S\tau_bx)(t)=2t\,x(2t-b),\qquad
(\tau_bSx)(t)=2(t-b)x(2t-2b).
\]

二者一般不同，所以不是时不变。系统线性但有记忆；\(t>0\) 时访问 \(2t>t\) 的未来，因此非因果。\(x=1\) 给出 \(y=2t\)，故不稳定。

## (d) 固定过去区间的总和

令 \(m=k-n\)，则

\[
y[n]=\sum_{m=-\infty}^{0}x[m].
\]

**求和边界固定在输入时间 0；输出在所有 \(n\) 都是同一个数。** 系统在求和存在的输入上是线性的，但有记忆。

\[
(S\tau_Nx)[n]=\sum_{m=-\infty}^{-N}x[m],\qquad
(\tau_NSx)[n]=\sum_{m=-\infty}^{0}x[m].
\]

取 \(x=\delta\)、\(N=1\)，前者为 0，后者为 1，故不是时不变。\(n=-1\) 的输出使用 \(x[0]\)，所以非因果。恒定有界输入使求和发散，故不 BIBO 稳定。

## (e) 含提前项与变化增益

令 \((M_nx)[n]=nx[n]\)，则 \(S=I+M_n\tau_{-1}\)。

\[
(S\tau_Nx)[n]=x[n-N]+nx[n+1-N],
\]

\[
(\tau_NSx)[n]=x[n-N]+(n-N)x[n+1-N].
\]

差为 \(Nx[n+1-N]\)，所以不是时不变。系统线性、有记忆；例如 \(y[1]\) 使用 \(x[2]\)，所以非因果。输入 \(x[n]=1\) 得到 \(y[n]=1+n\)，所以不稳定。

## (f) 两个固定延迟的组合

\[
S=I+\tau_2.
\]

平移之间可交换，因此 \(S\tau_N=\tau_NS\)：时不变。系统线性、有记忆、因果，而且

\[
|y[n]|\le |x[n]|+|x[n-2]|\le2\|x\|_\infty,
\]

所以 BIBO 稳定。其冲激响应是 \(\delta[n]+\delta[n-2]\)。

## 全部结论

| 子问 | 无记忆 | 时不变 | 线性 | 因果 | BIBO 稳定 |
| --- | --- | --- | --- | --- | --- |
| (a) | 否 | 是 | 是 | 是 | 否 |
| (b) | 否 | 否 | 否 | 是 | 否 |
| (c) | 否 | 否 | 是 | 否 | 否 |
| (d) | 否 | 否 | 是 | 否 | 否 |
| (e) | 否 | 否 | 是 | 否 | 否 |
| (f) | 否 | 是 | 是 | 是 | 是 |
