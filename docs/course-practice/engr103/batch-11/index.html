Input/output · millilitres, litres and minutes · 01

A dispenser rate and a filling time

A dispenser delivers liquid at constant rate q in mL/s. Read q > 0 and target volume V > 0 in litres. Calculate the rate in L/min and the time needed to dispense V, both in seconds and minutes. Test q = 18 and V = 2.7. Print three decimals and correct units. Assume the container starts empty, with no losses.

Reference / 必要约定与公式\(q_{L/min}=60q/1000\), \(t_s=1000V/q\), \(t_{min}=t_s/60\).
中文提示（不含解答）

先把目标体积与每秒流量配成同一种体积单位；每分钟有 60 秒。

Similar triangles · height is not a volume fraction · 02

Liquid in the lower part of a cone

A conical container stands with its point downward. Its full internal height is H cm and top radius is R cm. Liquid fills it to vertical height h cm measured upward from the point. Read H,R,h with H,R > 0 and 0 < h ≤ H. Calculate the liquid-surface radius, liquid volume in cm³, and percentage of full capacity occupied. Test H = 24, R = 9, h = 8. Print three decimals. Ignore wall thickness.

Reference / 必要约定与公式\(r=Rh/H\), \(V=\pi r^2h/3\), \(V_{full}=\pi R^2H/3\), \(P=100V/V_{full}\).
中文提示（不含解答）

液面半径随高度同比例变化；容量还涉及半径平方，因此不能直接用 h/H 当作体积比例。

Composite volumes · a fully contained sphere · 03

Empty space around a ball in a cubic box

A spherical ball is centered inside a cubic box. The box has internal side length a cm and the ball has diameter d cm, with 0 < d < a. Read a,d and calculate the box volume, ball volume, empty space in cm³, and percentage of the box volume occupied by the ball. Test a = 12, d = 8. Print three decimals. The box walls and any supports are excluded.

Reference / 必要约定与公式\(V_b=a^3\), \(V_s=4\pi(d/2)^3/3\), \(V_{empty}=V_b-V_s\), \(P=100V_s/V_b\).
中文提示（不含解答）

先从直径得到半径；这里的空余空间是立方体内部体积减去球体体积。

Coordinates · slope, midpoint and distance · 04

Report the geometry of two surveyed points

Read two planar points (x1,y1) and (x2,y2), with coordinates in metres and x2 ≠ x1. Calculate the slope of the line, midpoint coordinates, and straight-line distance. Test (x1,y1) = (−2,5) and (x2,y2) = (7,−7). Print three decimals. State the units of each result and whether the line rises or falls as x increases.

Reference / 必要约定与公式\(m=(y_2-y_1)/(x_2-x_1)\), \(M=((x_1+x_2)/2,(y_1+y_2)/2)\), \(d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}\).
中文提示（不含解答）

斜率用两点的坐标差相除；距离需要先平方再相加，所以负的坐标差不会导致负距离。

Area · thickness and mass conversion · 05

Material in a trapezoidal metal panel

A flat trapezoidal panel has parallel sides a and b and perpendicular separation h, all in cm. Its uniform thickness t is in mm, and material density rho is in g/cm³. Read all five positive inputs and calculate face area in cm², material volume in cm³, and mass in grams. Test a = 18, b = 30, h = 16, t = 1.5, rho = 7.8. Print three decimals. Treat the panel as a solid prism with no cutouts.

Reference / 必要约定与公式\(A=(a+b)h/2\), \(V=A(t/10)\), \(m=\rho V\).
中文提示（不含解答）

梯形面积使用两条平行边的平均值乘高；厚度换成 cm 后再计算体积。

A supplied travel-time model · round trip · 06

Distance inferred from an underwater echo

A pulse travels straight from a sensor to a flat reflector and returns along the same path. Read round-trip time dt_ms > 0 in milliseconds and sound speed c > 0 in m/s. Under this supplied constant-speed model, calculate the one-way distance in metres and centimetres. Test dt_ms = 3.4 and c = 1480. Print three decimals. Explain why using c times the full measured time gives twice the requested distance.

Reference / 必要约定与公式\(d=c(\Delta t_{ms}/1000)/2\), \(d_{cm}=100d\).
中文提示（不含解答）

测到的是往返时间；先把 ms 换成 s，然后把总路程除以二。

math.log10 · compatible input units · 07

Evaluate a supplied logarithmic power ratio

A dimensionless power ratio is reported as level L = 10 log10(P/P0) in dB. Read P > 0 and reference power P0 > 0, both in mW. Calculate L to three decimals. Test P = 2.5 and P0 = 0.001. Use the inverse formula to reconstruct P from the unrounded L and print it to six decimals in mW. Also determine the change in L if P is multiplied by 10 with P0 fixed.

Reference / 必要约定与公式\(L=10\log_{10}(P/P_0)\), \(P=P_0\,10^{L/10}\). Use math.log10, not the natural logarithm.
中文提示（不含解答）

对数的输入是无单位比值；两个功率用同一种单位即可，反算时不要使用已格式化的 L。

A supplied exponential model · inverse calculation · 08

Time for a cold sample to warm toward a room

A warming model is T(t) = Ta + (T0 − Ta) exp(−kt), with time in minutes and k in min⁻¹. Read T0, Ta, target Tstar and k with Ta > Tstar > T0 and k > 0. Calculate the first time the target is reached, in minutes and seconds. Test T0 = −4 °C, Ta = 20 °C, Tstar = 12 °C, k = 0.12 min⁻¹. Print three decimals. Substitute your unrounded time into the original model as a check.

Reference / 必要约定与公式\(t=\ln[(T_a-T_0)/(T_a-T_*)]/k\), \(t_s=60t\). Use math.log and math.exp.
中文提示（不含解答）

两个温差都取环境温度减去样品温度，确保比值为正；使用自然对数。

Debugging · radius units and exponent operator · 09

Repair a spherical surface-area conversion

The program should read positive sphere diameter D in millimetres and report surface area in cm² to three decimals. Repair all errors and test D = 40. Explain the required Python operator for squaring.

import math
D = input("Diameter (mm): ")
r = D / 2
area = 4 * math.pi * r ^ 2
print(f"Surface area: {area:.3f} mm²")
Reference / 必要约定与公式\(r_{cm}=D_{mm}/20\), \(A=4\pi r_{cm}^2\).
中文提示（不含解答）

输入要变成数值，半径要换成 cm；Python 的平方运算用 **，不是 ^。

Supplied geometry formulas · square roots and powers · 10

Dimensions and mass of a regular tetrahedron

A regular tetrahedron is a solid with four congruent equilateral-triangular faces. Read edge length a > 0 in centimetres and uniform density rho > 0 in g/cm³. Use the supplied formulas to calculate total outside surface area in cm², volume in cm³, and mass in grams. Test a = 6 and rho = 1.2. Print three decimals. The solid has no hollow interior.

Reference / 必要约定与公式\(A=\sqrt3\,a^2\), \(V=a^3/(6\sqrt2)\), \(m=\rho V\).
中文提示（不含解答）

面积随边长平方变化，体积随边长立方变化；质量再由密度乘体积得到。
