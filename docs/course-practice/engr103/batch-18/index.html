ICA 3 · CSV columns, markers and a linear trend · 01

Read a two-column experiment and fit a line

Use the complete synthetic CSV below. Column 1 is elapsed time in seconds and column 2 is voltage in volts. Save it as sensor.csv, or read the same text from an in-memory buffer. The first row is a header.

time_s,voltage_V
0,0.8
1,1.6
2,2.7
3,3.5
4,4.6
5,5.3
  1. Write a Python program that reads the two numeric columns into one-dimensional arrays. Print the array lengths and the first and last data pairs. Use NumPy and Matplotlib, or equivalent tools; no particular CSV-loading API is required.
  2. Find the unweighted least-squares line V=mt+c. Print m,c to four decimals with their units and predict the fitted voltage at t=2.5 s. Plot the fitted line over 0≤t≤5 using at least 101 points.
  3. Show the data as circles with size 8, blue face, red edge of width 2, and no joining line. Use a teal dashed fit of width 2, a legend, blue grid, titled axes with units, and a bold blue title of size 20. Keep data and fit on the same axes.
Reference / 必要约定与公式Fit \(y=mx+c\). For equally weighted points, \(m=\sum(x_i-\bar x)(y_i-\bar y)/\sum(x_i-\bar x)^2\), \(c=\bar y-m\bar x\). NumPy polyfit(x,y,1) is one available method.
中文提示（不含解答）

先检查列的含义与数组长度；拟合线使用自己的密集横坐标，不要把拟合系数当成绘图数据。

ICA 3 · plotting and loading diagnosis · 03

Repair a CSV fit that mismatches columns and plotted points

The CSV contains displacement x in cm followed by force F in N. There is one header row.

x_cm,F_N
0,1
1,3
2,4
3,7

This proposed program contains loading/shape, labeling and plotting mistakes. Assume NumPy and Matplotlib are already installed.

import numpy as np
import matplotlib.pyplot as plt
x, F = np.loadtxt('spring.csv', delimiter=',')
a, b = np.polyfit(F, x, 1)
xfit = np.linspace(0, 3, 101)
Ffit = a*xfit + b
plt.plot(x, F, 'o', label='measurements')
plt.plot(x, Ffit, '--', label='fit')
plt.xlabel('Force (N)')
plt.ylabel('Displacement (cm)')
plt.legend()
plt.show()
  1. Explain and repair the CSV read, fit direction and mismatched x/y plot lengths. You may use unpack=True with skiprows=1, or another correct way to extract columns.
  2. Fit F=ax+b, print a,b and the prediction at x=1.5 cm, each to four decimals with units. State the required lengths of the experimental and fit arrays.
  3. Correct both axis labels, add a descriptive title and grid, and use red circular data points plus a blue dashed fit. The repaired program must run without shape or conversion errors.
Reference / 必要约定与公式For a linear fit, \(F_{fit}=a x_{fit}+b\). A two-column CSV may be read with delimiter comma and its header skipped.
中文提示（不含解答）

表头不是数字；拟合的是纵轴量关于横轴量的关系，两条曲线可以有不同采样数，但每条曲线自己的 x 与 y 长度必须相同。

ICA 3 · vectorized arrays and equation annotation · 04

Plot three prescribed decaying cosine curves

Use the prescribed signals \(x_b(t)=A_0e^{-\alpha_b t}\cos(\omega_0t)\), with A0=1.5 m, m=8 kg, k=32 N/m, \(\omega_0=\sqrt{k/m}\), and \(\alpha_b=b/(2m)\). Use b=4,8,16 kg/s. These are supplied plotting formulas; do not identify them as the exact general critically/overdamped spring solution. Use 0≤t≤4 s with step 0.01 s, including both endpoints.

  1. Construct one shared one-dimensional time array and three signal arrays using elementwise NumPy calculations. Print their lengths, omega0, and the three alpha values with units.
  2. Print every signal at t=0 and t=1 s to six decimals. Explain why all start at the same displacement despite different decay factors.
  3. Plot all three on one axes with distinct colors and solid/dashed/dotted styles, a legend naming b and its units, time/displacement labels, green grid, and an annotation of the general supplied equation. Use a clear title.
Reference / 必要约定与公式\(\omega_0=\sqrt{k/m}\), \(\alpha_b=b/(2m)\), \(x_b=A_0e^{-\alpha_b t}\cos(\omega_0t)\). Both endpoints give \(N=(4-0)/0.01+1\) samples.
中文提示（不含解答）

ICA 3 · two array signals with different phases · 05

Separate phase changes from the shared decay envelope

Use \(u(t)=2e^{-0.3t}\cos(3t)\) V and \(w(t)=2e^{-0.3t}\cos(3t+\pi/3)\) V, for 0≤t≤6 s at step 0.02 s including both endpoints. The displayed expressions are the complete models.

  1. Build the time array and both signal arrays without a Python loop over samples. Print the sample count and both values at t=0 and t=π/6 s, evaluating that latter time directly rather than using the nearest grid point.
  2. On one axes plot u as solid blue and w as dashed orange. Add the two shared envelope curves ±2exp(−0.3t) as thin dotted gray lines, with only one envelope legend entry.
  3. Use voltage/time units, a title, grid and legend. Annotate both signal equations. Explain which shared factor controls the envelope and which difference shifts the oscillation; do not describe the two decaying signals as exactly periodic.
Reference / 必要约定与公式NumPy exponential and cosine functions act elementwise. \(|\cos\theta|\le1\), so both signals remain inside the supplied positive/negative envelopes.
中文提示（不含解答）

ICA 3 · sampling counts and axis limits · 06

Choose array endpoints before drawing a short transient

Plot the supplied curve \(z(t)=0.6e^{-0.4t}\cos(2\pi t)\) cm from t=0 through t=2 s, with step 0.025 s and both endpoints included. Compare the two candidate time arrays below.

a = np.arange(0, 2, 0.025)
b = np.linspace(0, 2, 81)
  1. Determine the number of entries and final entry in each candidate. Select the one that meets the stated endpoints and step, and explain the excluded upper endpoint of arange here.

  3. Plot one purple line, mark these three checkpoint values with black circles, and annotate the supplied equation. Set x limits0 to 2 and ticks every0.25 s; include a title, legend, grid and units. Use unrounded data for plotting.

import numpy as np
import matplotlib.pyplot as plt
alpha = np.arange(0, 360, np.pi/16)
fig, ax = plt.subplots(2, 1)
ax[0].plot(alpha, np.sin(alpha), label='sine')
ax[0].plot(alpha, np.cos(alpha), label='cosine')
ax[1].set_xlabel('Time (s)')
plt.legend()
plt.show()
  1. Correct the angle array so it has the required count, step and endpoints. Explain the radians/degrees error in the original range and print the corrected count and last angle.
  2. Route each curve to its own axes and make both legends display the intended curve labels. Add separate titles, blue grids, Voltage(V) vertical labels and Angle(rad) horizontal labels, using different line colors and styles.
  3. Use ticks0,π/2,π,3π/2,2π with fractional-π labels on both axes. Verify each axes contains exactly one signal curve and report the two signal values at the first and last samples. Show the complete repaired program.
