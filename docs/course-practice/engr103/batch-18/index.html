ICA 3 · CSV columns, markers and a linear trend · 01

Read a two-column experiment and fit a line

Supplied input file: Download q01_sensor.csv. Save it beside your Python program and read this file; do not invent, manually type, or paste the observations. UTF-8 text, comma delimiter, one header row, 41 numeric data rows. Column order: time_s,voltage_V. Time is in seconds and voltage is in volts. These are original synthetic practice data, not the instructor’s private file.

  1. Read the first numeric column into x and the second into y, both one-dimensional arrays. Print the number of samples and the first and last data pairs. Any correct CSV-loading library is allowed.
  2. Find the unweighted least-squares line V=mt+c. Print m and c to four decimals with units, and predict the fitted voltage at t=2.5 s. Plot the fitted line over 0≤t≤10 using at least 101 evenly spaced points.
  3. Plot observations as circles of size 8, blue faces, red edges of width 2, and no joining line. Use a teal dashed fit of width 2, a legend and blue grid. Give the plot a bold blue title of size 20 with pad 10. Label Time (s) and Voltage (V) in blue, size 15, semibold, pad 4, centered. Keep data and fit on the same axes.
Reference / 必要约定与公式Fit \(y=mx+c\). For equally weighted points, \(m=\sum(x_i-\bar x)(y_i-\bar y)/\sum(x_i-\bar x)^2\), \(c=\bar y-m\bar x\). NumPy polyfit(x,y,1) is one available method.
中文提示（不含解答）

先检查列的含义与数组长度；拟合线使用自己的密集横坐标，不要把拟合系数当成绘图数据。

ICA 3 · plotting and loading diagnosis · 03

Repair a CSV fit that mismatches columns and plotted points

Supplied input file: Download q03_spring.csv. Save it beside your Python program and read this file; do not invent, manually type, or paste the observations. UTF-8 text, comma delimiter, one header row, 13 numeric data rows. Column order: x_cm,F_N. Displacement x is in cm and force F in N. These are original synthetic practice data, not the instructor’s private file.

The proposed program below contains loading, fit-direction, array-shape and labeling mistakes.

import numpy as np
import matplotlib.pyplot as plt
x, F = np.loadtxt('q03_spring.csv', delimiter=',')
a, b = np.polyfit(F, x, 1)
xfit = np.linspace(0, 6, 101)
Ffit = a*xfit + b
plt.plot(x, F, 'o', label='observations')
plt.plot(x, Ffit, '--', label='fit')
plt.xlabel('Force (N)')
plt.ylabel('Displacement (cm)')
plt.legend()
plt.show()
  1. Explain and repair the CSV read, fit direction and mismatched x/y plot lengths. You may use skiprows=1 and unpack=True, or another correct way to extract the supplied columns.
  2. Fit F=ax+b and print a, b and the predicted force at x=1.5 cm, to four decimals with units. State the lengths of the experimental arrays and of the smooth-fit arrays.
  3. Correct the axis labels, add a descriptive title and grid, and use red circular observations plus a blue dashed fit. Show the complete repaired program, which reads the downloaded file and runs without conversion or shape errors.
Reference / 必要约定与公式For a linear fit, \(F_{fit}=a x_{fit}+b\). A two-column CSV may be read with delimiter comma and its header skipped.
中文提示（不含解答）

表头不是数字；拟合的是纵轴量关于横轴量的关系，两条曲线可以有不同采样数，但每条曲线自己的 x 与 y 长度必须相同。

Separate phase changes from the shared decay envelope

  1. Build the time array and both signal arrays without a Python loop over samples. Print the sample count and both values at t=0 and t=π/6 s, evaluating that latter time directly rather than using the nearest grid point.
  2. On one axes plot u as solid blue and w as dashed orange. Add the two shared envelope curves ±2exp(−0.3t) as thin dotted gray lines, with only one envelope legend entry.
  3. Use voltage/time units, a title, grid and legend. Annotate both signal equations. Explain which shared factor controls the envelope and which difference shifts the oscillation; do not describe the two decaying signals as exactly periodic.

ICA 3 · positive counts and logarithmic y-axis · 07

Load count-first, year-second data before an exponential fit

Supplied input file: Download q07_chip_counts.csv. Save it beside your Python program and read this file; do not invent, manually type, or paste the observations. UTF-8 text, comma delimiter, one header row, 13 numeric data rows. Column order: count,year. All counts are positive. The observations are fictional examples, not historical transistor-count claims. These are original synthetic practice data, not the instructor’s private file.

  1. Extract year as x and count as y, despite their reversed order in the file. Set \(t=\mathrm{year}-1990\), measured in years. Fit \(\ln y=a+bt\) with equal weights in log space and recover \(y=Ae^{bt}\). Print A, b and the fitted count for calendar year 2005.
  2. Plot the original counts against calendar year as light-blue circles of size 8 with black edges. Add a smooth exponential trendline using at least 161 points across the supplied year range. Set the y-axis to a logarithmic scale, but pass original counts rather than ln(count) into the plotting function.
  3. Use a descriptive title, year/count axis labels, legend and black grid. From the fitted b calculate the predicted count ratio over two years and the doubling time in years. Explain why a trend inferred from these synthetic inputs is not evidence of an actual historical law.

Make the three-panel layout shown in the original layout guide: f alone in the upper-left panel, g alone in the lower-left panel, and both curves together in one large right panel spanning the full height. Use red solid f and navy dashed g consistently. The two left panels are the same size; the right panel spans their two rows. GridSpec, subplot2grid or equivalent layout tools are allowed.

Repair data routing in a three-panel trigonometric figure

The intended figure follows the same three-panel arrangement: sin(α) alone at upper left, cos(α) alone at lower left, and both together in the full-height right panel. Generate α from 0 through 2π radians with step π/16 including both endpoints; this is a formula-generated task and requires no CSV file. The following code is wrong.

import numpy as np
import matplotlib.pyplot as plt
alpha = np.arange(0, 360, np.pi/16)
fig = plt.figure()
grid = fig.add_gridspec(2, 2)
upper = fig.add_subplot(grid[0, 0])
lower = fig.add_subplot(grid[1, 0])
combined = fig.add_subplot(grid[0, 1])
upper.plot(alpha, np.sin(alpha), label='sine')
upper.plot(alpha, np.cos(alpha), label='cosine')
combined.plot(alpha, np.sin(alpha), label='sine')
lower.set_xlabel('Time (s)')
plt.legend()
plt.show()
  1. Correct the angle array’s units, sample count, step and endpoints. Explain the radians/degrees mistake and print the corrected count and final angle.
  2. Fix the right panel so it spans both rows, route the sine and cosine to the proper separate left panels, and draw both in the right panel. Use blue solid sine and red dashed cosine consistently. Add all three titles and legends, blue grids, Voltage (V) and Angle (rad) labels.
  3. Use fractional-π tick labels at 0,π/2,π,3π/2,2π on all three axes. Verify the panel line counts are one, one and two, and report the first and last values of both generated signals. Show the complete repaired program.
