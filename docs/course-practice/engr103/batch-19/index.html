ICA 3_1 · repeated CSV and linear-fit practice · 01

Plot threshold-voltage data set A

Write a Python program to create a threshold-voltage graph from synthetic practice data set A. This repeats the ICA 3_1 homework pattern with a new input file.

Input: Download batch19-engr103-q01-threshold.csv. Save the CSV beside your program and load it. The file is UTF-8, comma-separated, with one header row and 15 numeric data rows. Column 1 is time_s (seconds); column 2 is threshold_voltage_V (volts). The values are original synthetic observations, not the instructor's data.

  • Extract the first numeric column into a one-dimensional array x and the second into a one-dimensional array y. Plot threshold voltage against time.
  • Show the observations as circles with marker size 8, blue faces, red edges, and marker-edge width 2. Do not join the observation markers.
  • Add a linear line of best fit on the same axes. Use a teal dashed line of width 2, drawn across the time range in the file.
  • Use the title "Threshold voltage (VT) Testing" with font size 20, bold weight, padding 10, and blue color.
  • Use the x-axis label "Time (t) [sec]" and y-axis label "Threshold voltage (VT) [Volts]". For both labels use padding 4, centered placement, font size 15, semibold weight, and blue color.
  • Include a legend identifying the observations and fitted line. Make the grid blue.
Reference / 必要约定与公式Fit \(y=mx+c\) by ordinary least squares, allowing an intercept. NumPy polyfit(x, y, 1) is one available method. Use the resulting line only over the supplied time range.

先下载本题 CSV 并跳过表头；第一列作横坐标，第二列作纵坐标。实验点和拟合直线画在同一坐标轴上。

ICA 3_2 · repeated formula-generated plotting practice · 04

Plot three damped curves with A0 = 1.2 m

Write a Python program to graph three prescribed damped-motion curves on one axes. This repeats the ICA 3_2 homework pattern with A0 = 1.2 m, m = 10 kg, and k = 2.5 N/m. Generate the arrays directly from the formulas; no CSV file is needed.

Use \(b_1=\sqrt{4mk}/2\), \(b_2=\sqrt{4mk}\), \(b_3=\sqrt{4mk}/0.5\), \(\omega_0=\sqrt{k/m}\), and \(\alpha_j=b_j/(2m)\). For each \(j=1,2,3\), use the prescribed plotting expression \(y_j(t)=A_0e^{-\alpha_j t}\cos(\omega_0t)\).

  • Create a one-dimensional time array from 0 through 20 seconds in increments of 0.01 second, including both endpoints, and calculate all three displacement arrays.
  • Plot all three curves on the same axes using a different line type and color for each curve.
  • Use the title "Damped Harmonic Motion of Springs", x-axis label "Time (t) [sec]", and y-axis label "Displacement (y) [m]".
  • Include a legend with the worksheet-style labels "Underdamped \(b=\sqrt{4mk}/2\)", "Critically Damped \(b=\sqrt{4mk}\)", and "Overdamped \(b=\sqrt{4mk}/0.5\)".
  • Make the grid green. Add a text annotation showing \(y(t)=A_0e^{-\alpha t}\cos(\omega_0t)\), \(\alpha=b/(2m)\).

The regime names follow the worksheet labels; use the supplied expressions as plotting rules for this exercise.

Reference / 必要约定与公式For the inclusive time grid, \(N=1+(20-0)/0.01\). The divisions by 2 and 0.5 occur outside the square root in the definitions of \(b_1\) and \(b_3\). Use NumPy exponential and cosine functions elementwise.
中文提示（不含解答）

先按给定参数计算三个 b 和对应的 α，再让三个公式共用同一个时间数组。图例、绿色网格和公式文字都要保留。

ICA 3_3 · repeated CSV and exponential-fit practice · 07

Plot transistor-count data set D

Write a Python program to graph synthetic transistor-count data set D. This repeats the ICA 3_3 homework pattern with a new input file.

Input: Download batch19-engr103-q07-transistors.csv. Save the CSV beside your program and load it. The file is UTF-8, comma-separated, with one header row and 13 numeric data rows. Column 1 is transistor_count (number of transistors); column 2 is year (calendar year, 1983 through 2019). Every count is positive. These are original fictional practice observations, not historical records or the instructor's data.

  • Extract the two columns and plot year on the x-axis and the original transistor count on the y-axis.
  • Use light-blue circular observation markers of size 8 with black edges, without a line joining the observations.
  • Add one smooth exponential trendline across the supplied year range. For this practice use a straight-line least-squares fit of ln(count) against t = year − 1983, then exponentiate to obtain the trendline.
  • Set the y-axis to a logarithmic scale. Plot the original counts and exponential fitted counts, rather than plotting their logarithms.
  • Use the graph title "Moore's Law: The number of transistors on a microchip doubles every two years (synthetic practice data)". Line breaks in this long title are allowed.
  • Label the x-axis "Year the Microchip was Introduced (x) [Years]" and the y-axis "Transistor Count (y) [Transistors]". Include a legend for the observations and trendline, and make the grid black.
Reference / 必要约定与公式Let \(t=\mathrm{year}-1983\). Fit \(\ln N=a+bt\), then \(\widehat N=e^a e^{bt}\). All logarithms here are natural. This specifies one fitting method for the homework-style exponential trendline; no extra fit statistics are required.
中文提示（不含解答）

文件第一列是计数，第二列才是年份。用对数数据求指数拟合后，画图时仍传入原始计数，并把纵轴设置成对数刻度。

ICA 3_4 · repeated three-panel plotting practice · 09

Arrange sine and cosine panels with amplitudes 1.25 and 0.8

Write a Python program to make the three-panel trigonometric figure described below. This repeats the ICA 3_4 homework pattern with new amplitudes. Generate the angle and signal arrays in Python; no CSV file is needed.

Create a one-dimensional angle array \(\alpha\) from 0 through \(2\pi\) radians in increments of \(\pi/16\), including both endpoints. Define \(y_1=1.25\sin(\alpha)\) V and \(y_2=0.8\cos(\alpha)\) V.

  • Use exactly three panels: the sine curve alone in the upper-left panel, the cosine curve alone in the lower-left panel, and both curves together in one larger right panel spanning both rows. The two left panels have equal size.
  • Use a blue solid line for the sine curve and a red dashed line for the cosine curve, consistently in the individual and combined panels.
  • Title the upper-left panel "\(y_1=1.25\sin(\alpha)\)", the lower-left panel "\(y_2=0.8\cos(\alpha)\)", and the right panel "\(y_1=1.25\sin(\alpha)\) and \(y_2=0.8\cos(\alpha)\)".
  • Label every x-axis "Angle (alpha) [Rad]" and every y-axis "Amplitude (v) [Volts]". Include a legend on each panel using its trigonometric function or functions as the names.
  • Make every grid blue. Set x-axis ticks at \(0,\pi/2,\pi,3\pi/2,2\pi\) on all three panels and show these ticks with fractional-π labels.
Reference / 必要约定与公式Use radians in NumPy sine and cosine. For the inclusive angle grid, \(N=1+(2\pi)/(\pi/16)\). GridSpec, subplot2grid, or another equivalent three-axes layout may be used.
中文提示（不含解答）

先生成弧度数组，再计算正弦与余弦。左上只放正弦、左下只放余弦，右侧同一个大面板跨两行并同时显示两条曲线。
