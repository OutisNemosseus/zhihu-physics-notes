复合梯形法估算电荷

5 道原创同型练习。用 NumPy 生成等距节点，估算电流曲线下的面积，再用 2×2 子图对照四种细分。

结构依据：已核对 ENGR 103 HW9 的复合梯形法小题。参数是新编的；不需要 CSV。

1. 低频测试脉冲

i(t) = 3π cos(2πt) A

积分区间：[-1/8, 1/6] s

电荷 Q（C）等于 i(t) 在给定时间区间内的积分。用 NumPy 和 Matplotlib 完成：

  1. 先对 i(t) 解析积分，求 Q 的精确值。
  2. 分别取 N = 4、8、16、32 个等宽小区间。每次用 np.linspace 生成含两个端点的 N+1 个时间，求复合梯形近似 QN 和带符号的百分误差 100 × (QN − Q) / Q。
  3. 画一张 2×2 图：左上 N=4，右上 N=8，左下 N=16，右下 N=32。每格用蓝色实线画平滑的 i(t)，用红色虚线连起梯形上边，标出各节点至横轴的竖线，并给梯形面积填色。标注 N、精确值、近似值、带符号误差，加时间（s）和电流（A）轴标签、网格及图例。
展开答案与参考代码

原函数：(3/2) sin(2πt)。在两个端点相减得到 2.359698 C。将相邻样点的平均电流乘以步长，再累加各段面积。

  • N = 4：2.318278 C；误差 -1.7553%
  • N = 8：2.349370 C；误差 -0.4377%
  • N = 16：2.357118 C；误差 -0.1093%
  • N = 32：2.359053 C；误差 -0.0273%
import numpy as np
import matplotlib.pyplot as plt

A, k = 3, 2
a, b = -1/8, 1/6
def current(t):
    return A * np.pi * np.cos(k * np.pi * t)

exact = (A / k) * (np.sin(k * np.pi * b) - np.sin(k * np.pi * a))
fine = np.linspace(a, b, 401)
fig, axes = plt.subplots(2, 2)
fig.set_size_inches(11, 7)
fig.subplots_adjust(wspace=.28, hspace=.45)
for ax, n in zip(axes.flat, (4, 8, 16, 32)):
    t = np.linspace(a, b, n + 1)
    y = current(t)
    dx = (b - a) / n
    q = dx * (0.5*y[0] + np.sum(y[1:-1]) + 0.5*y[-1])
    error = 100 * (q - exact) / exact
    ax.plot(fine, current(fine), "b-", label="Current")
    ax.fill_between(t, 0, y, color="salmon", alpha=0.25)
    ax.vlines(t, 0, y, color="gray", linewidth=0.6)
    ax.plot(t, y, "r--", label="Trapezoids")
    ax.set_title(f"N={n} | error {error:+.4f}%")
    ax.text(0.03, 0.04, f"Exact {exact:.6f} C; approx {q:.6f} C",
            transform=ax.transAxes)
    ax.set_xlabel("Time (s)")
    ax.set_ylabel("Current (A)")
    ax.grid(True, alpha=0.25)
    ax.legend()
print(f"Exact: {exact:.8f} C")
plt.show()
