Calculate projectile arrays at 215 m/s

  • Create the angle array in NumPy and convert the angles to radians before evaluating the trigonometric functions.
  • Evaluate the two supplied formulas elementwise for every angle.
  • Display two labeled, seven-element arrays: range s in meters and maximum height h in meters. Keep the same angle order as the input array.

Program file: LastName_FirstName_Practice20_Q01.py. Enter the given constants and arrays in your program. Include comments for an author-name placeholder, date, a short program description, and calculation units. Label every requested output and include units where applicable.

Reference / 必要约定与公式\(s(\theta)=\frac{v_0^2}{g}\sin(2\theta)\); \(h(\theta)=\frac{v_0^2}{2g}\sin^2(\theta)\). In both formulas, \(\theta\) is in radians.

  • Display a labeled pressure table with exactly 6 rows and 3 columns, in Pa. Row 1 corresponds to the first listed height, row 2 to the second, and so on. Columns 1, 2, and 3 correspond to fluids A, B, and C. State this row and column order with your output.

HW2 2_3 · original-data variant · indexing, slicing, and stacking · 07

Construct arrays D through H, set A

Write a Python program using the following original practice arrays. Create A with shape (3, 3), B with shape (3, 1), and C with shape (1, 4). Entries are dimensionless.

A = [[21, 7, 34],
     [9, 16, 11],
     [28, 5, 63]]

B = [[4],
     [12],
     [19]]

C = [[17, 26, 8, 13]]

Use array indexing, slicing, and array-combination functions to create the following arrays from A, B, and C; do not manually re-enter the result entries.

  1. Create D from the third column of A, keeping it as a column array with shape (3, 1).
  2. Create E with shape (3, 2) by placing B as the first column and D as the second. Label and display E.
  3. Create F with shape (6, 1) by stacking B above D. Label and display F. This exercise explicitly requires a two-dimensional column array, not shape (6,).
  4. Create G with shape (4, 3) by keeping all rows of A first and appending the first three entries of C as the fourth row. Label and display G.
  5. Create a three-element array H, either a one-dimensional array with shape (3,) or a one-row array with shape (1, 3). Its entries, in order, are row 1/column 3 of A, row 1/column 2 of C, and row 2/column 1 of B. Label and display H.

Row and column numbers in the instructions start at 1; NumPy indices start at 0. The teacher handout describes F as one-dimensional while also specifying six rows and one column; the shape (6, 1) stated here resolves that wording conflict for this practice.

Program file: LastName_FirstName_Practice20_Q07.py. Enter the given constants and arrays in your program. Include comments for an author-name placeholder, date, a short program description, and calculation units. Label every requested output and include units where applicable.

Reference / 必要约定与公式Required shapes: D (3, 1), E (3, 2), F (6, 1), G (4, 3). H may have shape (3,) or (1, 3), retaining the stated three-entry order. Array entries are dimensionless.
中文提示（不含解答）
