Composite area · unit conversion · 01

A stadium-shaped garden

A garden has a rectangular central region of length L and width 2r, plus one semicircle of radius r on each short end. Read L and r in metres, with both positive. Print outer perimeter in metres and kilometres and total area in m² and hectares. Test L = 48 and r = 12. Count only the outside boundary.

Reference / 必要约定与公式\(P=2L+2\pi r\), \(A=2rL+\pi r^2\); 1 km = 1000 m; 1 hectare = 10000 m².
中文提示（不含解答）

两个半圆合起来相当于一个完整圆；连接缝不在外边界上。

Square root · geometry inputs · 02

Recover a cone height from a slant length

A right circular cone has base radius r and slant length s in cm. Read both, assuming s > r > 0. Calculate perpendicular height, enclosed volume, lateral surface area, and total surface area including the circular base. Print height in cm, volume in litres, and areas in cm². Test r = 5 and s = 13. Use three decimal places.

Reference / 必要约定与公式\(h=\sqrt{s^2-r^2}\), \(V=\pi r^2h/3\), \(A_{side}=\pi rs\), \(A_{total}=\pi rs+\pi r^2\); 1 L = 1000 cm³.
中文提示（不含解答）

斜高与垂直高度不同；先用勾股关系得到体积需要的高度。

Supplied formula · numerical tracing · 03

A triangle from three measured sides

Read the three side lengths a, b, and c of a nondegenerate triangle in metres. Use Heron’s formula to calculate area and the altitude perpendicular to side c. Test a = 13, b = 14, c = 15. Print area in m² and altitude in metres. Trace the values of s, s−a, s−b, and s−c before the square root. Assume the inputs satisfy the strict triangle inequalities.

Reference / 必要约定与公式\(s=(a+b+c)/2\), \(A=\sqrt{s(s-a)(s-b)(s-c)}\), \(h_c=2A/c\).
中文提示（不含解答）

本题 s 是半周长，不是任何一条边；把公式逐项写清可以避免漏括号。

Trigonometric components · degrees · 04

A resultant of two planar forces

Two forces act at a point in the xy plane. Read magnitudes F1, F2 in newtons and angles a1, a2 in degrees measured counterclockwise from the positive x-axis. Compute resultant x and y components, magnitude, and direction in degrees in [−180°, 180°]. Assume the resultant is nonzero. Test F1 = 30, a1 = 0, F2 = 40, a2 = 90. Then repeat after adding 180° to both angles and explain the geometric change.

Reference / 必要约定与公式\(F_x=F_1\cos a_1+F_2\cos a_2\), \(F_y=F_1\sin a_1+F_2\sin a_2\), \(F=\sqrt{F_x^2+F_y^2}\). The endpoint directions −180° and +180° are equivalent.
中文提示（不含解答）

输入角先转弧度；合力方向使用 math.atan2(Fy, Fx)，不要把两个角直接相加。

Pressure distribution · supplied model · 05

Water force on a rectangular gate

A vertical rectangular gate has width w metres and height h metres, with its top edge at the free surface of still water. The other side is exposed to the same atmospheric pressure, so use gauge pressure only. Read w and h, both positive. Use rho = 1000 kg/m³ and g = 9.81 m/s². Calculate the total horizontal water force in N and kN and the depth of its line of action below the surface. Test w = 1.20 and h = 0.75. Use the formulas supplied; no integration is required.

Reference / 必要约定与公式\(F=\rho gwh^2/2\), \(y_{action}=2h/3\); 1 kN = 1000 N.
中文提示（不含解答）

底部压强不能当作整块门上的均匀压强；此处已给出三角形分布的合力公式。

Dimensional calculation · customary units · 06

Pressure expressed as a water-column height

A gauge reads pressure p in psi. Read p and liquid density rho in kg/m³, both positive. Convert the gauge pressure into pascals and kilopascals, then calculate the equivalent stationary liquid-column height in metres. Test p = 18.0 and rho = 998.0. Use g = 9.81 m/s² and print height to three decimal places. Explain why atmospheric pressure must not be added to this gauge-pressure calculation.

Reference / 必要约定与公式\(h=p_{Pa}/(\rho g)\); 1 psi = 6894.757293 Pa; 1 kPa = 1000 Pa.
中文提示（不含解答）

先把 psi 转为 Pa；柱高公式使用给定液体密度，不默认任何其他液体。

Volume difference · flow-rate units · 07

Filling part of a cylindrical reservoir

A vertical cylindrical reservoir of diameter D metres contains liquid at height h0 metres. A constant pump rate Q in L/min raises it to h1 metres, with no outflow or losses. Read D, h0, h1, Q; assume D > 0, Q > 0, 0 ≤ h0 < h1, and that h1 is below the rim. Print added volume in m³ and litres, and filling time in minutes and hours. Test D = 1.6, h0 = 0.35, h1 = 1.10, Q = 24.0.

Reference / 必要约定与公式\(\Delta V=\pi(D/2)^2(h_1-h_0)\), \(t=\Delta V_L/Q\); 1 m³ = 1000 L.
中文提示（不含解答）

只需要补入两液面之间的体积；泵流量单位为每分钟升。

math.log · parameter estimation · 08

Estimate a cooling constant from one observation

A model uses T(t) = Ta + (T0 − Ta) exp(−kt), with t in minutes. All temperatures are in °C. Read Ta, T0, one observation time t1, and the observed temperature T1. Assume t1 > 0 and T0 > T1 > Ta. Calculate k in min⁻¹, then predict T(2t1). Test Ta = 16, T0 = 96, t1 = 8, T1 = 56. Print k to six decimal places and temperatures to two decimals. Check T(t1) using your unrounded k.

Reference / 必要约定与公式\(k=-\ln[(T_1-T_a)/(T_0-T_a)]/t_1\); use math.log and math.exp.
中文提示（不含解答）

先求温差比，再取自然对数；每一个等长时间间隔对应相同的温差比例。

Python operators · input types · 09

Debug a ball-volume report

This program intends to read a solid ball diameter in millimetres and print its volume in cubic centimetres. Repair every error affecting that task and test diameter = 30. Keep the input prompt and output units unambiguous. Assume positive diameter.

import math
d = input("Diameter in mm: ")
r = d / 2
volume_mm3 = (4 / 3) * math.pi * r ^ 3
volume_cm3 = volume_mm3 / 10
print("Volume:", volume_cm3, "cm")
Reference / 必要约定与公式\(V=\frac43\pi r^3\); 1 cm³ = 1000 mm³. Python exponentiation uses **.
中文提示（不含解答）

检查文本输入、Python 的幂运算符、体积单位换算与标签。

Linear formula · labeled output · 10

A two-point sensor calibration

A temperature sensor has a linear voltage–temperature relation over its calibrated range. At V1 = 0.50 V it reads T1 = −20 °C; at V2 = 4.50 V it reads T2 = 120 °C. Write a program that reads a measured voltage V between V1 and V2, converts it to temperature in °C and °F, and prints two decimal places. Test V = 0.72 V, then test both calibration endpoints. Calculate the slope in °C/V and intercept in °C, and explain why the conversion must reproduce both endpoints.

Reference / 必要约定与公式\(m=(T_2-T_1)/(V_2-V_1)\), \(b=T_1-mV_1\), \(T_C=mV+b\), \(T_F=9T_C/5+32\).
中文提示（不含解答）

求出直线后再代入测量值；不要把电压本身当作温差比例。
