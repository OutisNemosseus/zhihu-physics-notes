Input/output · grams per square metre · 01

Estimate a mesh roll from its areal density

A rectangular mesh has uniform areal density sigma in g/m². Read positive width w and length L in metres, and sigma. Calculate area, total mass in grams and total mass in kilograms. Test w = 1.2, L = 3.5, sigma = 180. Write a Python program and print each result to three decimals with units. Ignore edge bindings and cutting losses.

Reference / 必要约定与公式\(A=wL\), \(m_g=\sigma A\), \(m_{kg}=m_g/1000\).
中文提示（不含解答）

面密度乘面积得到质量；注意 g 与 kg 的换算，而不是对长度重复换算。

Composite geometry · two arcs and two straight edges · 02

Cut an annular sector from a thin sheet

An annular sector is the region between concentric radii R and r, bounded by two radial cuts separated by angle theta degrees. Read R > r > 0 in cm, 0 < theta < 360, thickness t > 0 in mm, and density rho > 0 in g/cm³. Calculate face area, the complete boundary length (both arcs and both straight radial edges), and mass. Test R = 9, r = 5, theta = 120, t = 1.5, rho = 2.7. Write Python and print three decimals with units.

Reference / 必要约定与公式\(\alpha=\operatorname{radians}(\theta)\), \(A=\alpha(R^2-r^2)/2\), \(P=\alpha(R+r)+2(R-r)\), \(m=\rho A(t/10)\).
中文提示（不含解答）

内外两条弧都属于切割边界；每条直边长度为两半径之差。

Inverse geometry · litres and square centimetres · 03

Choose a closed cylinder height from a capacity

A closed cylindrical container has specified internal volume V litres and radius r cm. Read V > 0 and r > 0. Ignore wall thickness. Find its height h, total surface area including both circular ends, and the dimensionless ratio h/(2r). Test V = 1.2 and r = 5. Write Python and print three decimals, with cm and cm² where appropriate.

Reference / 必要约定与公式\(V_{cm^3}=1000V\), \(h=V_{cm^3}/(\pi r^2)\), \(A=2\pi rh+2\pi r^2\).
中文提示（不含解答）

先把升换成 cm³，再解出高度；封闭容器的面积包括两个圆面。

Inverse trigonometry · radians, degrees and sagitta · 04

Recover a minor arc from its chord

A circle of radius R cm has a chord of length c cm, with R > 0 and 0 < c < 2R. Read R,c. Using the minor arc (central angle strictly between 0 and 180°), calculate the central angle in degrees, minor-arc length, and sagitta: the distance from the chord midpoint to the minor arc along the radius perpendicular to the chord. Test R = 9 and c = 9. Write Python and print three decimals with units.

Reference / 必要约定与公式\(\alpha=2\arcsin[c/(2R)]\), \(\theta=\operatorname{degrees}(\alpha)\), \(s=R\alpha\), \(h=R-\sqrt{R^2-(c/2)^2}\).
中文提示（不含解答）

asin 的结果是弧度；弧长用弧度角，报告角度时才转换成度。

Supplied algebraic model · displacement and stored energy · 05

Evaluate two ideal springs in series

Two ideal massless springs in series carry the same positive force F. Read k1,k2 > 0 in N/m and F > 0 in N. Use the supplied static model to calculate equivalent stiffness, each extension, total extension, and total stored energy. Test k1 = 120, k2 = 180, F = 9. Write Python; print stiffness to three decimals, energy to four decimals in joules, and extensions to four decimals in metres. This is only an evaluation of the stated ideal model.

Reference / 必要约定与公式\(k_{eq}=(1/k_1+1/k_2)^{-1}\), \(x_1=F/k_1\), \(x_2=F/k_2\), \(x=x_1+x_2\), \(E=(k_1x_1^2+k_2x_2^2)/2\).
中文提示（不含解答）

串联时两个弹簧承受相同的力；总伸长相加，总能量也相加。

Unit conversion · diameter in millimetres and rpm · 06

Report a roller speed without mixing revolutions and radians

A cylindrical roller has diameter d > 0 mm and rotates at n > 0 revolutions per minute. Assume no slip between its surface and a passing sheet. Read d,n and calculate revolutions per second, angular speed in rad/s, surface speed in m/s, and rotation period in seconds. Test d = 64 and n = 450. Write Python and print four decimals with units.

Reference / 必要约定与公式\(f=n/60\), \(\omega=2\pi f\), \(v=\pi(d/1000)f\), \(T=1/f\).
中文提示（不含解答）

线速度等于每转经过的周长乘每秒转数；直径必须先换成米。

Weighted average · signed coordinates · 07

Locate the balance point of two masses

Two point masses lie on a horizontal coordinate axis. Read positive masses m1,m2 in kg and positions x1,x2 in metres, which may be negative. Calculate total mass, the center position xbar, and each signed displacement xi − xbar. Also print the weighted-moment residual m1(x1−xbar)+m2(x2−xbar). Test m1 = 3, x1 = −0.2, m2 = 2, x2 = 1.3. Write Python and print three decimals with units; a tiny floating-point residual is expected to be numerically close to zero.

Reference / 必要约定与公式\(\bar x=(m_1x_1+m_2x_2)/(m_1+m_2)\). The moment residual has units kg·m.
中文提示（不含解答）

坐标保留正负号；相对于平衡点的位移不等于到原点的距离。

math.log · a positive ratio and a length scale · 08

Invert a supplied exponential pressure model

A supplied ideal model is p = p0 exp(−h/H), where pressures use the same units and h,H are lengths in metres. Read p0 > 0, H > 0, and p with 0 < p ≤ p0. Calculate h, then substitute the unrounded h back into the original model to recover p. Test p0 = 101.3 kPa, p = 80.0 kPa, H = 8400 m. Write Python; print h to three decimals in metres and recovered pressure to four decimals in kPa. Use only this supplied model, without asserting a real atmospheric prediction.

Reference / 必要约定与公式\(h=-H\ln(p/p_0)\), \(p_{check}=p_0e^{-h/H}\). Use math.log and math.exp.
中文提示（不含解答）

对数的输入是无量纲压强比；反算时先保留未四舍五入的高度。

Debugging · cubic conversion and formatted strings · 09

Repair a cylinder density report

This program should read mass in grams, diameter and height in millimetres, then report the solid cylinder volume in cm³ and density in g/cm³. Inputs are positive real numbers. Repair every error, test m_g = 54, d_mm = 30, h_mm = 20, and explain why converting millimetres to centimetres must happen in all three length factors. Print four decimals.

import math
m_g = int(input("Mass (g): "))
d_mm = float(input("Diameter (mm): "))
h_mm = float(input("Height (mm): "))
volume = math.pi * (d_mm / 2) ** 2 * h_mm / 10
rho = volume / m_g
print("V={volume:.4f} cm^3, rho={rho:.4f} g/cm^3")
Reference / 必要约定与公式\(d_{cm}=d_{mm}/10\), \(h_{cm}=h_{mm}/10\), \(V=\pi(d_{cm}/2)^2h_{cm}\), \(\rho=m_g/V\).
中文提示（不含解答）

先转换两个长度输入，或把最终 mm³ 除以 1000；密度是质量除以体积。

Supplied geometry · square and cubic powers · 10

Size an ideal regular octahedral solid

A regular octahedron consists of eight equilateral triangular faces, with every edge length a > 0 cm. Read a and density rho > 0 in g/cm³. Use the supplied formulas to calculate surface area, volume, center-to-vertex radius, and mass. Test a = 6, rho = 2.2. Write Python and print three decimals with appropriate units; assume a uniform solid without openings.

Reference / 必要约定与公式\(A=2\sqrt3\,a^2\), \(V=\sqrt2\,a^3/3\), \(R=a/\sqrt2\), \(m=\rho V\).
中文提示（不含解答）

面积随边长平方变化，体积随立方变化；密度单位与体积单位需要配套。
