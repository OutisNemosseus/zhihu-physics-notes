第 1 / 6 题

写一个 Python 程序，生成以下三列数据并完成一次 CSV 写入、读回与绘图。

θ：从 0 到 2π rad，等间距取 100 个值，包含两个端点。

y₁(θ) = 2.5 sin(θ) cm

y₂(θ) = 5.5 cos(θ) cm

  1. 用 NumPy 生成 theta、y1、y2 数组。先把生成的两条曲线画在左图。
  2. 实现 filewritecsv(filename, theta, y1, y2)，用 pandas DataFrame 和 to_csv() 写到 signal_variant_01.csv。逗号分隔，表头按 theta,y1,y2 排列；单位依次为 rad、cm、cm，不输出行索引。
  3. 实现 filereadcsv(filename)，用 pandas read_csv() 读取表头，按同一顺序返回三个 NumPy 数组。用读回的数组在右图画两条曲线。
  4. 一张图内排成 1 行 × 2 列。两图各有标题、横轴 Angle (rad)、纵轴 Displacement (cm)、网格和图例；y₁ 蓝色实线，y₂ 红色虚线。
左图原数组，两条曲线
右图CSV 读回，两条曲线
展开参考答案与检查点

CSV 包含 1 行表头、100 行数据。两个子图各有两条曲线，读回图应与左图重合；下列行号从 0 开始，不含表头。浮点数可有微小尾差。

  i |   theta rad |       y1 cm |       y2 cm
  0 |    0.000000 |    0.000000 |    5.500000

参考实现

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt

def filewritecsv(filename, theta, y1, y2):
    data = pd.DataFrame({"theta": theta, "y1": y1, "y2": y2})
    data.to_csv(filename, index=False)

def filereadcsv(filename):
    data = pd.read_csv(filename)
    return (data["theta"].to_numpy(),
            data["y1"].to_numpy(),
            data["y2"].to_numpy())

def draw(ax, theta, y1, y2, title):
    ax.plot(theta, y1, "b-", label="y1")
    ax.plot(theta, y2, "r--", label="y2")
    ax.set_title(title)
    ax.set_xlabel("Angle (rad)")
    ax.set_ylabel("Displacement (cm)")
    ax.grid(True)
    ax.legend()

theta = np.linspace(0, 2 * np.pi, 100)
y1 = 2.5 * np.sin(theta)
y2 = 5.5 * np.cos(theta)
fig, (left, right) = plt.subplots(1, 2)
draw(left, theta, y1, y2, "Generated arrays")

name = "signal_variant_01.csv"
filewritecsv(name, theta, y1, y2)
theta_r, y1_r, y2_r = filereadcsv(name)
draw(right, theta_r, y1_r, y2_r, "Read back from CSV")
fig.subplots_adjust(wspace=0.55, bottom=0.15)
plt.show()
