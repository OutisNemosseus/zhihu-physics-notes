Input/output · specified gallon conversion · 01

Convert a container reading into volume and mass

A container reading is in US liquid gallons. Read volume G in US gal and liquid density rho in kg/L, both positive. Print volume in litres and cubic metres, then mass in kilograms, all to three decimals. Test G = 3.25 and rho = 0.85. Use exactly 1 US liquid gallon = 3.785411784 L. Do not use the Imperial gallon conversion.

Reference / 必要约定与公式\(V_L=3.785411784G\), \(V_{m^3}=V_L/1000\), \(m=\rho V_L\).
中文提示（不含解答）

先统一体积单位，再乘以每升质量；题目已明确是哪一种 gallon。

Geometry · inner and outer dimensions · 02

Material in a hollow rectangular duct

A straight hollow duct has outside width W, outside height H, and uniform wall thickness t, all in mm. Its open ends are not capped. Read W,H,t in millimetres and length L in metres, assuming W,H > 2t, t > 0, L > 0. Calculate the material cross-sectional area in mm², material volume in cm³, and inner air-passage area in cm². Test W = 80, H = 50, t = 2, L = 1.5. Print three decimals.

Reference / 必要约定与公式\(A_m=WH-(W-2t)(H-2t)\), \(V_m=A_mL_{mm}\), \(A_{air}=(W-2t)(H-2t)\); 1 m=1000 mm, 1 cm²=100 mm², 1 cm³=1000 mm³.
中文提示（不含解答）

内长宽各减去两层壁厚；材料截面积等于外矩形面积减去内矩形面积。

Square root · volume and surface area · 03

A closed right-triangular prism

A solid right prism has a right-triangular end face with perpendicular legs a and b, and prism length L. Read all three lengths in centimetres, all positive. Calculate the third side of the triangle, prism volume, and total outside surface area including both triangular ends. Test a = 5, b = 12, L = 20. Print three decimals and correct area/volume units.

Reference / 必要约定与公式\(c=\sqrt{a^2+b^2}\), \(V=abL/2\), \(A=ab+(a+b+c)L\).
中文提示（不含解答）

两端共有两个三角形；三个侧面的宽度分别是三角形的三条边。

Radians · a supplied segment formula · 04

Area between a chord and an arc

A minor circular segment is the region between a straight chord and the shorter circular arc joining its endpoints. Read radius r in cm and central angle theta_deg in degrees, with r > 0 and 0 < theta_deg < 180°. Calculate chord length, segment area, and segment area as a percentage of the full circle. Test r = 10 and theta_deg = 60. Print three decimals. Convert the angle to radians before using the area formula.

Reference / 必要约定与公式\(c=2r\sin(\theta/2)\), \(A=r^2(\theta-\sin\theta)/2\), \(P=100A/(\pi r^2)\).
中文提示（不含解答）

弓形面积是扇形面积减去等腰三角形面积；公式中的角度本身也必须是弧度。

Arithmetic · absolute temperature · 05

Report a temperature in three scales

Read a temperature F in degrees Fahrenheit, assuming it is above −459.67 °F. Convert it to Celsius and kelvin, and print the original Fahrenheit value and both conversions to two decimals with clear labels. Test F = 95. Also test F = 32 as a reference check. State why adding 273.15 directly to the Fahrenheit input would be incorrect.

Reference / 必要约定与公式\(C=5(F-32)/9\), \(K=C+273.15\).
中文提示（不含解答）

先把华氏度转为摄氏度，再转换绝对温度；kelvin 的单位符号是 K。

Power · minutes, hours and joules · 06

Energy used during a timed run

A device draws constant input power P in watts for t minutes and converts a fraction eta_percent of the input energy into useful output. Read P > 0, t ≥ 0 and 0 ≤ eta_percent ≤ 100. Calculate input energy in joules and kWh, useful energy in joules, and wasted energy in joules. Test P = 750, t = 12, eta_percent = 80. Print three decimals and check that useful plus wasted energy equals input energy.

Reference / 必要约定与公式\(E_{in}=P(60t)\), \(E_{kWh}=(P/1000)(t/60)\), \(E_{useful}=E_{in}\eta_{percent}/100\), \(E_{waste}=E_{in}-E_{useful}\).
中文提示（不含解答）

瓦特是每秒焦耳；kWh 则要用千瓦乘小时。百分比先除以 100。

Planar components · distance from start · 07

Two travel legs with a turn

A walker first travels distance a due east, then turns counterclockwise through angle theta from east and travels distance b. Read a and b in metres and theta in degrees, with a,b > 0 and 0 ≤ theta ≤ 180°. Calculate the final east and north coordinates relative to the start, straight-line distance from the start, and total path length. Test a = 30, b = 40, theta = 60°. Print three decimals. Explain why total path length and straight-line displacement need not agree.

Reference / 必要约定与公式\(x=a+b\cos\theta\), \(y=b\sin\theta\), \(d=\sqrt{x^2+y^2}\), \(s=a+b\). Convert degrees before trigonometric functions.
中文提示（不含解答）

第二段的方向相对于东向定义；先把两段位移的分量相加，再求最终距离。

A linear model · input ranges · 08

Interpolate between two supplied table entries

A table gives a dimensionless factor y = 1.12 at temperature x = 20 °C and y = 1.28 at x = 60 °C. Assume straight-line interpolation is valid only between these two temperatures. Read a temperature x in [20,60] and calculate the interpolated factor to four decimals. Test x = 35, then check both endpoints. Write your code using named variables x0, x1, y0 and y1 for the table entries rather than scattering repeated numeric constants.

Reference / 必要约定与公式\(y=y_0+(y_1-y_0)(x-x_0)/(x_1-x_0)\), with \(x_0=20,x_1=60,y_0=1.12,y_1=1.28\).
中文提示（不含解答）

先算输入位于两个端点之间的比例；同一个比例用于输出的变化量。

Type conversion · grouping and units · 09

Repair a percentage-extension report

The program should read an original length L0 and final length L1 in millimetres, with L1 ≥ L0 > 0. It must print extension in centimetres and percentage extension relative to L0. Repair all errors and test L0 = 250, L1 = 251.5. Use three decimals.

L0 = float(input("Original length (mm): "))
L1 = input("Final length (mm): ")
extension_cm = (L1 - L0) * 10
percent = L1 - L0 / L0 * 100
print(f"Extension: {extension_cm:.3f} mm")
print(f"Extension percentage: {percent:.3f}%")
Reference / 必要约定与公式\(\Delta L=L_1-L_0\), \(P=100\Delta L/L_0\); 1 cm = 10 mm.
中文提示（不含解答）

检查输入类型、毫米到厘米的方向，以及百分比中整个长度差的括号。

Mass balance · compatible units · 10

Density of an ideal additive-volume mixture

Two hypothetical liquids are combined under a supplied ideal model in which volumes add exactly and no mass is lost. Read volumes V1 and V2 in litres and densities rho1 and rho2 in g/cm³, all positive. Calculate each mass in grams, total volume in cm³, and final density in g/cm³. Test V1 = 1.2, V2 = 0.8, rho1 = 1.10, rho2 = 0.90. Print three decimals. Explain why an unweighted mean of the densities is not appropriate for this test.

Reference / 必要约定与公式\(m_i=\rho_iV_i\) in compatible units, \(\rho_f=(m_1+m_2)/(V_1+V_2)\); 1 L = 1000 cm³.
中文提示（不含解答）

先把两个体积转为 cm³；总质量除以总体积，不能先直接平均两个密度。
