Input/output · area and thickness · 01

Material in a rectangular frame

A flat rectangular frame has outside length L and width W. A rectangular opening is centered inside it, leaving a uniform border b on all four sides. Read L, W, b and thickness t in millimetres, and material density rho in g/cm³. Assume L,W > 2b, b,t,rho > 0. Compute remaining face area in mm², material volume in cm³, and mass in g. Test L = 120, W = 80, b = 10, t = 3, rho = 2.70. Print three decimals.

Reference / 必要约定与公式\(A=LW-(L-2b)(W-2b)\), \(V=At\), \(m=\rho V\) in compatible units; 1000 mm³ = 1 cm³.
中文提示（不含解答）

内孔的长和宽都要减去两边边框；体积换为 cm³ 后才能乘给定密度。

Composite geometry · exposed surfaces · 02

A cylindrical vessel with a conical top

A closed vessel consists of a circular cylinder of radius r and straight height h, topped by a cone of the same radius and vertical height k. Its flat circular bottom is exposed. Read r, h and k in centimetres, all positive. Ignore thickness and the internal circular join. Calculate enclosed volume in litres and total exterior area in cm². Test r = 3, h = 8, k = 4. Print three decimals.

Reference / 必要约定与公式\(\ell=\sqrt{r^2+k^2}\), \(V=\pi r^2h+\pi r^2k/3\), \(A=2\pi rh+\pi r\ell+\pi r^2\); 1000 cm³ = 1 L.
中文提示（不含解答）

外表面包括圆柱侧面、圆锥侧面和一个底面；圆柱与圆锥交界的圆面不外露。

Radians · inverse geometry · 03

A sector specified by its arc length

A circular sector has radius r cm and arc length s cm. Read r and s, assuming r > 0 and 0 < s < 2πr. Calculate its central angle in radians and degrees, area in cm², and the perimeter consisting of the arc plus two radial edges. Test r = 12 and s = 10. Print all outputs to three decimals. The arc length is not the straight chord length.

Reference / 必要约定与公式\(s=r\theta\), \(A=r^2\theta/2\), \(P=s+2r\); \(\theta_{deg}=180\theta/\pi\).
中文提示（不含解答）

弧长公式使用弧度；扇形周长还包括两条半径。

Percent grade · trigonometry · 04

Convert a road grade to angle and length

A straight uphill path has horizontal run d in metres and grade G percent, defined as 100 times vertical rise divided by horizontal run. Read d > 0 and G ≥ 0. Compute rise, actual sloped length, and angle above the horizontal. Test d = 250 and G = 6. Print lengths to three decimals and angle in degrees to two decimals. Also check G = 0.

Reference / 必要约定与公式\(h=dG/100\), \(\ell=\sqrt{d^2+h^2}\), \(\theta=\arctan(h/d)\). Use math.degrees for the output angle.
中文提示（不含解答）

6% 坡度不是 6°；把百分数还原成高差与水平距离的比值。

Time units · total-distance average · 05

Average speed for a round trip with a stop

A vehicle travels one-way distance d km at outbound speed v1 km/h, stops for s minutes, then returns the same distance at speed v2 km/h. Read d,v1,v2 > 0 and s ≥ 0. Calculate total elapsed time in hours and average speed over the whole trip, including the stop. Test d = 18, v1 = 36, v2 = 54, s = 10. Print three decimals. Compare the result with the arithmetic mean of v1 and v2 and explain why that mean is not the requested average.

Reference / 必要约定与公式\(t=d/v_1+d/v_2+s/60\), \(v_{avg}=2d/t\).
中文提示（不含解答）

先分别计算两段行驶时间，再加入停留时间；总路程是单程距离的两倍。

A supplied model · absolute temperature · 06

Gas volume after a state change

A fixed amount of ideal gas changes from state 1 to state 2. Read initial volume V1 in litres, initial and final absolute pressures P1 and P2 in kPa, and temperatures T1 and T2 in °C. Assume V1,P1,P2 > 0 and both Celsius temperatures exceed −273.15. Calculate final volume in litres and percentage volume change, using the supplied model. Test V1 = 2.4, P1 = 100, P2 = 125, T1 = 20, T2 = 60. Print three decimals. The pressures are absolute, not gauge readings.

Reference / 必要约定与公式\(T_K=T_C+273.15\), \(V_2=V_1(P_1/P_2)(T_{2K}/T_{1K})\), \(\Delta\%=100(V_2-V_1)/V_1\).
中文提示（不含解答）

比例中的温度必须用开尔文；两次压力使用同一单位即可相除。

Sine and cosine · units and signs · 07

Position of a ball under a supplied model

An idealized ball starts at ground level at t = 0, with speed v0 at angle theta above the horizontal. Ignore air resistance and use the supplied position formulas. Read v0 in m/s, theta in degrees, and t in seconds, with v0 > 0, 0 < theta < 90°, and t between launch and the return to ground. Compute horizontal and vertical position. Test v0 = 10, theta = 30°, t = 0.50, using g = 9.81 m/s². Print both positions to three decimals. Also verify that t = 0 returns the starting point.

Reference / 必要约定与公式\(x=v_0\cos\theta\,t\), \(y=v_0\sin\theta\,t-gt^2/2\). The valid flight interval is \(0\le t\le2v_0\sin\theta/g\).
中文提示（不含解答）

先将角度转为弧度再传给 sin 和 cos；竖直项中的重力作用要减去。

Exponential function · milliseconds · 08

Evaluate a provided charging formula

An ideal model gives capacitor voltage v(t) as below. Write a program that reads source voltage Vs in V, resistance R in Ω, capacitance C_micro in μF, and elapsed time t_ms in ms. Assume Vs,R,C_micro > 0 and t_ms ≥ 0. The capacitor starts uncharged. Print the time constant in ms, voltage in V, and percentage of final voltage, to three decimals. Test Vs = 9, R = 2000, C_micro = 50, t_ms = 150. Also evaluate t_ms = 0 and t_ms equal to the time constant. You only need to evaluate the supplied formula, not derive a differential equation.

Reference / 必要约定与公式\(C=C_{micro}10^{-6}\;\mathrm F\), \(\tau=RC\), \(v=V_s(1-e^{-t/\tau})\); \(t=t_{ms}/1000\). Python math.exp evaluates the exponential.
中文提示（不含解答）

R 与 C 用 SI 单位相乘得到秒；指数中的时间比值必须使用同一单位。

Input types · radians and output units · 09

Repair a polar-to-Cartesian conversion

The program should read a planar vector magnitude M in newtons and direction theta measured counterclockwise from the positive x-axis in degrees. It must print x and y components in newtons to two decimals. Repair every error. Test M = 10, theta = 120°. Explain why the x-component should be negative for this test.

import math
M = input("Magnitude (N): ")
theta = float(input("Direction (degrees): "))
x = M * math.cos(theta)
y = M * math.cos(theta)
print(f"x = {x:.2f} m, y = {y:.2f} m")
Reference / 必要约定与公式\(x=M\cos\theta\), \(y=M\sin\theta\); math.sin and math.cos use radians.
中文提示（不含解答）

检查幅值类型、角度单位、y 分量所用函数以及输出标签；第二象限的正负号可作核对。

Formula translation · parentheses · 10

Evaluate two real quadratic roots

Write a program that reads real coefficients a, b and c of ax² + bx + c = 0. Assume a ≠ 0 and discriminant D = b² − 4ac > 0, so there are two distinct real roots; no validation logic is required. Calculate D and both roots with the supplied formula. Test a = 2, b = −7, c = 3. Print roots to four decimals. Substitute each unrounded root back into the polynomial and print the residual in scientific notation. Explain why the denominator must include the entire product 2a.

Reference / 必要约定与公式\(D=b^2-4ac\), \(x_\pm=(-b\pm\sqrt D)/(2a)\); residual \(r=ax^2+bx+c\). In Python, use ** for powers and :.2e for a scientific-notation residual.
中文提示（不含解答）

先计算判别式并开方；正负号产生两个结果，分母用括号包住 2*a。
