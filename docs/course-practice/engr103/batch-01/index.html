Input → calculation → output · 01

Triangle area, four units

Write a Python program that reads a triangle’s base B and perpendicular height H in inches as positive decimal numbers. Print its area in in², cm², ft², and m², each to three decimal places with a label and unit.

Test your program with B = 14.0, H = 9.0, and then B = 0.5, H = 0.8. State why the area conversion uses a squared factor.

Reference / 必要约定与公式\(A=BH/2\); 1 in = 2.54 cm; 1 ft = 12 in; 1 in = 0.0254 m.
中文提示（不含解答）

先列输入、基本单位、输出单位；保留中间精度，最后才格式化。

math.pi · length versus area · 02

A circular inspection port

Read a radius r in inches. Print circumference in inches and centimetres, and area in square inches and square centimetres. Use math.pi rather than a rounded value of π. Test r = 3.5 and r = 0.75. Assume r > 0.

After running both tests, explain how each output changes when the radius is doubled.

Reference / 必要约定与公式\(C=2\pi r,\quad A=\pi r^2\); 1 in = 2.54 cm.
中文提示（不含解答）

周长用一次换算，面积用平方换算。

Surface area · volume · powers · 03

A spherical sensor housing

Write a program that reads the radius of a solid sphere in centimetres and prints surface area in cm² and m², and volume in cm³ and litres. Use r = 2.4 cm for your first test and r = 6.0 cm for a second test. Include a short comment stating each variable’s unit.

Reference / 必要约定与公式\(S=4\pi r^2,\quad V=\frac43\pi r^3\); 1 m = 100 cm; 1 L = 1000 cm³.
中文提示（不含解答）

Python 的乘方写作 **；面积、体积和长度的单位因子不同。

Coordinates · square root · 04

Survey points and midpoint

Read x₁, y₁, x₂, y₂ in centimetres. Report the point-to-point distance and both midpoint coordinates in inches. Test the points (−3, 4) and (9, −1), then test two identical points. Do not discard negative midpoint coordinates.

Reference / 必要约定与公式\(d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}\), \(M=((x_1+x_2)/2,(y_1+y_2)/2)\); 1 in = 2.54 cm.
中文提示（不含解答）

距离是标量；中点有两个坐标，两者都要换单位。

Engineering units · input types · 05

Pressure below a liquid surface

A sensor is submerged H metres below a liquid surface open to atmospheric pressure. Read positive H and specific gravity SG. Calculate gauge pressure in Pa and kPa. Use H = 2.8 m and SG = 0.85 for a test. Print all outputs to two decimal places and explain why atmospheric pressure is not added.

Reference / 必要约定与公式\(\rho=1000\,SG\;\mathrm{kg/m^3}\), \(p=\rho gH\); use g = 9.81 m/s²; 1 kPa = 1000 Pa.
中文提示（不含解答）

比重无单位，先换成密度；求的是相对液面的表压。

Degrees ↔ radians · math functions · 06

A triangular bracket

Read positive side lengths a and b in cm and the included angle γ in degrees, with 0 < γ < 180. Calculate the third side c and the remaining angles α and β in degrees. Define α opposite a and β opposite b. Test a = 7, b = 10, γ = 52°. Print the three angles and their sum.

You may assume valid inputs and need not implement input validation. Explain where radians are required.

Reference / 必要约定与公式\(c=\sqrt{a^2+b^2-2ab\cos\gamma}\); \(\alpha=\arccos((b^2+c^2-a^2)/(2bc))\); \(\beta=180^\circ-\gamma-\alpha\).
中文提示（不含解答）

math.cos 与 math.acos 使用弧度；不要在中间步骤四舍五入。

Geometry · unit-aware outputs · 07

An open cylindrical tank

An open-top cylindrical tank has internal radius r and height h, both in metres. Ignore wall thickness. Read r and h, then print capacity in m³ and litres, and the inside surface area of the wall plus bottom in m². Test r = 0.4 and h = 1.2. State which circular face is excluded.

Reference / 必要约定与公式\(V=\pi r^2h\), \(S=2\pi rh+\pi r^2\); 1 m³ = 1000 L.
中文提示（不含解答）

开口没有顶盖，面积只算侧面与一个底面。

float(input()) · formatted output · 08

Reading and formatting temperature

Write a program that asks for a Celsius temperature, converts it to Fahrenheit and kelvin, and prints both to one decimal place with explicit units. Test C = −12.5, C = 0, and C = 37. Explain why reading the input as an integer would be inappropriate here.

Reference / 必要约定与公式\(F=\frac95C+32\), \(K=C+273.15\). Inputs are at least −273.15 °C.
中文提示（不含解答）

input 返回字符串；这里允许小数，不要截成整数。

Natural logarithm · model parameters · 09

Cooling a laboratory sample

A sample cools in a constant 20 °C room. It is 70 °C at t = 0 min and 50 °C at t = 12 min. Write a program that reads these four values (room temperature, initial temperature, later temperature, elapsed minutes), calculates k in min⁻¹, and finds the total time from t = 0 until the sample reaches 35 °C. Assume the temperatures satisfy the cooling model.

Use math.log for natural logarithms. Print k to five decimals and time to two decimals.

Reference / 必要约定与公式\(T(t)=T_s+(T_0-T_s)e^{-kt}\); \(k=-\ln((T_1-T_s)/(T_0-T_s))/t_1\); \(t=-\ln((T-T_s)/(T_0-T_s))/k\).
中文提示（不含解答）

始终使用“高于环境的温差”；求的是从最初时刻开始的总时间。

Trace → diagnose → repair · 10

Debug a unit-conversion script

The following program intends to read a radius in inches and print circle area in cm². Identify every error that affects this task, write a corrected version, and test it with radius 2.0 and 4.0. Explain why doubling the input should multiply the result by four.

import math
r = input("Radius in inches: ")
area_in2 = math.pi * r ^ 2
area_cm2 = area_in2 * 2.54
print("Area =", area_cm2, "cm")
Reference / 必要约定与公式\(A=\pi r^2\); 1 in = 2.54 cm.
中文提示（不含解答）

分别检查数据类型、运算符、换算因子、输出单位。
