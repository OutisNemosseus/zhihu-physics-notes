Input/output · signed flow balance · 01

Fill a reservoir while a drain remains open

A reservoir initially contains V0 litres. A pump adds Qin mL/min while a drain removes Qout L/min, both at constant rates. Read V0 ≥ 0, target Vf > V0, Qin > 0 and Qout ≥ 0, with Qin/1000 > Qout. Calculate net filling rate in L/min and time in minutes and seconds to first reach Vf. Test V0 = 0.6, Vf = 2.4, Qin = 420, Qout = 0.18. Write Python and print three decimals with units. Assume adequate tank capacity and constant rates throughout.

Reference / 必要约定与公式\(q_{net}=Q_{in}/1000-Q_{out}\), \(t_{min}=(V_f-V_0)/q_{net}\), \(t_s=60t_{min}\).
中文提示（不含解答）

进水与出水单位统一后做减法；需要增加的是目标体积减去初始体积。

Supplied approximation · semiaxes and mass · 02

Estimate the edge length of an elliptical plate

An elliptical plate has semimajor axis a and semiminor axis b in cm, with a ≥ b > 0. Read a,b, thickness t > 0 in mm, and density rho > 0 in g/cm³. Use the supplied perimeter approximation to calculate area, approximate perimeter and mass. Test a = 6, b = 4, t = 2, rho = 2.8. Write Python and print three decimals with units. The inputs are semiaxes, not full diameters; ignore edge bevels.

Reference / 必要约定与公式\(A=\pi ab\), \(P\approx\pi[3(a+b)-\sqrt{(3a+b)(a+3b)}]\), \(m=\rho A(t/10)\).
中文提示（不含解答）

椭圆面积使用两条半轴；周长公式是给定的近似式，质量仍由面积和厚度计算。

Composite geometry · distinguish the hidden join · 03

A cylinder with a hemispherical roof

An ideal closed vessel consists of a right circular cylinder of radius r cm and cylindrical height h cm, topped by a hemisphere of the same radius. Its bottom is a flat circular disk. Read r,h > 0. Calculate internal capacity in cm³ and litres, total exterior area, and total height. Test r = 3 and h = 10. Ignore wall thickness; do not count the circular join between the cylinder and hemisphere as exposed surface. Write Python and print three decimals with units.

Reference / 必要约定与公式\(V=\pi r^2h+2\pi r^3/3\), \(A=2\pi rh+2\pi r^2+\pi r^2\), \(H=h+r\), \(V_L=V/1000\).
中文提示（不含解答）

体积把两个部分相加；外表面积不包括内部接合圆面，但包括底部圆盘。

Supplied vector formulas · dot product and inverse cosine · 04

Measure an angle and a signed projection

Read two nonzero planar vectors u=(ux,uy) and v=(vx,vy), with all components in metres. Compute their dot product, magnitudes, angle between them in [0°,180°], and the signed scalar projection of u along v. Test u=(2,−1), v=(1,3). Write Python and print three decimals; use m² for the dot product, m for magnitudes/projection and degrees for angle. Use the unrounded intermediate values. If roundoff moves the acos input slightly outside [−1,1], clamp it to that interval with min and max.

Reference / 必要约定与公式\(d=u_xv_x+u_yv_y\), \(U=\sqrt{u_x^2+u_y^2}\), \(V=\sqrt{v_x^2+v_y^2}\), \(\theta=\operatorname{degrees}(\arccos[d/(UV)])\), \(s=d/V\).
中文提示（不含解答）

点积的负号有意义；反余弦返回弧度，投影的正负表示沿 v 方向还是反方向。

Units and trigonometry · centimetres to metres · 05

Evaluate a supplied lever-torque model

A planar force of magnitude F newtons makes angle theta degrees with a lever arm of length r centimetres. Read F,r > 0 and 0 < theta < 180. Use the supplied magnitude formulas to calculate the force component perpendicular to the arm and the resulting torque magnitude. Test F = 25, r = 18, theta = 40. Write Python and print four decimals with N and N·m. The angle is measured between the lever arm vector and force vector.

Reference / 必要约定与公式\(\alpha=\operatorname{radians}(\theta)\), \(F_\perp=F\sin\alpha\), \(\tau=(r/100)F_\perp\).
中文提示（不含解答）

力臂先换成米；给定夹角用正弦求垂直分量，不能直接使用以度表示的数作为 sin 输入。

Supplied steady model · millimetres and elapsed minutes · 06

Calculate heat flow through an ideal flat layer

For a uniform flat insulating layer, use the supplied steady heat-flow model. Read conductivity k > 0 in W/(m·K), area A > 0 in m², thickness L > 0 in mm, temperature difference deltaT > 0 in K, and duration t > 0 in minutes. Calculate thermal resistance, heat-flow rate and energy transferred over the duration. Test k = 0.20, A = 0.75, L = 12, deltaT = 18, t = 10. Write Python; print resistance to five decimals and other results to three, with units. Assume fixed temperatures and ignore edge flow and storage.

Reference / 必要约定与公式\(R_{th}=(L/1000)/(kA)\) in K/W, \(\dot Q=\Delta T/R_{th}\) in W, \(E=\dot Q(60t)\) in J.
中文提示（不含解答）

厚度与时间分别转换为米和秒；热流率是功率，乘秒才得到能量。

Volume conversion · math.ceil and surplus · 07

Round a droplet count upward only at the end

Assume each delivered droplet is an identical sphere of radius r mm. Read r > 0 and desired volume V > 0 in mL. Calculate volume per droplet in mm³, the smallest whole number N of droplets delivering at least V, the resulting delivered volume in mL and the surplus in mL. Test r = 0.8, V = 1.5. Write Python; print N as an integer and volume results to four decimals. Ignore evaporation and changes in droplet shape, and do not round droplet volume before finding N.

Reference / 必要约定与公式\(v_d=4\pi r^3/3\), \(N=\lceil1000V/v_d\rceil\), \(V_{del}=Nv_d/1000\), \(V_{extra}=V_{del}-V\). Use math.ceil.
中文提示（不含解答）

1 mL 等于 1000 mm³；只有液滴数量需要向上取整，其余计算保留精度。

math.exp and math.log · a positive-coordinate choice · 08

Evaluate and invert a supplied Gaussian profile

A supplied one-dimensional intensity profile is I(x)=I0 exp[−(x/a)²]. Read I0 > 0 in arbitrary intensity units, length scale a > 0 in cm, and position x in cm. Calculate I(x). Then find the positive coordinate x10 where intensity is I0/10, and verify the ratio I(x10)/I0 using the unrounded x10. Test I0 = 50, a = 4, x = 6. Write Python; print intensity and x10 to four decimals and the ratio to six decimals. The model is given; no wave or optics theory is required.

Reference / 必要约定与公式\(I(x)=I_0e^{-(x/a)^2}\), \(x_{10}=a\sqrt{\ln10}\). Use math.exp, math.log and math.sqrt.
中文提示（不含解答）

指数中的长度比无量纲；平方会产生对称位置，本题明确只要正坐标。

Debugging · milliampere-minutes are not coulombs · 09

Repair an electrical-charge unit report

The program should read a positive constant current in mA and duration in minutes, then report charge in coulombs and capacity in mAh. Repair every unit/formatting error and test I_mA = 250, t_min = 18. Explain how the two requested results can represent the same amount of charge. Print three decimals with units.

I_mA = float(input("Current (mA): "))
t_min = float(input("Duration (min): "))
charge = I_mA * t_min
capacity = charge / 3600
print("Q={charge:.3f} C, capacity={capacity:.3f} mAh")
Reference / 必要约定与公式\(Q_C=(I_{mA}/1000)(60t_{min})\), \(Q_{mAh}=I_{mA}t_{min}/60\), \(1\;\mathrm{mAh}=3.6\;\mathrm C\).
中文提示（不含解答）

库仑使用安培乘秒；mAh 则使用毫安乘小时，两个结果的换算系数是 3.6。

Supplied geometry · both circular end faces · 10

Material in a closed circular frustum

A uniform solid right circular frustum has larger radius R, smaller radius r and perpendicular height h, all in cm, with R > r > 0 and h > 0. Read R,r,h and density rho > 0 in g/cm³. Compute slant length, volume, total outside area including both circular faces, and mass. Test R = 6, r = 2, h = 3, rho = 1.3. Write Python and print three decimals with units. The faces are parallel and their centers lie on the perpendicular axis.

Reference / 必要约定与公式\(s=\sqrt{h^2+(R-r)^2}\), \(V=\pi h(R^2+Rr+r^2)/3\), \(A=\pi(R+r)s+\pi R^2+\pi r^2\), \(m=\rho V\).
中文提示（不含解答）

侧面展开面积使用斜长；完整外表面积还包括大小两个圆面。
