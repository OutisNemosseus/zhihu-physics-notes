Input/output · litres and millilitres · 01

Prepare a diluted solution by conserving solute

A stock solution has concentration Cs in g/L. Read Cs > Ct > 0, the desired concentration Ct in g/L, and final solution volume Vf > 0 in mL. Assuming volumes add and the added solvent contains no solute, calculate required stock volume, added solvent volume (both mL), and solute mass (g). Test Cs=80, Ct=20, Vf=750. Write Python and print three decimals with units.

Reference / 必要约定与公式\(m=C_tV_f/1000\), \(V_s=1000m/C_s\), \(V_{solvent}=V_f-V_s\).
中文提示（不含解答）

先用最终体积和目标浓度计算溶质量；同一溶质量决定需要多少原液。

Geometry · perpendicular diagonals · 02

Material in a rhombus-shaped plate

A uniform rhombus has perpendicular diagonals d1,d2 in cm, thickness t in mm, and density rho in g/cm³. Read positive inputs. Compute its face area, side length, perimeter and mass. Test d1=12, d2=16, t=3, rho=7.8. Write Python and print three decimals with units. Ignore edge bevels; use the supplied diagonal formulas.

Reference / 必要约定与公式\(A=d_1d_2/2\), \(s=\sqrt{(d_1/2)^2+(d_2/2)^2}\), \(P=4s\), \(m=\rho A(t/10)\).
中文提示（不含解答）

两条对角线各取一半形成直角三角形；厚度先由毫米转为厘米。

Composite surfaces · a flat rectangular base · 03

Close every face of a half-cylinder

A solid right half-cylinder has semicircular end faces of radius r cm and length L cm along its straight axis. Its boundary consists of a curved half-cylinder, two semicircular ends and a flat rectangle of width 2r and length L. Read r,L > 0. Compute volume, total outside area, overall width and height. Test r=3,L=20. Write Python and print three decimals with units; do not omit the flat rectangular face.

Reference / 必要约定与公式\(V=\pi r^2L/2\), \(A=\pi rL+\pi r^2+2rL\), \(W=2r\), \(H=r\).
中文提示（不含解答）

两个半圆端面合为一个圆；曲面仅为圆柱侧面的一半，切开的长方形面仍是外表面。

Supplied coordinate formulas · degrees to radians · 04

Rotate a point without changing its distance

Read coordinates x,y in metres and counterclockwise rotation angle theta in degrees about the origin. Use the supplied formulas to compute the rotated coordinates and the original and rotated distances from the origin. Test x=3,y=4,theta=30. Write Python and print six decimals with units. State whether the two computed distances agree to the displayed precision; use full precision in all intermediate calculations.

Reference / 必要约定与公式\(a=\operatorname{radians}(\theta)\), \(x_r=x\cos a-y\sin a\), \(y_r=x\sin a+y\cos a\), \(d=\sqrt{x^2+y^2}\), \(d_r=\sqrt{x_r^2+y_r^2}\).
中文提示（不含解答）

旋转的正方向为逆时针；三角函数输入需要弧度，距离检查可发现公式符号错误。

Supplied model · grams to kilograms · 05

Evaluate an ideal mass-and-spring timing model

For an ideal undamped mass and spring, read spring constant k > 0 in N/m and attached mass m > 0 in grams. Calculate angular frequency in rad/s, ordinary frequency in Hz and period in seconds. Test k=180,m=500. Write Python and print four decimals with units. The mass of the spring is neglected; the model below is supplied and does not require solving a differential equation.

Reference / 必要约定与公式\(m_{kg}=m/1000\), \(\omega=\sqrt{k/m_{kg}}\), \(f=\omega/(2\pi)\), \(T=2\pi/\omega\).
中文提示（不含解答）

质量使用千克；角频率与每秒循环次数相差 2π，周期是普通频率的倒数。

Supplied model · circular piston areas · 06

Use an ideal hydraulic force and travel ratio

An ideal hydraulic device has input piston diameter d1 and output diameter d2 in mm. Read positive d1,d2, input force F1 in N and input travel s1 in mm. Compute the common gauge pressure in Pa, output force in N and output travel in mm. Test d1=10,d2=50,F1=12,s1=25. Assume incompressible fluid, no leakage or friction, and conservation of displaced volume. Write Python and print three decimals with units.

Reference / 必要约定与公式\(A_i=\pi(d_i/1000)^2/4\), \(p=F_1/A_1\), \(F_2=pA_2\), \(s_2=s_1A_1/A_2\).
中文提示（不含解答）

求压力时面积使用平方米；输出位移由体积守恒决定，与面积比成反比。

Supplied geometry · one revolution at a time · 07

Measure the length of a helical tool path

A tool follows a circular helix of radius r mm, advancing a fixed pitch p mm along the axis per full revolution. Read r,p > 0 and a positive whole number N of revolutions. Calculate path length per revolution, total path length and axial advance, all in mm. Test r=5,p=3,N=8. Write Python and print three decimals. The supplied unwrapped-helix formula is exact for this ideal path.

Reference / 必要约定与公式\(\ell=\sqrt{(2\pi r)^2+p^2}\), \(L=N\ell\), \(h=Np\).
中文提示（不含解答）

每圈沿圆周和轴向的距离互相垂直；轴向前进距离不同于工具实际行程。

math.exp and math.log · offset exponential · 08

Invert a supplied drying model with a residual mass

A supplied drying model is m(t)=mr+(m0−mr)exp(−kt), with t in minutes and masses in grams. Read m0 > mt > mr ≥ 0, k > 0 in min⁻¹, and an observation time t ≥ 0. Calculate m(t), the first time at which mass reaches target mt, and verify the model at that unrounded target time. Test m0=120,mr=20,mt=50,k=0.08,t=15. Write Python and print four decimals with units.

Reference / 必要约定与公式\(m(t)=m_r+(m_0-m_r)e^{-kt}\), \(t_*=-\ln[(m_t-m_r)/(m_0-m_r)]/k\).
中文提示（不含解答）

只有超出残余质量的部分按指数衰减；求时间前先减去残余质量。

Debugging · conversions and the power operator · 09

Repair a momentum and kinetic-energy report

The program should read a positive mass in grams and speed in km/h, then report momentum in kg·m/s and kinetic energy in joules. Repair every conversion, operator and formatting error. Test mass_g=750,speed_kmh=36. Write the corrected program and print three decimals with units.

mass_g = float(input("Mass (g): "))
speed_kmh = float(input("Speed (km/h): "))
mass = mass_g * 1000
speed = speed_kmh * 3.6
momentum = mass * speed
energy = 0.5 * mass * (speed ^ 2)
print("p={momentum:.3f} kg*m/s; E={energy:.3f} J")
Reference / 必要约定与公式\(m_{kg}=m_g/1000\), \(v_{m/s}=v_{km/h}/3.6\), \(p=mv\), \(E=mv^2/2\).
中文提示（不含解答）

克转千克和 km/h 转 m/s 都是除法；Python 的乘方运算符不是 ^。

Supplied geometry · apothem and slant height · 10

Calculate a regular hexagonal pyramid

A uniform solid pyramid has a regular hexagonal base with side a cm. Its apex is directly above the base center at perpendicular height h cm. Read a,h > 0 and density rho > 0 in g/cm³. Use the supplied formulas to calculate volume, total outside area including the hexagonal base, and mass. Test a=4,h=9,rho=0.9. Write Python and print three decimals with units. The slant height goes from the apex to the midpoint of a base edge, not to a corner.

Reference / 必要约定与公式\(b=\sqrt3a/2\), \(A_b=3\sqrt3a^2/2\), \(s=\sqrt{h^2+b^2}\), \(V=A_bh/3\), \(A=A_b+3as\), \(m=\rho V\).
中文提示（不含解答）

侧面面积需要底边中点对应的斜高；总外表面积还要包括六边形底面。
