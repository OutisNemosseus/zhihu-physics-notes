Input/output · thickness and density units · 01

Mass of a triangular sheet

A triangular sheet has base b and perpendicular height h in centimetres, uniform thickness t in millimetres, and material density rho in g/cm³. Read positive b,h,t,rho. Calculate face area in cm², material volume in cm³, and mass in grams. Test b = 18, h = 12, t = 2.5, rho = 2.70. Print three decimals with units. Use the thin-prism model with no material removed.

Reference / 必要约定与公式\(A=bh/2\), \(V=A(t/10)\), \(m=\rho V\).
中文提示（不含解答）

底和垂直高度用来算三角形面积；厚度先从 mm 转成 cm，再乘面积。

Area subtraction · coverage units · 02

Paint a wall around one rectangular opening

A rectangular wall is W metres wide and H metres high. One rectangular opening has width w and height h, also in metres, and lies entirely inside the wall. Read W,H,w,h and paint coverage c in m²/L, assuming all are positive and w < W, h < H. For one coat with no waste allowance, calculate painted area and required paint volume. Test W = 5.2, H = 2.8, w = 1.4, h = 1.1, c = 9. Print both results to three decimals. Do not round up to a can size.

Reference / 必要约定与公式\(A=WH-wh\), \(V_{paint}=A/c\).
中文提示（不含解答）

涂刷面积先扣掉开口；覆盖率是每升能刷多少平方米，因此用面积除以覆盖率。

Composite volume · preserve length units · 03

A square block with a round through-hole

A solid block has square cross section of side a centimetres and length L centimetres. A centered cylindrical hole of diameter d centimetres is drilled along the length through both ends. Assume 0 < d < a and L > 0. Read a,L,d and calculate remaining material volume in cm³ and the fraction of the original volume removed, expressed as a percentage. Test a = 6, L = 10, d = 2. Print three decimals.

Reference / 必要约定与公式\(V_0=a^2L\), \(V_h=\pi(d/2)^2L\), \(V_{left}=V_0-V_h\), \(P=100V_h/V_0\).
中文提示（不含解答）

钻孔的长度等于块体长度；孔的直径要先除以二得到半径。

Right triangle · angle from the floor · 04

Place a ladder from a horizontal offset

A straight ladder of length L metres reaches a vertical wall while its foot is a horizontal distance x metres from the wall. Read L and x with 0 < x < L. Calculate the height reached and the ladder angle above the horizontal floor in degrees. Test L = 5, x = 1.4. Print three decimals. Treat the wall and floor as perpendicular and ignore ladder thickness.

Reference / 必要约定与公式\(h=\sqrt{L^2-x^2}\), \(\theta=\arccos(x/L)\). Use math.acos and math.degrees.
中文提示（不含解答）

已知斜边和邻边；高度由勾股定理得到，反余弦返回的角度再转成度。

Radians and degrees · no automatic wrapping · 05

Read a directed angle in both common units

Read any real angle theta_deg in degrees and convert it to radians and turns. Keep its sign and full accumulated amount; do not reduce it to one turn. Print radians to six decimals and turns to three decimals. Test theta_deg = −225, then theta_deg = 540. Explain why a negative result is valid for a directed angle.

Reference / 必要约定与公式\(\theta_{rad}=\theta_{deg}\pi/180\), \(N=\theta_{deg}/360\).
中文提示（不含解答）

负号表示相反的旋转方向；超过一圈的累计角度也不用截断。

A supplied formula · kPa and Celsius conversions · 06

Estimate gas density with an absolute-temperature model

Use the supplied ideal-gas density model rho = p/(Rs T), where pressure p must be in Pa, absolute temperature T in K, and Rs = 287 J/(kg·K). Read absolute pressure p_kPa > 0 and temperature T_C > −273.15 °C. Calculate density in kg/m³ and g/L. Test p_kPa = 95, T_C = 27. Print four decimals. Explain why Celsius temperature cannot be inserted directly into this formula.

Reference / 必要约定与公式\(p=1000p_{kPa}\), \(T=T_C+273.15\), \(\rho=p/(287T)\). 1 kg/m³ = 1 g/L.
中文提示（不含解答）

压力必须是绝对压强，不是表压；摄氏度先加 273.15，kPa 先乘 1000。

Rearrange a supplied square-root model · 07

Choose a pendulum length from a target period

A small-angle pendulum model gives period T = 2π√(L/g). Read a target period T > 0 in seconds and use g = 9.81 m/s². Calculate the required length in metres and centimetres. Test T = 1.5, then recompute the period from your unrounded length as a check. Print lengths to three decimals; retain full precision in intermediate calculations. Ignore air resistance and amplitude corrections.

Reference / 必要约定与公式\(L=g[T/(2\pi)]^2\), \(T_{check}=2\pi\sqrt{L/g}\).
中文提示（不含解答）

先把给定周期公式解出 L；检验时使用未格式化、未提前取整的数值。

A supplied energy model · efficiency and kWh · 08

Energy needed to raise a load

A lifting device raises mass m kilograms vertically through height h metres at constant speed. Read m > 0, h ≥ 0 and efficiency eta_percent with 0 < eta_percent ≤ 100. Use g = 9.81 m/s². Calculate the load’s gained gravitational energy in J and the input energy required in J and kWh. Test m = 75, h = 8, eta_percent = 60. Print three decimals for joules and six decimals for kWh. Under this model, no other energy changes occur.

Reference / 必要约定与公式\(E_{load}=mgh\), \(E_{input}=E_{load}/(\eta_{percent}/100)\); 1 kWh = 3.6×10⁶ J.
中文提示（不含解答）

效率是有效输出除以输入；反求输入时用有效能量除以效率，而不是再乘一次。

Debugging · numeric input and angle convention · 09

Repair a sloping-distance projection

The program should read positive sloping length L in metres and inclination theta_deg in degrees above the horizontal, with 0 ≤ theta_deg < 90°. It must print horizontal distance and vertical rise in metres to three decimals. Repair all errors and test L = 12, theta_deg = 30.

import math
L = input("Sloping length (m): ")
theta_deg = float(input("Angle above horizontal (deg): "))
horizontal = L * math.sin(theta_deg)
rise = L * math.cos(theta_deg)
print(f"Horizontal: {horizontal:.3f} cm")
print(f"Rise: {rise:.3f} cm")
Reference / 必要约定与公式\(x=L\cos\theta\), \(y=L\sin\theta\); \(\theta=\theta_{deg}\pi/180\).
中文提示（不含解答）

输入要变成数值；相对水平的角度，邻边对应 cos，对边对应 sin；函数需要弧度。

Two-point calibration · solve for the measured quantity · 10

Infer a straight-line sensor conversion

A sensor outputs voltage V that is linear in displacement x. It reads 0.8 V at x = 0 mm and 4.4 V at x = 120 mm. Assume this model is valid only over that range. Read V in [0.8,4.4] and calculate x in mm and metres. Test V = 2.9, then check both endpoint voltages. Print three decimals. Use named variables for the two calibration pairs.

Reference / 必要约定与公式\(x=x_0+(V-V_0)(x_1-x_0)/(V_1-V_0)\), with \((x_0,V_0)=(0,0.8)\), \((x_1,V_1)=(120,4.4)\).
中文提示（不含解答）

先算电压占整个量程的比例，再乘位移量程；最后把 mm 转成 m。
