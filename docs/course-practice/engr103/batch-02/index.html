Input/output · squared and cubed units · 01

An annular mounting plate

A flat annular plate has outer radius ro, inner radius ri, and thickness h, all in millimetres. Write a Python program that reads these values, calculates the area of one flat annular face in mm² and m², and material volume in mm³ and cm³. Assume ro > ri > 0 and h > 0. Test ro = 45, ri = 18, h = 6.

Print labels and units; use three decimal places, except use six decimal places for m². Explain why the inner circular hole is subtracted.

Reference / 必要约定与公式\(A=\pi(r_o^2-r_i^2)\), \(V=Ah\); 1 m = 1000 mm; 1 cm = 10 mm.
中文提示（不含解答）

厚度也以毫米输入；不要把“一个平面面积”和所有表面积混淆。

Geometry · dimensions and units · 02

Packaging a rectangular instrument

Read the internal length, width, and height of a closed rectangular box in inches. Ignore wall thickness. Print its internal volume in in³ and litres, and total interior surface area in in² and m². Test dimensions 12.5 × 8.0 × 3.0 in. Then exchange length and width and explain which results should change.

Reference / 必要约定与公式\(V=LWH\), \(S=2(LW+LH+WH)\); 1 in = 0.0254 m; 1 in³ = 0.016387064 L.
中文提示（不含解答）

同一套几何尺寸要贯穿所有单位；三个维度交换位置不改变体积或表面积。

Consistent units · inverse tangent · 03

Designing a straight ramp

A straight ramp rises h centimetres over a horizontal run d metres. Read h and d as positive decimals. Print the sloping length in metres, slope angle in degrees, and grade as a percentage. Test h = 72 and d = 4.8. State why the rise must first be converted to metres.

Reference / 必要约定与公式\(h_m=h/100\), \(\ell=\sqrt{d^2+h_m^2}\), \(\theta=\arctan(h_m/d)\), \(\text{grade}=100h_m/d\). math.atan returns radians.
中文提示（不含解答）

百分坡度 = 竖直高度/水平距离 × 100%，不是角度本身。

Time conversion · dimensional checks · 04

Timing a survey vehicle

Read a travelled distance D in kilometres and an elapsed time as two separate numbers: whole minutes m and additional seconds s, with 0 ≤ s < 60. Assume total time is positive. Print average speed in m/s, km/h, and miles/hour. Test D = 1.2, m = 2, s = 30. Explain why 2 min 30 s cannot be represented as 2.30 minutes.

Reference / 必要约定与公式\(t=60m+s\), \(v=1000D/t\) in m/s; 1 mile = 1609.344 m; 1 h = 3600 s.
中文提示（不含解答）

先合成总秒数；再用统一的距离与时间单位求速度。

Supplied formulas · solid geometry · 05

A conical funnel section

A hollow funnel section has the shape of a conical frustum. Ignore material thickness and both end faces. Read upper radius R, lower radius r, and vertical height h in centimetres, with R > r > 0 and h > 0. Print enclosed volume in cm³ and litres, and lateral surface area in cm². Test R = 6, r = 2, h = 9.

Use the slant length only in the surface-area formula; include a comment distinguishing slant length from vertical height.

Reference / 必要约定与公式\(s=\sqrt{h^2+(R-r)^2}\), \(V=\frac{\pi h}{3}(R^2+Rr+r^2)\), \(A=\pi(R+r)s\); 1 L = 1000 cm³.
中文提示（不含解答）

本题不计两个端面；体积式中的 h 是竖直高度。

math.asin · radians · geometric model · 06

An open belt around two pulleys

Two pulleys of radii r1 and r2 have centre separation C, all in cm. An open, uncrossed belt is taut around them. Assume r1 > 0, r2 > 0, r1 ≠ r2, and C > r1 + r2 so the pulleys do not overlap. Neglect belt thickness and assume no slip. Using the exact length formula below, write a program that reads the three inputs and prints belt length in cm and metres. Test r1 = 4, r2 = 7, C = 24.

Explain why an angle returned by math.asin must remain in radians when used in the length formula.

Reference / 必要约定与公式Let \(d=|r_2-r_1|\). \(L=2\sqrt{C^2-d^2}+\pi(r_1+r_2)+2d\arcsin(d/C)\).
中文提示（不含解答）

先令 d 为两半径之差的绝对值。弧长公式中的角度必须为弧度。

Pressure · absolute temperature · 07

Gas volume with SI conversion

For an ideal gas, read amount n in mol, pressure p in bar, and temperature TC in degrees Celsius. Assume n > 0, p > 0, and TC > −273.15. Calculate volume in m³ and litres. Test n = 0.50, p = 1.20, TC = 25.0. Print six decimal places for m³ and three for litres.

State why substituting Celsius directly into the gas equation is invalid.

Reference / 必要约定与公式\(pV=nR_gT\), \(R_g=8.314462618\;\mathrm{Pa\,m^3/(mol\,K)}\); \(T=T_C+273.15\); 1 bar = 100000 Pa; 1 m³ = 1000 L.
中文提示（不含解答）

先把压强转 Pa、温度转 K；公式中的温度为绝对温度。

Angular and tangential speed · 08

Pulley speed from revolutions per minute

A pulley of radius r cm rotates at N revolutions per minute. Read r and N, both positive. Print angular speed in rad/s and rim speed in m/s. Test r = 8.0, N = 450.0, then keep N fixed and double r. Which output should double and which should remain unchanged?

Reference / 必要约定与公式\(\omega=2\pi N/60\), \(v=\omega(r/100)\).
中文提示（不含解答）

角速度与半径无关；线速度要使用米制半径。

Tracing · degree/radian mistakes · 09

Debug an angle-dependent area

The program intends to read two sides in cm and their included angle in degrees, then print the triangle area in square inches. Assume valid positive side lengths and an angle between 0° and 180°. Identify and fix all errors affecting that task, then test a = 8, b = 5, γ = 30°.

import math
a = input("First side in cm: ")
b = float(input("Second side in cm: "))
gamma = float(input("Included angle in degrees: "))
area_cm2 = a * b * math.sin(gamma)
area_in2 = area_cm2 / 2.54
print("Area:", area_in2, "in")
Reference / 必要约定与公式\(A=\frac12ab\sin\gamma\); 1 in = 2.54 cm; \(\gamma_{rad}=\pi\gamma_{deg}/180\).
中文提示（不含解答）

检查输入类型、三角函数角度、公式系数、面积换算与单位标签。

Engineering model · percent to fraction · 10

Heating time and efficiency

A heater warms a uniform metal block. Read mass m in kg, specific heat c in J/(kg·°C), initial and final temperatures Ti and Tf in °C, electrical power P in watts, and efficiency eta_percent in percent. Assume m > 0, c > 0, Tf > Ti, P > 0, and 0 < eta_percent ≤ 100; neglect heat loss beyond this efficiency model.

  1. Print required thermal energy in joules and electrical energy in kilojoules.
  2. Print heating time in seconds and minutes.
  3. Test m = 1.8, c = 900, Ti = 18, Tf = 68, P = 500, eta_percent = 80. Explain why using 80 instead of 0.80 in the equation gives the wrong result.
Reference / 必要约定与公式\(\eta=\eta_{percent}/100\), \(Q=mc(T_f-T_i)\), \(E=Q/\eta\), \(t=Q/(\eta P)\); 1 W = 1 J/s.
中文提示（不含解答）

先区分热量 Q 与耗电能 E；温差用摄氏度差或开尔文差得到同一数值。
