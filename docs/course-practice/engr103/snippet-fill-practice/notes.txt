 Quick reference for functions and plotting Download the reference notes Task Usage Evenly spaced samples including both endpoints np.linspace(start, stop, num) . num is the number of points. Grid for a function of two variables X,Y=np.meshgrid(x,y) . The default shape is (len(y), len(x)), with rows for y and columns for x. One parameter for a space curve x(t), y(t), and z(t) are 1D arrays of equal length. Use them directly. Two side-by-side 3D axes fig=plt.figure(); ax1=fig.add_subplot(121,projection="3d"); ax2=fig.add_subplot(122,projection="3d") Space curve and viewing angle ax.plot(x,y,z); ax.view_init(elev=35,azim=-130) . Angles are in degrees. 2D contour lines p=ax.contour(X,Y,Z,levels=levels,cmap="jet") . Use contourf to fill the regions. Specify contour levels levels=np.linspace(-1,1,21) gives 21 boundaries and 20 filled intervals. An integer level count uses an automatic locator, so the number of lines may vary. Color bar fig.colorbar(p,ax=ax) . Pass the plot object as p and its axes as ax. Wireframe and surface plots ax.plot_wireframe(X,Y,Z,rstride=4,cstride=4) / ax.plot_surface(X,Y,Z,cmap="jet"). 3D contours and projection onto a plane Use contour on 3D axes. To project onto a plane, add zdir="z",offset=-1.5  and include the plane in the z-axis limits. Labels and final output ax.set(xlabel="x [in]",ylabel="y [in]",zlabel="z"); fig.tight_layout(); fig.savefig("plot.png",dpi=150); plt.show() tight_layout adjusts subplot spacing to reduce label overlap. savefig saves the figure and show displays it. Use ** for exponentiation. In Python, ^ means bitwise XOR.
