HW 1 · amplitude, frequency, timing · 01

Read a sinusoid

Let \(v(t)=6\cos(400\pi t-\pi/3)\;\mathrm V\), where t is in seconds.

  1. Find amplitude, angular frequency (rad/s), frequency (Hz), period (ms), and phase (degrees).
  2. Find the first maximum at or after t = 0 and the first minimum at or after t = 0.
  3. Plot v against t from 0 to 15 ms using a spreadsheet or plotting tool. Label axes, units, title, and mark those extrema.
Reference / 必要约定与公式\(\omega=2\pi f\), \(T=1/f\); cosine maxima have phase \(2\pi n\), minima \((2n+1)\pi\).
中文提示（不含解答）

先确定角频率；解相位条件后再把秒换成毫秒。

HW 1 · reference convention · 02

Sine, cosine, and delay

Let \(x(t)=4\sin(1000t+\pi/6)\;\mathrm V\). Use cosine-reference, peak-amplitude phasors.

  1. Rewrite x(t) as a cosine with a phase in degrees; state its phasor.
  2. A new signal is y(t) = x(t − 0.0008). Find its cosine-reference phasor and time-domain expression.
  3. State whether y is delayed or advanced, and give the phase difference in radians and degrees.
Reference / 必要约定与公式\(\sin\theta=\cos(\theta-\pi/2)\); a delay \(t_d\) contributes phase \(-\omega t_d\).
中文提示（不含解答）

时间平移使用秒；给相量统一采用余弦、峰值约定。

HW 1 · rectangular ↔ polar · 03

Complex arithmetic with quadrants

For \(z_1=3-4j\) and \(z_2=-2+2j\), compute each result in rectangular and polar form:

  1. \(z_1\) and \(z_2\)
  2. \(z_1+z_2\)
  3. \(z_1z_2\)
  4. \(z_1/z_2\)

Give principal angles in (−180°, 180°] and explain how you checked each quadrant.

Reference / 必要约定与公式\(j^2=-1\), \(|a+jb|=\sqrt{a^2+b^2}\), \(\arg(a+jb)=\operatorname{atan2}(b,a)\).
中文提示（不含解答）

atan2 的两个参数顺序要核对；普通 arctan 不会自动识别象限。

HW 1 · phasor sum · 04

Add same-frequency signals

Find a single cosine expression for \(v(t)=8\cos(2000t+\pi/6)+6\sin(2000t+\pi/3)\;\mathrm V\).

  1. Convert both terms to peak, cosine-reference phasors.
  2. Add in rectangular form, then return to polar form and the time domain.
  3. Check the original expression and your result at t = 0 and t = 0.0005 s. Keep at least four significant digits internally.
Reference / 必要约定与公式\(A\angle\phi=A(\cos\phi+j\sin\phi)\); \(\sin\theta=\cos(\theta-\pi/2)\).
中文提示（不含解答）

只有角频率相同才能直接相加；先把 sin 统一为 cos。

HW 1 · subtraction and geometry · 05

A scaled phasor diagram

At a common angular frequency \(\omega=500\;\mathrm{rad/s}\), let \(V_1=5\angle0^\circ\;\mathrm V\) and \(V_2=5\angle120^\circ\;\mathrm V\).

  1. Compute \(V_1+V_2\) and \(V_1-V_2\) in rectangular and polar form.
  2. Draw two separate tip-to-tail diagrams on equal-scale real/imaginary axes, with values in volts. For subtraction draw −V₂ explicitly.
  3. Write the two resulting cosine waveforms using peak amplitudes.
Reference / 必要约定与公式\(V_1-V_2=V_1+(-V_2)\). All phases are cosine-reference peak phases.
中文提示（不含解答）

减法是加上反向向量；实轴和虚轴应使用相同尺度。

HW 2 · impedance and steady state · 06

A series RLC circuit

The original circuit below has \(v_s(t)=10\cos(1000t+\pi/9)\;\mathrm V\), R = 30 Ω, L = 20 mH, C = 100 μF. The clockwise current i(t) leaves the positive source terminal.

  1. Draw the phasor-domain circuit, labeling the source phasor and all three impedances.
  2. Find total impedance and current phasor, in rectangular and polar forms.
  3. Write steady-state i(t). Check KVL using the three component voltage phasors.
  4. Optional LTspice check: use matching sine-source phase, allow startup transients to settle, and compare current at two distinct times in a late cycle. State the current reference direction.
Reference / 必要约定与公式\(Z_R=R,\ Z_L=j\omega L,\ Z_C=1/(j\omega C)\); \(I=V_s/(Z_R+Z_L+Z_C)\).
中文提示（不含解答）

毫亨、微法先转成 SI；相量幅值全部用峰值。

HW 2 · series and parallel · 07

Reduce a mixed network

Find the equivalent impedance seen between terminals A and B at \(\omega=500\;\mathrm{rad/s}\). R₁ = 8 Ω is in series with two parallel branches: R₂ = 12 Ω, and the series pair R₃ = 4 Ω with L = 12 mH. All connections are shown below.

  1. Redraw one reduction step at a time.
  2. Give ZAB in rectangular and polar form.
  3. Without recomputing every step, determine whether the equivalent network is inductive or capacitive, and justify using the sign of its imaginary part.
Reference / 必要约定与公式\(Z_a\parallel Z_b=Z_aZ_b/(Z_a+Z_b)\); \(Z_L=j\omega L\).
中文提示（不含解答）

并联的是完整支路 R₃ + jωL；不要把三个电阻误当串联。

HW 2 · admittance and node voltage · 08

A current-driven node

An ideal current source \(i_s(t)=0.060\cos(2000t-\pi/6)\;\mathrm A\) injects current from ground into node A. A 100 Ω resistor and a 5 μF capacitor both connect from A to ground. Define vA positive at A relative to ground; define branch currents downward.

  1. Draw the impedance-domain circuit.
  2. Use KCL to find VA and the resistor and capacitor current phasors.
  3. Write steady-state vA(t) and verify that the two branch-current phasors sum to Is.
Reference / 必要约定与公式\(Y_R=1/R,\ Y_C=j\omega C\); \(I_s=(Y_R+Y_C)V_A\).
中文提示（不含解答）

电流源箭头向上，支路电流向下；先写导纳会更简洁。

HW 2 · impedance divider · 09

A capacitor-output divider

In the circuit, \(v_s(t)=12\cos(500t)\;\mathrm V\), R = 40 Ω, C = 50 μF. The output vo is the capacitor voltage, positive at the upper terminal.

  1. Find the source current phasor and output-voltage phasor.
  2. Write vo(t) and state whether it leads or lags the source.
  3. Predict vo at t = 0 and t = 2 ms. If using LTspice, compare after transients decay at corresponding phases in a late cycle; do not compare startup directly to steady state.
Reference / 必要约定与公式\(V_o=V_s\,Z_C/(R+Z_C)\), \(Z_C=1/(j\omega C)\).
中文提示（不含解答）

输出跨接在哪个元件，分压分子就用哪个阻抗。

HW 2 · multistep synthesis · 10

Divider with a parallel load

An ideal source \(v_s(t)=15\cos(1000t-\pi/6)\;\mathrm V\) drives a 20 Ω series resistor R₁. At node A, a 60 Ω resistor R₂ and a 30 mH inductor connect in parallel to ground. Define vo = vA and source current from the source through R₁.

  1. Reduce the parallel load to Zp, then find total input impedance.
  2. Find the source current and output voltage phasors, and write vo(t).
  3. Find both load branch currents and check KCL at A.
  4. Specify two different times within one steady-state period for a numerical hand-calculation versus simulation check. Label the plotted voltage/current axes and units.
Reference / 必要约定与公式\(Z_p=R_2\parallel j\omega L\); \(V_o=V_sZ_p/(R_1+Z_p)\).
中文提示（不含解答）

先算并联负载，再阻抗分压；最后用 KCL 做独立检查。
