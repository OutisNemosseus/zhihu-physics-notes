Ideal Transformer and Reflected Load Impedance

An ideal, lossless transformer has turns ratio Nₚ/Nₛ = 3.00. A 120∠0° V RMS ideal source is connected directly across the primary. The secondary supplies ZL = 8 + j6 Ω at the operating frequency. Ignore magnetizing current, leakage impedance and winding resistance. Both voltage references run from the dotted terminal to the undotted terminal.

Show your work. Use the transformer voltage and current ratios to derive the input impedance. Calculate load power on the secondary and verify the same real power enters the primary. State on paper whether the source power factor is leading or lagging. Enter numerical answers to three significant figures.

令 a = Nₚ/Nₛ = 3，初级电流 Iₚ 定义为流入初级点端，次级负载电流 Iₛ 定义为流出次级点端。理想变压器满足 Vₚ = aVₛ、Iₚ = Iₛ/a。因此 Zin = Vₚ/Iₚ = a²Vₛ/Iₛ = a²ZL。

  1. Zin = 9(8 + j6) = 72 + j54 Ω，实部为 72.0 Ω。
  2. 输入阻抗虚部为 +54.0 Ω，保持感性。
  3. |Zin| = √(72² + 54²) = 90 Ω，故 |Iₚ| = 120/90 = 4/3 ≈ 1.33 A RMS。
  4. 次级电压 Vₛ = 120/3 = 40 V RMS。|ZL| = 10 Ω，故 |Iₛ| = 40/10 = 4 A。PL = |Iₛ|² × 8 = 128 W。初级检查，Pin = |Iₚ|² × 72 = (4/3)² × 72 = 128 W。
  5. 源看到的功率因数是 Re(Zin)/|Zin| = 72/90 = 0.800 lagging。输入阻抗乘以正数 a² 后相角保持不变。

原创题，参考 OSU ENGR 202 · Kyle Webb 第 5 节的理想变压器、电压电流比与功率关系。
