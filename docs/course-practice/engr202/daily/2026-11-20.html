Design a Low-Pass Filter with Source Resistance

Design the RC low-pass circuit below for a 1.00 kHz cutoff, measured from the ideal source Vₛ to Vout. The source has a fixed series resistance Rₛ = 500 Ω and the capacitor is C = 100 nF. The output is unloaded. All components are ideal except for the explicitly shown source resistance.

The available resistor values are 820 Ω, 1.00 kΩ, 1.10 kΩ, 1.20 kΩ, and 1.50 kΩ. Choose the value nearest to the ideal calculated R. Use the chosen resistor for parts (c)–(e).

Show your work. Derive H(jω) = Vout/Vₛ, calculate the ideal resistor, and show the magnitude and phase substitutions at 1.00 kHz. Enter numerical answers to three significant figures.

展开中文推导

电容前面串联着 Rₛ 和 R。分压关系为 H(jω) = [1/(jωC)]/[Rₛ + R + 1/(jωC)] = 1/[1 + jω(Rₛ + R)C]。低频增益趋近 1 V/V。

  1. fc = 1/[2π(Rₛ + R)C]，所以 R = 1/(2πfcC) − Rₛ = 1591.55 − 500 ≈ 1.09 × 10³ Ω。
  2. 理想 R 约为 1091.55 Ω，给定列表中最接近的是 1100 Ω。
  3. 此时总串联电阻是 500 + 1100 = 1600 Ω，实际 fc = 1/[2π(1600)(100×10⁻⁹)] ≈ 995 Hz。
  4. 1.00 kHz 时，ω(Rₛ + R)C = 2π(1000)(1600)(100×10⁻⁹) ≈ 1.00531。|H| = 1/√(1 + 1.00531²)，故 |Vout| = 2.00|H| ≈ 1.41 V RMS。
  5. 相位为 −arctan[ω(Rₛ + R)C] ≈ −45.2°，输出滞后理想源电压。
