Identify a Capacitor from Scope Measurements

The circuit contains an ideal unknown capacitor and a 1.00 kΩ resistor. At angular frequency ω = 1000 rad/s, the input voltage is Vᵢₙ = √20∠0° V RMS. The scope shows that the output lags the input by arctan(1/2) = 26.565051…° and that |Vout|/|Vin| = 2/√5. The measuring instruments do not load the circuit.

Show your work. Write the complex voltage-divider equation and use it to find C. Give numerical answers to three significant figures. Use the input voltage as the phase reference at each frequency.

展开中文推导

由串联分压，H(jω) = ZC/(R + ZC) = 1/(1 + jωRC)。其相角是 −arctan(ωRC)。测得输出滞后 arctan(1/2)，所以 ωRC = 1/2。

  1. |Vout| = |Vin| × |H| = √20 × 2/√5 = 4.00 V RMS。
  2. ωRC = 1/2，故 1/(ωC) = 2R = 2000 Ω。电容阻抗是 −j/(ωC) = −j2000 Ω，虚部为 −2.00 × 10³ Ω。
  3. C = (1/2)/(ωR) = 0.5/(1000 × 1000) F = 500 nF。
  4. ωc = 1/(RC) = 2000 rad/s，故 fc = 2000/(2π) ≈ 318 Hz。
  5. 测量频率加倍后，ω′ = 2000 rad/s，恰好等于 ωc。此时 H = 1/(1 + j)，相角为 −45°。

幅值也可独立验证，|H| = 1/√[1 + (ωRC)²] = 1/√(1.25) = 2/√5。
