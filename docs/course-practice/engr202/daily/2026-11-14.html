Recovering Load Impedance from Meter Readings

An ideal 60 Hz sinusoidal source drives an unknown two-terminal load in steady state. The measured load voltage is 120 V RMS, the measured current is 10.0 A RMS, and an ideal wattmeter reads 960 W absorbed by the load. The current lags the voltage. Use the source voltage as the 0° reference and the current direction shown.

Show your work. On paper, write the complex power and impedance relationships you use. Enter each answer to three significant figures.

展开中文推导
  1. 先算视在功率的大小 |S| = VRMSIRMS = 120 × 10.0 = 1200 VA。功率因数是 P/|S| = 960/1200 = 0.800，电流滞后。
  2. 由 |S|² = P² + Q²，得到 |Q| = √(1200² − 960²) = 720 var。电流滞后，负载为感性，所以 Q = +720 var。
  3. 对负载使用被动符号约定，S = V I* = Z|I|²。取实部，R = P/|I|² = 960/100 = 9.60 Ω。
  4. 取虚部，X = Q/|I|² = 720/100 = +7.20 Ω。因此 Z = 9.60 + j7.20 Ω。
  5. 阻抗相角 arctan(7.20/9.60) ≈ +36.87°。由 I = V/Z，电压以 0° 为参考，电流相位是 −36.9°。
