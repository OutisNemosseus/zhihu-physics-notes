When the Shunt Capacitor Is Too Large

A 120∠0° V RMS, 50 Hz ideal source supplies a load with impedance Zload = 9 + j9 Ω. An ideal capacitor is connected in parallel with the load. Its capacitance is C = 7/(7200π) F ≈ 309.47 μF. Use the exact value of C in your calculations. The current Iₛ flows from the source into the parallel combination.

Show your work. Find the load and capacitor currents separately, then use KCL to find Iₛ. Write the total complex power and state on paper whether the final power factor is leading or lagging. Enter answers to three significant figures.

展开中文推导

先求负载电流。Iload = 120/(9 + j9) = 20/3 − j20/3 A。电容电流 IC = jωCV = j(100π)[7/(7200π)](120) = j35/3 A。根据 KCL，Iₛ = Iload + IC = 20/3 + j5 A。

  1. 复功率使用 RMS 相量和电流的复共轭，S = VₛIₛ* = 120(20/3 − j5) = 800 − j600 VA。实部为 P = 800 W。理想电容的平均功率是零。
  2. 总无功功率为复功率虚部，Q = −600 var。负载原本吸收 +800 var，电容贡献 −1400 var，合计为 −600 var。
  3. 由刚才的 KCL，电源电流虚部为 +5.00 A。
  4. |Iₛ| = √[(20/3)² + 5²] = 25/3 ≈ 8.33 A。
  5. ∠Iₛ = arctan[5/(20/3)] = arctan(3/4) ≈ +36.9°，电流超前电压。
  6. |S| = 120 × (25/3) = 1000 VA，所以 PF = P/|S| = 800/1000 = 0.800 leading。电容提供的容性无功超过原负载的感性无功，形成过补偿。
