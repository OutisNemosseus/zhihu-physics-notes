Loaded RL Low-Pass Filter

An ideal sinusoidal source drives the circuit below. The 240 Ω resistor RL is an external load that can be removed, leaving an open branch. The other 240 Ω resistor R remains connected. Define H(jω) = Vout/Vs.

Show your work. Write the loaded transfer function on paper. Enter the answers below to three significant figures. For each configuration, define cutoff relative to its own low-frequency passband gain.

展开中文推导
  1. 接上负载后，输出端的电阻为 R ∥ RL = 240 ∥ 240 = 120 Ω。用分压公式得 H(jω) = 120/(120 + 120 + jω·0.040) = 120/(240 + jω·0.040)。令 ω = 0，通带增益为 0.500 V/V。
  2. 当电感电抗 ωL 等于分母的实部 240 Ω 时，分母幅值变为低频时的 √2 倍。因此 fc = 240/[2π(0.040)] = 955 Hz。
  3. 截止点的增益幅值为 0.500/√2。相对 1 V/V 的增益是 20 log₁₀(0.500/√2) = −9.03 dB，比通带的 −6.02 dB 低约 3.01 dB。
  4. 截止点分母为 240 + j240，相角为 +45°。分子相角为 0°，所以输出相位为 −45°。
  5. 移除 RL 后，输出仍跨在 R = 240 Ω 上，分母变成 360 + jω·0.040。新的截止频率为 360/[2π(0.040)] ≈ 1.43 × 10³ Hz。
