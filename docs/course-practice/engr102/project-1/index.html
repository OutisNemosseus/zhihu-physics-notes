使用与提交

  1. 下载 Excel，在 Microsoft Excel 中打开。
  2. 在 Invoicing 页黄色单元格选择家具编号并输入正整数数量；删除订单行时清空两格。
  3. 查看金额、运费以及 Materials 页的木板数量与 board-feet 是否随订单更新。
  4. 演示前向 Canvas 提交 .xlsx，现场打开 Excel 演示并解释负责部分。

工作簿保留两件银色书架的示例订单。部分切板尺寸采用简化假设，见 Catalog Data 页的说明；不作为实际加工图。

运费算术更正：67.8 lb 按规则为 $12 + 40 × $0.25 + 27.8 × $0.20 = $27.56。
