模型怎样评分？

四轮按左侧两轮、右侧两轮联动。平均 PWM 固定为 25，配平 u = (左−右)/2。用直线拟合 H2 到 H4 的净转角 = a + b × u。在每组内重采样试跑、重新拟合，再加入一次实测残差；每个候选重复 1,000 次，比较预测净转角绝对值的平均数。只比较采过数据的配平范围内的整数 PWM。终点命中单独显示，净转角小仍可能整车偏离中心。此模型没有各轮编码器数据，无法分别辨认四个电机增益或侧滑。

为什么还要一条短纵胶带？

从下往上看。两幅图都画了同一辆车在两个时刻的位置。黄色表示探头读到黑胶带。

中探头压住短纵带时读到 010。轻微偏移也可能只有左或右探头亮；偏得更远才会出现图右的 000。

实车怎样采集一组数据

  1. 一次布场。从下往上编号 H1–H4。在左列白地中央对准 H1 摆车，三探头压线亮 111。在 H4 后方留一小段白地，再沿车道中心贴短纵胶带，用来检测终点横向偏移。
  2. 每趟起跑。使用下方固件，电池供电，摆回同一起点后按 RST。等待 2.5 秒，车以恒定 PWM 前进。在白地读到 000 属于正常情况。每趟起点需要人工复位。
  3. 自动记录。约每 0.5 ms 采样三个探头。先离开起跑线，再分别记录 H2、H3、H4 的左、中、右触线时刻。过 H4 后寻找目标带上的 010，命中或到达搜索时限即停车。超时、触线不完整均单独记录。
  4. 自动选参数。左右 PWM 依次试 25/25、23/27、27/23，轮换直到每组有 3 趟完整数据。每趟取三条线的左右触线时间差绝对值的中位数，再比较各组三趟的中位数。选最小者，再跑 10 趟完整验证，同时统计终点带命中数。
  5. 回传。测试后用 USB 连接 Pico W，在 115200 串口发送 D 导出 CSV。文件内含 PWM、运行状态、目标命中及 9 个微秒时间戳；未检测到的时间记作 0。过线时间与终点命中分别反映当时的姿态和终点位置。
