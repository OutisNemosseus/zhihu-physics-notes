Module 1 · statements and variables · 01

What counts as a proposition?

For each item, say whether it is a proposition as written. For propositions, state the truth value; for non-propositions, explain what prevents a truth value.

  1. 17 is an odd integer.
  2. Please close the laboratory door.
  3. \(x+2=7\), where x has not been assigned a value or quantified.
  4. Every square has four sides.
中文提示（不含解答）

命题必须是具有确定真假的陈述句；开放变量还需要赋值或量词。

Module 1 · connectives · 02

Translate a laboratory rule

Let p mean “The sensor is powered,” q mean “The cable is connected,” and r mean “A reading is recorded.” Translate each statement into propositional symbols. Use inclusive “or.”

  1. The sensor is powered and the cable is not connected.
  2. If both the sensor is powered and the cable is connected, a reading is recorded.
  3. A reading is recorded only if the sensor is powered.
  4. Either the cable is connected or the sensor is powered, but not both.
Reference / 必要约定与公式\(\neg\) = not; \(\land\) = and; \(\lor\) = inclusive or; \(\to\) = implies.
中文提示（不含解答）

“A only if B” 的方向是 A → B；注意 exclusive 与 inclusive or。

Module 1 · conditional equivalence · 03

A full truth table

Construct a truth table for \((p\to q)\leftrightarrow(\neg q\to\neg p)\). Include columns for each conditional and for the biconditional. Classify the final statement as a tautology, contradiction, or contingency.

Use the row order (T,T), (T,F), (F,T), (F,F).

Reference / 必要约定与公式\(p\to q\) is false only when p is true and q is false. A biconditional is true when both sides have the same truth value.
中文提示（不含解答）

不要只写最终一列；两边条件句分别计算。

Module 1 · equivalence · 04

De Morgan and a compound negation

Negate \((p\lor q)\land\neg r\), then simplify until every negation applies only to an individual variable. Show one equivalence at each step.

Check your result at p = F, q = T, r = T and at p = F, q = F, r = F.

Reference / 必要约定与公式\(\neg(A\land B)\equiv\neg A\lor\neg B\); \(\neg(A\lor B)\equiv\neg A\land\neg B\); \(\neg\neg A\equiv A\).
中文提示（不含解答）

对整个式子先加外层否定，再逐层使用德摩根律。

Module 1 · implication directions · 05

Converse, inverse, contrapositive

Start with: “If an integer is divisible by 8, then it is divisible by 4.”

  1. Write the converse, inverse, and contrapositive in words.
  2. Over the integers, determine which of the four statements are true. Give a counterexample for each false statement.
  3. Identify which statement is logically equivalent to the original, independent of this particular arithmetic example.
Reference / 必要约定与公式For \(p\to q\): converse \(q\to p\); inverse \(\neg p\to\neg q\); contrapositive \(\neg q\to\neg p\).
中文提示（不含解答）

反例必须让前件为真、后件为假；数值 0 也是整数。

Module 1 · truth-table validity · 06

Does the conclusion follow?

A device obeys these premises: “If the battery is charged, the indicator lights” and “The indicator lights.” Someone concludes “The battery is charged.” Let p = battery charged and q = indicator lights.

  1. Symbolize both premises and the conclusion.
  2. Use a truth table or a single assignment to test whether the conclusion follows.
  3. Repeat the test when the second premise is instead “The indicator does not light” and the conclusion is “The battery is not charged.”
Reference / 必要约定与公式An argument is valid exactly when no truth assignment makes all premises true and its conclusion false.
中文提示（不含解答）

检验是否存在“所有前提真、结论假”的一行。

Module 1 · quantifier truth values · 07

Predicates over a finite domain

Let the domain be \(D=\{-2,-1,0,1,2\}\). Define \(P(x):x^2\le1\) and \(Q(x):x>0\). Determine each truth value and justify with a witness or counterexample where appropriate.

  1. \(\forall x\in D\;P(x)\)
  2. \(\exists x\in D\;[P(x)\land Q(x)]\)
  3. \(\forall x\in D\;[Q(x)\to P(x)]\)
  4. \(\exists x\in D\;[\neg P(x)\land\neg Q(x)]\)
中文提示（不含解答）

全称假需一个反例；存在真需一个见证，且必须来自给定论域。

Module 1 · quantifier negation · 08

Negate nested quantifiers

The domain of s is students in a class; the domain of b is books on a reading list. Let R(s,b) mean “student s has read book b.”

  1. Translate \(\forall s\,\exists b\,R(s,b)\) into plain English.
  2. Negate that formula and move the negation all the way to R.
  3. Translate \(\exists b\,\forall s\,R(s,b)\) and its fully simplified negation into English.
  4. Explain why the two original formulas make different claims.
Reference / 必要约定与公式\(\neg\forall x\,P\equiv\exists x\,\neg P\); \(\neg\exists x\,P\equiv\forall x\,\neg P\).
中文提示（不含解答）

量词顺序有意义：“每人有一本”不一定是“大家同一本”。

Module 1 · nested quantifiers and domain · 09

Order matters

For each formula, decide whether it is true and give a proof using a choice of witness, or a counterexample. First use the domain of all real numbers, then repeat over all integers.

  1. \(\forall x\,\exists y\;(y>x)\)
  2. \(\exists y\,\forall x\;(y>x)\)
  3. \(\forall x\,\exists y\;(2y=x)\)
中文提示（不含解答）

见证允许依赖外层变量；整数论域中，除以 2 不一定仍是整数。

Module 1 · integrated truth-table test · 10

A three-variable inference

Analyze the formula \(\bigl[(p\to q)\land(q\to r)\bigr]\to(p\to r)\).

  1. Build all eight truth-table rows in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Include columns for both premises, their conjunction, the conclusion, and the full conditional.
  2. Classify the full formula.
  3. Explain in plain English what this says about a chain of two implications. Does the result require p to be true?
Reference / 必要约定与公式For any A, B, \(A\to B\equiv\neg A\lor B\).
中文提示（不含解答）

完整条件式和单独的结论不是同一列；前提不同时为真时也要正确处理。
