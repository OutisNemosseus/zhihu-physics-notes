1. Rewrite a compound conditional

If the alarm is armed or the guard is present, then the east gate is locked and the camera is recording. Here ‘or’ is inclusive. Treat this as propositional logic. Rewrite the entire conditional in each requested form, preserving its meaning. Do not assume the converse.

  1. Use ‘whenever’.
  2. Use ‘only if’.
  3. Use ‘sufficient’.
  4. Use ‘necessary’.
  5. Use ‘unless’.

2. Converse, contrapositive, and inverse

Let p, q, and r be propositions. I: (¬p ∨ q) → (p ∧ r); II: (p ∧ q) → (¬q ∨ r); III: (¬p ∧ ¬r) → (q ∨ r). Simplify negations using De Morgan’s laws and double negation.

  1. I: converse
  2. I: contrapositive
  3. I: inverse
  4. II: converse
  5. II: contrapositive
  6. II: inverse
  7. III: converse
  8. III: contrapositive
  9. III: inverse

3. Negate a quantified statement

Let D be an arbitrary nonempty domain, and R, S arbitrary binary predicates on D. All quantifiers range over D. Which option is logically equivalent to the negation of ∃x ∀y [R(x,y) → ∃z (S(y,z) ∧ ¬R(x,z))]?

  1. ∀x ∀y [R(x,y) ∧ ∀z (¬S(y,z) ∨ R(x,z))]
  2. ∀x ∃y [R(x,y) ∧ ∀z (¬S(y,z) ∨ R(x,z))]
  3. ∀x ∃y [R(x,y) ∧ ∀z (¬S(y,z) ∧ R(x,z))]
  4. ∀x ∃y [¬R(x,y) ∨ ∀z (¬S(y,z) ∨ R(x,z))]
  1. Enter the letter of the correct option.

4. Classify compound propositions

Let p, q, and r be arbitrary propositions. Classify each expression as a tautology, a contradiction, or a contingency. Here ↔ is the biconditional and → is material implication.

  1. (p → q) ∨ (q → p)
  2. [(p → q) ∧ (p → ¬q)] → ¬p
  3. [(p ∨ q) ∧ ¬(p ∧ q)] ↔ (p ↔ q)
  4. [(p → q) ∧ (q → r)] ∧ ¬(p → r)
  5. [(p → q) ∧ (q → p)] → r

5. Translate relational statements

The domain is all files in a fixed nonempty collection. R(x,y) means ‘file x refers to file y’. Equality has its usual meaning; self-references are allowed. Translate using R, equality, quantifiers, and logical connectives.

  1. Every file that refers to itself is referred to by some different file.
  2. Some file refers to every other file and does not refer to itself.
  3. For every two different files, some file refers to both of them and to no other files.

6. Integer truth sets

The free variable x ranges over all integers ℤ. Each bound variable has the finite range written beside its quantifier. List each truth set in roster notation; use ∅ if empty. The inequality a < b ≤ c means both a < b and b ≤ c.

  2. ∀y ∈ {−1, 1} ∃z ∈ {−2, −1, 0, 1, 2}: x = 2y + z
  3. ∃y ∈ {−1, 1} ∀z ∈ {−1, 0, 1}: z < x + y ≤ z + 4

7. Membership versus inclusion

Treat 1 as an atomic object, not a set. Let X = {1, {1}}, Y = {∅, {1}, X}, and Z = {Y, {∅}, {{1}}}. Enter True or False. The symbol ⊆ allows equality.

  1. ∅ ∈ Y
  2. ∅ ⊆ Z
  3. {∅} ⊆ Y
  4. {∅} ⊆ Z
  5. {1} ∈ Y
  6. {{1}} ⊆ Y
  7. {{1}} ∈ Y
  8. {{1}} ∈ Z
  9. X ⊆ Y
  10. Y ⊆ Z
  11. {Y} ∈ Z
  12. {Y} ⊆ Z

8. Eight Venn regions

Let U = {−6, −5, …, 9}. Define A = {n ∈ U : n² ≤ 16}, B = {n ∈ U : n is even}, and C = {n ∈ U : |n − 2| ≤ 4}. Here |a| denotes absolute value. List the elements in each region. Complements are relative to U.

  1. A ∩ Bᶜ ∩ Cᶜ
  2. Aᶜ ∩ B ∩ Cᶜ
  3. Aᶜ ∩ Bᶜ ∩ C
  4. A ∩ B ∩ Cᶜ
  5. A ∩ Bᶜ ∩ C
  6. Aᶜ ∩ B ∩ C
  7. A ∩ B ∩ C
  8. Aᶜ ∩ Bᶜ ∩ Cᶜ

9. Equivalent set expression

Let A, B, C be arbitrary subsets of a universal set U. Complements are relative to U; ∖ denotes set difference. Let E = ((A ∪ B) ∩ (B ∩ Cᶜ)ᶜ) ∖ (A ∖ (B ∖ C)).

  1. B ∩ C
  2. A ∩ B ∩ C
  3. (B ∩ C) ∖ A
  4. (A ∩ C) ∖ B
  1. Select the one option that equals E for every choice of A, B, and C.

12. Nested sets and Cartesian products

Let A = {∅,{∅}}, B = {∅,{∅},{{∅}}}, C = {∅,A,B,{B}}, and D = {∅,A,B}. Cartesian products use ordered pairs; named sets may be left unexpanded inside pairs. Candidates in the last two parts are ∅, A, B, C, D.

  1. Find |A|.
  2. Find |B|.
  3. Find |C|.
  4. Find |D|.
  5. Find |A × A| and list every element of A × A.
  6. Find |A × D| and list every element of A × D.
  7. Which candidate sets are elements of C?
  8. Which candidate sets are subsets of C? Include C itself if appropriate.

16. Translate statements about people

The domain is all members of a book club. P(x) means x is a poet; E(x) means x is an editor; T(x,y) means x trusts y. Constant m denotes Mira. Do not assume poet and editor are disjoint categories or trust is symmetric. Use quantifiers, connectives, and equality; do not use ∃!. Write one formula per part.

  1. Every editor trusts at least one poet who does not trust that editor.
  2. There is a poet who is trusted by every editor.
  3. There are two distinct editors who trust exactly the same poets.
  4. Only poets are trusted by Mira.
  5. At least two poets are trusted by nobody.
  6. Every poet trusts exactly one editor, and that editor is someone other than the poet.
