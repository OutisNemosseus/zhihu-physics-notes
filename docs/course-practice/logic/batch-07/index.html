Module 1 · easy · parentheses and connective scope · 01

Locate the operation that acts last

Let p, q, and r be propositions. Consider:

  • A: \(\neg(p\land q)\)
  • B: \((\neg p)\land q\)
  • C: \((p\lor q)\to r\)
  • D: \(p\lor(q\to r)\)
  1. For each expression, identify its outermost connective, meaning the operation applied last. State the whole expression or the two expressions to which that connective applies.
  2. Evaluate A, B, C, and D when p is true, q is false, and r is false. Show the intermediate values inside the parentheses.
  3. Using this assignment, explain why A and B cannot be treated as interchangeable, and why C and D cannot be treated as interchangeable.

“Or” is inclusive. A negation has one input; each other connective shown has two inputs.

中文提示（不含解答）

先找最后执行的运算，再看它直接作用于哪些部分；括号外的否定与只否定一个变量，作用范围不同。

Module 1 · easy · conditional negation and translation · 02

Separate a denied rule from a negative outcome

Let p mean “The ticket is valid” and q mean “The gate opens.” Treat the following as claims about one particular ticket and one opening attempt; assume no other facts about the gate.

  • A: If the ticket is valid, then the gate opens.
  • B: It is not true that, if the ticket is valid, then the gate opens.
  • C: If the ticket is valid, then the gate does not open.
  1. Translate A, B, and C into symbols, placing parentheses so that the scope of every negation is clear.
  2. Make a four-row table for their truth values, using (p,q) in the order TT, TF, FT, FF.
  3. If B is true, what must be true about p and q? If C is true, are those same two values forced? Use all permitted rows to explain.
中文提示（不含解答）

区分“整个条件句不成立”和“后件是否定句”；先明确否定的对象，再逐行检查。

Module 1 · medium · truth tables and logical equivalence · 03

Follow a closed loop of implications

For independent propositions p, q, and r, define

\(A=(p\to q)\land(q\to r)\land(r\to p),\qquad B=(p\land q\land r)\lor(\neg p\land\neg q\land\neg r).\)

  1. Build a truth table with columns p, q, r, \(p\to q\), \(q\to r\), \(r\to p\), A, B, and \(A\leftrightarrow B\). Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every assignment satisfying A. Are A and B logically equivalent?
  3. Classify A and \(A\leftrightarrow B\) as tautologies, contradictions, or contingencies.
  4. Explain in words what the three implications require about the relationship among the truth values of p, q, and r. In particular, do the implications require any one of them to be true?
中文提示（不含解答）

三个条件句都必须成立；逐行寻找被违反的那一条，并单独检查三个前件全为假时会发生什么。

Module 1 · medium · De Morgan laws and a stronger denial · 04

Deny two complete pairs without denying every component

Four independent propositions p, q, r, and s describe four components. A condition requires either both p and q, or both r and s:

\(S=(p\land q)\lor(r\land s).\)

A proposed way to express failure of S is \(H=\neg p\land\neg q\land\neg r\land\neg s\).

  1. Negate S and use De Morgan’s laws to put every negation directly on a variable. Show each equivalence.
  2. Evaluate S, \(\neg S\), and H on these four assignments to (p,q,r,s): TFFT, FFTT, TTFF, FFFF.
  3. Is H equivalent to \(\neg S\)? Give an assignment that distinguishes them if they are not equivalent.
  4. Does H being true always guarantee that \(\neg S\) is true? Does \(\neg S\) being true always guarantee that H is true? Explain each direction using the meanings of the two complete pairs.

You do not need to construct a full sixteen-row table. “Or” is inclusive.

中文提示（不含解答）

“两组都没有完整满足”与“四个分量全不成立”需要分开判断；否定每一组的“且”时，注意连接词如何变化。

Module 1 · medium · converse inverse contrapositive and counterexamples · 05

Reverse a rule whose outcome is an interval

The integer domain is exactly \(D=\{-1,0,1,2,3,4\}\). Consider the original claim:

“For every n in D, if n is even, then \(0\le n\le2\).”

The condition \(0\le n\le2\) means \((0\le n)\land(n\le2)\). Even integers are integers divisible by 2, including 0.

  1. Write the converse, inverse, and contrapositive as complete universally quantified statements over D. Express a negated interval using individual inequalities joined by “or.”
  2. Make a table for all six values of n, showing whether n is even and whether it belongs to the interval from 0 through 2. Use the table to evaluate all four universal claims. For each false claim, list every violating n.
  3. Identify the pairs that are equivalent by logical form, regardless of this particular domain and these predicate values.
  4. Write the negation of the original universal claim using an existential quantifier, with no negation outside a compound expression. List every witness. Explain how this existential negation differs from the universal contrapositive.
中文提示（不含解答）

先把整个区间条件视作后件，再进行调换或否定；“逆否命题”和“原命题的否定”还涉及不同的量词作用。

Module 1 · medium · biconditional premises and counterexamples · 06

Use an agreement premise to test new conclusions

Let p mean “The first status light is on,” q mean “The second status light is on,” and r mean “The backup light is on.” The only premises are

\(p\leftrightarrow q,\qquad q\lor r.\)

  1. Check all eight assignments to p, q, and r, using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each proposed conclusion \(p\lor r\), \(p\to r\), and \(r\to p\), decide whether it follows. For every conclusion that does not follow, give every compatible counterexample assignment.
  3. An additional reliable observation says \(\neg r\). Determine p and q, and state whether all three premises can be true together.

A conclusion follows exactly when no assignment makes every premise true and that conclusion false. “Or” is inclusive, and no other relationship among the lights is assumed.

中文提示（不含解答）

双条件先限制前两个灯的状态关系；再筛选符合“或”的行，只在这些行上检验结论。

Module 1 · medium · quantifier negation and finite expansion · 07

Tell not every from none

The domain is exactly \(D=\{-2,0,3\}\), and P(x) means “x is nonzero.” Consider:

  • A: \(\neg(\forall x\in D\,P(x))\)
  • B: \(\forall x\in D\,\neg P(x)\)
  • C: \(\neg(\exists x\in D\,P(x))\)
  • E: \(\exists x\in D\,\neg P(x)\)
  1. Translate each statement into English. Make the difference between “not every” and “none” explicit.
  2. Expand each statement using only the three instances P(-2), P(0), P(3), together with \(\neg,\land,\lor\). Then use De Morgan’s laws to identify which pairs are logically equivalent.
  3. Evaluate all four statements for the given P. List every witness for a true existential claim and every counterexample to a false universal claim, after moving an outer negation through its quantifier where needed.
  4. Would your equivalence pairings remain correct if P were replaced by any other predicate on the same domain? Explain from the expansions, rather than from the current truth values alone.
中文提示（不含解答）

量词外的否定与谓词前的否定不在同一个位置；把有限论域展开成几个“且”或“或”，再使用 De Morgan 定律。

Module 1 · medium · nested quantifiers over two explicit domains · 08

Swap two quantifiers of the same kind

The device domain is \(D=\{A,B\}\), and the test domain is \(T=\{1,2,3\}\). R(d,t) means “device d passes test t.” These are the complete records:

DeviceTest 1Test 2Test 3
ATTF
BFTF

Consider:

  • U: \(\forall d\in D\,\forall t\in T\,R(d,t)\)
  • V: \(\forall t\in T\,\forall d\in D\,R(d,t)\)
  • N: \(\exists d\in D\,\exists t\in T\,\neg R(d,t)\)
  • M: \(\exists t\in T\,\exists d\in D\,\neg R(d,t)\)
  1. Translate and evaluate U, V, N, and M. List every pair (d,t) that violates the universal claims or witnesses the existential claims; always write the device first in your list.
  2. Negate U and V, moving every negation directly onto R. Match each result to N or M.
  3. Explain why U and V must agree for any replacement of the six table entries. Do the same for N and M. You may expand the statements into six-term conjunctions or disjunctions.
  4. Explain why this example concerns swapping two universal quantifiers or two existential quantifiers, rather than swapping a universal quantifier with an existential one.
中文提示（不含解答）

先确定每个量词所遍历的论域；同一种量词只是以不同顺序检查相同的六个格子，不要据此推断不同种类的量词也能交换。

Module 1 · synthesis · truth tables conditions and choosing an output · 09

Find which requests allow a consistent output

Let p mean “A request for a green signal is active,” q mean “A request for a red signal is active,” and r mean “The displayed signal is green.” In this model the display is always exactly one of green or red, so \(\neg r\) means that it is red. The requests may be active independently. The two requirements are

\(p\to r,\qquad q\to\neg r.\)

Write \(A=(p\to r)\land(q\to\neg r)\) and \(C=\neg(p\land q)\).

  1. Construct the full truth table for A and C, including each component implication. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. For each fixed request pair (p,q) in TT, TF, FT, FF, list every permitted value of r that makes A true. Identify any pair with no permitted output.
  3. Classify \(A\to C\) and \(C\to A\) as tautologies, contradictions, or contingencies. Give every counterexample row for a direction that is not a tautology.
  4. If C is true, is there always at least one output value that can be chosen to satisfy A? Does C instead guarantee that every output choice satisfies A? Explain the difference using your list from part 2.
中文提示（不含解答）

先固定两个请求，再检查输出为真和假这两种选择；“存在一种可行输出”与“任意输出都符合规则”是不同的保证。

Module 1 · synthesis · nested quantifiers conjunction and negation · 10

Keep the passing and failing witnesses separate

The participant domain is \(U=\{A,B,C\}\), and the quiz domain is \(Q=\{1,2,3\}\). R(u,k) means “participant u passes quiz k.” A false entry means that the participant fails that quiz; there are no missing results.

ParticipantQuiz 1Quiz 2Quiz 3
ATTF
BFTF
CFTT

Consider:

  • P: \(\forall u\in U\,[(\exists k\in Q\,R(u,k))\land(\exists j\in Q\,\neg R(u,j))]\)
  • S: \([\forall u\in U\,\exists k\in Q\,R(u,k)]\land[\forall u\in U\,\exists j\in Q\,\neg R(u,j)]\)
  • H: \(\forall u\in U\,\exists k\in Q\,[R(u,k)\land\neg R(u,k)]\)
  1. Translate P, S, and H into English, preserving whether the passing and failing quiz can be chosen separately. Evaluate all three. For P, list every passing witness and every failing witness for each participant.
  2. Must P and S agree for every possible complete table on these domains? Explain from the quantifiers. Could H be true for any complete table on these domains? Explain.
  3. Negate P, moving each negation directly onto R. Translate your result into English and evaluate it using the original table.
  4. A corrected result changes only R(B,2) from T to F. Reevaluate P, S, H, and the negation of P. Identify any participant who now witnesses the negation.

The variables k and j both range over Q. They may be chosen separately, and neither is required in advance to differ from the other.

中文提示（不含解答）

两个分别量化的见证可以分别选择；检查是否要求同一场测验同时满足相反条件，并在否定时从最外层量词逐步向内处理。
