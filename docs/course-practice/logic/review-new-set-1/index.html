8. Venn diagram regions

  1. A only: A ∖ (B ∪ C)
  2. B only: B ∖ (A ∪ C)
  3. C only: C ∖ (A ∪ B)
  4. (A ∩ B) ∖ C
  5. (A ∩ C) ∖ B
  6. (B ∩ C) ∖ A
  7. A ∩ B ∩ C
