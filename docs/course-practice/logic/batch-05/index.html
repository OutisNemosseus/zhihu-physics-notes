Module 1 · easy · propositions and partial quantification · 01

Check which variables remain free

Both x and y range over exactly \(D=\{0,1\}\). Define \(P(x,y)\) to mean \(x\le y\). An unquantified variable has no assigned value.

  1. \(P(1,0)\)
  2. \(\forall x\in D\,P(x,y)\)
  3. \(\exists y\in D\,P(0,y)\)
  4. \(\forall x\in D\,\exists y\in D\,P(x,y)\)
  5. \(\exists y\in D\,P(x,y)\)
  6. \(P(x,x)\)

For each item, list its free variables, if any, and decide whether it is a proposition as written. Determine the truth value of every proposition. For each non-proposition, explain what still needs to be bound or assigned.

Use the syntactic convention that a formula with a free variable is an open formula, even if substituting every allowed value happens to give the same truth value.

中文提示（不含解答）

先逐个追踪变量是否被量词约束；某个量词只约束它自己的变量，不会自动约束式子中的其他字母。

Module 1 · easy · truth-table reading and reversed inputs · 02

Identify two mystery connectives

The propositions p and q vary independently. Two mystery binary connectives, C and D, have the output columns below. Each is exactly one of \(\land,\lor,\to,\leftrightarrow\), and they are different connectives.

pqC(p,q)D(p,q)
TTTT
TFFF
FTFT
FFTT
  1. Identify C and D. Describe in words exactly when each output is false.
  2. Complete a new column E defined by \(E(p,q)=D(q,p)\), using the same row order.
  3. Compare C(p,q) with \(D(p,q)\land E(p,q)\) on every row. Are they equivalent?
  4. Does C(p,q) being true guarantee that D(p,q) is true? Does D(p,q) being true guarantee that C(p,q) is true? For each failed guarantee, identify every counterexample row.
中文提示（不含解答）

看清哪一个输入处于前件位置；交换输入时，应查找交换后的整行，而不是把输出直接取反。

Module 1 · medium · defined connectives and equivalence · 03

Build familiar operations from NOR

Define the binary connective \(U\downarrow V\) by \(U\downarrow V=\neg(U\lor V)\). Thus its output is true exactly when both inputs are false. Let

\(X=(p\downarrow p)\downarrow(q\downarrow q),\qquad Y=(p\downarrow q)\downarrow(p\downarrow q).\)

  1. Build a truth table with columns p, q, A, B, C, X, Y, where \(A=p\downarrow p\), \(B=q\downarrow q\), and \(C=p\downarrow q\). Use TT, TF, FT, FF.
  2. Identify which familiar connective is represented by X and which is represented by Y. Confirm each identification using equivalences or all four rows.
  3. Construct an expression equivalent to \(p\to q\) using only p, q, \(\downarrow\), and parentheses. Do not use truth constants or any other connective in the final expression.
  4. Check your construction on all four assignments. Explain why using p twice as the two inputs of a NOR operation is allowed.
中文提示（不含解答）

先把同一个命题接到两个输入端，观察结果；构造新式子时可以重复使用已经得到的子式。

Module 1 · medium · biconditional negation and De Morgan · 04

Distinguish a failed equivalence from two failed arrows

Consider

\(N=\neg[(p\land q)\leftrightarrow r]\)

and the proposed replacement

\(K=\neg[(p\land q)\to r]\land\neg[r\to(p\land q)].\)

  1. Rewrite N using only \(\neg,\land,\lor\), with every negation directly on p, q, or r. Show the equivalences you use.
  2. Build a truth table with columns p, q, r, A, B, N, K, where \(A=(p\land q)\to r\) and \(B=r\to(p\land q)\). Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  3. List every assignment on which N and K differ. Classify each of N and K as a tautology, contradiction, or contingency.
  4. Explain whether the two directions of a biconditional can both be false on the same assignment, and identify the connective error in the proposed replacement.
中文提示（不含解答）

先把双条件看成两个条件句的合取，再否定整个合取；分别检查一个条件句为假需要什么。

Module 1 · medium · converse inverse and contrapositive with predicates · 05

Reverse a claim with an existential antecedent

The reviewer domain is \(U=\{A,B,C\}\), and the draft domain is \(V=\{1,2\}\). Let P(u) mean “reviewer u completed training,” and R(u,d) mean “reviewer u approved draft d.” The original claim is

\(O=\forall u\in U\,[(\exists d\in V\,R(u,d))\to P(u)].\)

ReviewerPDraft 1Draft 2
ATTF
BTFF
CFFF
  1. Translate O into English. Then write its converse, inverse, and contrapositive, keeping the outer universal quantifier over U. Negate the entire existential antecedent where necessary, and move negations directly onto P or R.
  2. Evaluate all four claims from the complete table. Identify a reviewer who violates each false claim.
  3. Which pairs are equivalent by logical form, regardless of the table?
  4. A corrected record changes only R(C,2) from F to T. Evaluate all four claims again and identify a violating reviewer for each false claim. Leave the training record unchanged.

把“至少批准过一份草稿”暂时作为一个整体前件；变换完成后，再展开它的否定。

Module 1 · medium · satisfiability and semantic validity · 06

Separate valid consequences from impossible evidence

Let p mean “The badge is active” and q mean “The door unlocks.” The two recorded requirements are

\(p\to q,\qquad p\to\neg q.\)

Write A for their conjunction. No other physical relationship between p and q is assumed.

  1. Check TT, TF, FT, FF and list every assignment satisfying A. Is A satisfiable? Is it a tautology, contradiction, or contingency?
  2. For each proposed conclusion \(\neg p\), q, and \(\neg q\), decide whether it follows from A. List every counterexample assignment for each conclusion that does not follow.
  3. An additional report asserts p. Are the three claims jointly satisfiable? Classify \(A\land p\).
  4. Let r be a third independent proposition meaning “The camera records.” Check all eight assignments to p, q, r and classify \((A\land p)\to r\). Does that classification establish that the camera actually records? Explain the role of whether the premises can all be true.

Use this semantic definition only: a conclusion follows when no assignment makes all premises true and the conclusion false. No formal proof rules are required.

中文提示（不含解答）

检验结论时寻找“前提全真、结论假”的行；另外单独检查前提是否有任何全真的行。

Module 1 · medium · quantifier domains and witness availability · 07

Track what changes when a domain grows

Initially the inspector domain is \(I=\{A,B\}\), and the machine domain is \(M=\{1,2\}\). R(i,m) means “inspector i can inspect machine m.” The complete initial table is:

InspectorMachine 1Machine 2
ATF
BFT

Consider \(P=\forall m\in M\,\exists i\in I\,R(i,m)\) and \(Q=\exists i\in I\,\forall m\in M\,R(i,m)\).

  1. Translate P and Q and evaluate both in the initial table.
  2. Add a new inspector C, keeping M and every old entry unchanged. The two new entries R(C,1) and R(C,2) are unrestricted. List all four possible new rows and determine P and Q for each enlarged table. Which old witnesses, if any, remain usable?
  3. Return to the initial table. Instead add a new machine 3, keeping I and every old entry unchanged. The entries R(A,3) and R(B,3) are unrestricted. List all four possible new columns and determine P and Q for each enlarged table.
  4. Explain why adding possible inspectors and adding machines have different effects on these two claims. Refer to the roles of their universal and existential quantifiers.

The two extensions are separate experiments. In each experiment, the displayed domains in P and Q are replaced by that experiment’s enlarged domain where applicable.

扩大的究竟是需要逐个满足的对象范围，还是可以选择见证的范围？先保留所有原有条目，再分析新增的行或列。

Module 1 · medium · three quantifiers and compound negation · 08

Compare shared and changing agreement tests

The device domain is \(D=\{A,B,C\}\), and the test domain is \(T=\{1,2\}\). R(d,t) means “device d passes test t.” Both d and e range over D. Define

\(U=\exists d\in D\,\forall e\in D\,[(e\ne d)\to\exists t\in T\,(R(d,t)\leftrightarrow R(e,t))]\)

and

\(J=\exists d\in D\,\exists t\in T\,\forall e\in D\,[(e\ne d)\to(R(d,t)\leftrightarrow R(e,t))].\)

DeviceTest 1Test 2
ATF
BFT
CTT
  1. Translate U and J into English, explaining which comparisons may use different tests. Agreement includes both devices failing the same test.
  2. Negate U. Remove all implication and biconditional symbols. Put every negation directly on R, and express the negation of disequality as equality if it occurs.
  3. Evaluate U and J in the table. For every possible witness device d, give enough information to show whether it works.
  4. For arbitrary complete truth tables on these same domains, must J imply U? Must U imply J? Justify a valid direction from the meanings of the quantifiers, and give a complete counterexample table for any failed direction.

Module 1 · synthesis · truth-table synthesis and equivalence classes · 09

Recover every permitted output column

An unknown compound proposition H uses only the independent propositions p, q, and r. Its output must satisfy both requirements on every assignment:

  • \((p\land q)\to H\) is a tautology.
  • \(H\to(p\lor q)\) is a tautology.

Use the row order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Count two choices of H as the same choice exactly when their eight output values are identical, even if their written formulas differ.

  1. For each row, determine whether the requirements force H to be T, force H to be F, or allow either value. How many distinct output columns satisfy these two requirements?
  2. Add the requirement that exchanging the truth values of p and q never changes H, while r stays fixed. Find every output column that satisfies all three requirements. Explain which rows must now have matching outputs.
  3. For every column in part 2, give one formula using only p, q, r, \(\neg,\land,\lor\). Check each formula on all eight rows. Classify each formula as a tautology, contradiction, or contingency.
  4. Can any output column from part 2 also make \(H\to r\) a tautology? Give a construction or an assignment showing why it is impossible.

No shortest-formula claim is required; the complete list of distinct truth-table columns is the target.

中文提示（不含解答）

逐行把两个条件句转成对输出值的限制；对称性连接了不同的行，因此不能继续把所有未定行当作独立选择。

Module 1 · synthesis · nested quantifier order and changed witness domains · 10

Keep track of which number may depend on which

In the first setting, x, y, and z all range independently over exactly \(D=\{0,1,2\}\). Define R(x,y,z) to mean \(x+y=z\), using ordinary integer arithmetic without wraparound. Consider:

  • A: \(\forall x\in D\,\forall y\in D\,\exists z\in D\,R(x,y,z)\)
  • B: \(\forall x\in D\,\exists z\in D\,\forall y\in D\,R(x,y,z)\)
  • C: \(\exists y\in D\,\forall x\in D\,\exists z\in D\,R(x,y,z)\)
  • F: \(\exists z\in D\,\forall x\in D\,\exists y\in D\,R(x,y,z)\)
  • G: \(\exists z\in D\,\exists y\in D\,\forall x\in D\,R(x,y,z)\)
  1. Translate all five statements into English, preserving which choices must remain fixed.
  2. Determine all five truth values. For each true statement, give the needed witness choices. For C and F, list every possible outer existential witness. For each false statement, give a counterexample or explain why every proposed fixed witness fails.
  3. Negate C, moving the negation directly onto R, and then replace \(\neg R(x,y,z)\) with an arithmetic relation. Evaluate the negation in this setting.
  4. In the second setting, only z’s domain changes to \(E=\{0,1,2,3,4\}\); x and y still range over D. Replace each quantifier over z accordingly, and repeat the truth-value and witness analysis for all five statements.
  5. A student says, “Enlarging z’s domain cannot change A, because A begins with universal quantifiers.” Test that claim using your results, and explain why the position of the existential choice still matters.
中文提示（不含解答）

外层存在量词的见证必须对后面的所有选择保持固定；内层存在量词则可以依赖此前已选定的变量。扩大 z 的范围时，不要同时扩大 x 或 y。
