Module 1 · easy · implication and De Morgan equivalence · 01

Express a prohibition in two directions

Let p and q be independent propositions. Define

\(A=p\to\neg q,\qquad B=q\to\neg p,\qquad C=\neg(p\land q).\)

  1. Make a truth table with columns p, q, A, B, and C. Use TT, TF, FT, FF.
  2. Determine which expressions are equivalent. Describe in words exactly which input pair each expression prohibits, and rewrite A without an implication symbol.
  3. Classify A, \(A\leftrightarrow B\), and \(A\land p\land q\) as tautologies, contradictions, or contingencies.

A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

条件句只有在前件为真、后件为假时才为假；注意后件本身带有否定。

Module 1 · easy · English translation and compound conditions · 02

Translate a shutdown condition and its reverse

Let p mean “The alarm is active,” q mean “The fan runs,” and r mean “The heater runs.” Consider these claims about one moment:

  • A: If the alarm is active, neither the fan nor the heater runs.
  • B: If the fan or the heater runs, the alarm is not active.
  • C: If neither the fan nor the heater runs, the alarm is active.
  1. Translate A, B, and C into symbols. Interpret “or” inclusively.
  2. Which claims are equivalent? Give one assignment that distinguishes any remaining claim from them.
  3. Suppose the alarm is inactive and both machines are stopped. Evaluate A, B, and C. Does this observation contradict A?

Assume no physical rules beyond the claims being tested.

中文提示（不含解答）

“两台都不运行”是两个否定的合取；把整个复合条件看作一个前件或后件，再比较箭头方向。

Module 1 · medium · distribution and truth-table comparison · 03

Keep a shared requirement in both alternatives

For independent propositions p, q, and r, define

\(A=p\land(q\lor r),\qquad B=(p\land q)\lor(p\land r),\qquad C=(p\land q)\lor r.\)

  1. Build a truth table with columns p, q, r, A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Are A and B equivalent? Are A and C equivalent? List every differing assignment for a pair that is not equivalent.
  3. Classify \(A\leftrightarrow B\), \(A\to C\), and \(C\to A\). Give every counterexample to a direction that is not a tautology, and explain which alternative in C can succeed without p.

Use inclusive “or” and the classifications tautology, contradiction, and contingency.

中文提示（不含解答）

分配时，原先要求的 p 要出现在每条替代路径中；先检查 p 为假的行。

Module 1 · medium · De Morgan laws and negated implications · 04

Negate a rule with compound input and output

Let p, q, and r be independent propositions. Define

\(S=(p\lor q)\to(\neg q\land r),\qquad N=\neg S.\)

A proposed expression for N is \(K=q\lor(p\land\neg r)\).

  1. Remove the implication from N and apply De Morgan’s laws until every negation is directly on a variable. Show one equivalence at each step.
  2. Make a truth table for S, N, and K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true and decide whether K is equivalent to N.
  3. When q is true, simplify N and K separately. Repeat when q is false. Explain the failure described by each alternative in K.
中文提示（不含解答）

规则失效需要整个前件成立、整个后件失败；后件是“且”，其失败不要求两个部分都为假。

Module 1 · medium · converse inverse contrapositive and finite predicates · 05

Reverse a claim about a squared value

The domain is exactly \(D=\{-2,-1,0,1,2\}\). Define P(x) to mean \(x^2=1\), and Q(x) to mean \(x<2\). The original claim is

\(O=\forall x\in D\,[P(x)\to Q(x)].\)

  1. Translate O into English. Write its converse, inverse, and contrapositive over D, replacing negated arithmetic predicates with an inequality or a disequality.
  2. Make a table for P(x), Q(x), and the four conditional instances. Evaluate all four universal claims and list every violating x for each false claim. Identify the pairs equivalent by logical form.
  3. Negate O using an existential quantifier and no implication symbol. Translate and evaluate this negation, listing every witness or explaining why there are none.

The square and order comparisons use ordinary integer arithmetic.

中文提示（不含解答）

先逐个填写五个数的谓词值，再检查各条条件句；全称命题的否定是寻找一个反例，不是把原命题的箭头反向。

Module 1 · medium · compatible assignments and valid conclusions · 06

Use a conditional agreement with an alternative premise

Let p mean “The synchronization request is active,” q mean “The left indicator is on,” and r mean “The right indicator is on.” The only premises are

\(p\to(q\leftrightarrow r),\qquad p\lor q.\)

  1. Check all eight assignments to p, q, and r in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each conclusion \(\neg q\to p\), \(\neg q\to\neg r\), and \(p\to r\), decide whether it follows. List every compatible counterexample to a conclusion that does not follow.
  3. First add the observation \(\neg q\). Then, in a separate case, add \(\neg r\) to the original premises. For each case, list every compatible assignment and state which of p, q, and r are forced.

A conclusion follows exactly when no assignment makes both premises true and the conclusion false. “Or” is inclusive; an inactive request does not by itself require the indicators to agree.

中文提示（不含解答）

只有 p 为真时，第一条规则才要求两个指示灯一致；筛选满足两条前提的行后，再测试结论和新增观察。

Module 1 · medium · quantified negation and empty antecedents · 07

Separate a counterexample from a universal denial

The domain is exactly \(D=\{-1,0,1\}\). Define P(x) to mean \(x^2=1\), and Q(x) to mean \(x>0\). Consider:

  • A: \(\neg\forall x\in D\,[P(x)\to Q(x)]\)
  • B: \(\forall x\in D\,[P(x)\to\neg Q(x)]\)
  • C: \(\exists x\in D\,[P(x)\land\neg Q(x)]\)
  1. Make a table for P, Q, \(P\to Q\), and \(P\to\neg Q\). Translate and evaluate A, B, and C. List every witness for C and every violating element for a false universal claim.
  2. Move the negation in A through the quantifier and remove the implication. Are A and C equivalent for every replacement of P and Q on D? Explain.
  3. In a separate setting, replace P by a predicate that is false at all three elements; keep Q unchanged. Reevaluate A, B, and C. Does B alone guarantee C? If \(\exists x\in D\,P(x)\) is also assumed, would B guarantee C for arbitrary P and Q? Explain using a witness.
中文提示（不含解答）

“并非每个 P 都是 Q”需要一个 P 成立而 Q 不成立的元素；“每个 P 都不是 Q”也可能在没有任何 P 时成立。

Module 1 · medium · nested quantifiers and finite arithmetic relations · 08

Distinguish a complete row from a complete column

The domains are exactly \(X=\{1,2,3\}\) and \(Y=\{0,1,2\}\). Define R(x,y) to mean \((x=y+1)\lor(x=3)\), using ordinary arithmetic. Consider:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  • C: \(\exists x\in X\,\forall y\in Y\,R(x,y)\)
  1. Construct the complete R table, with rows x in the order 1, 2, 3 and columns y in the order 0, 1, 2. Translate A, B, and C into English.
  2. Evaluate all three statements. For A, list every y witness for each x. For B and C, check every candidate fixed witness. Explain why B and C ask for different features of the table.
  3. Negate B, moving the negation directly onto R, and then replace the negated relation by arithmetic conditions. Evaluate the negation and list every x witness for each y when it is true.

The variables have different domains; a row label and a column label are not interchangeable. “Or” is inclusive.

中文提示（不含解答）

存在量词先选定的变量决定检查整行还是整列；对“或”取反时，要同时否定两条替代条件。

Module 1 · synthesis · report truth values and consistency · 09

Recover a state from one accurate report

Let p mean “The first input is active,” q mean “The second input is active,” and r mean “The output is active.” Three reports describe one state:

  • R1: At least one input is active.
  • R2: The first input is active if and only if the output is active.
  • R3: The second input is inactive.

Exactly one report is true and the other two are false. Its identity is not given, and no other system rules are assumed.

  1. Translate the reports and express the exactly-one-true requirement using R1, R2, R3, \(\neg,\land,\lor\). Build a table with columns p, q, r, R1, R2, R3, and the number of true reports. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every assignment satisfying the requirement and identify its true report. Can R2 be the only true report? Justify your answer.
  3. First suppose q is false. Then, separately, suppose q is true. In each case list the permitted assignments, determine any forced values of p and r, and identify all possible true reports.
中文提示（不含解答）

每份报告的真假都由同一组 p、q、r 决定；先逐行计算，再筛选恰好一份报告为真的行。

Module 1 · synthesis · three nested quantifiers and witness dependence · 10

Choose a day for each station or each mode

The station domain is \(S=\{A,B\}\), the day domain is \(D=\{1,2\}\), and the mode domain is \(M=\{n,f\}\), for normal and fast modes. R(s,d,m) means “station s is ready in mode m on day d.” These are all eight records:

Day 1nf
ATT
BFT
Day 2nf
ATF
BTT

Consider:

  • P: \(\forall s\in S\,\exists d\in D\,\forall m\in M\,R(s,d,m)\)
  • Q: \(\exists d\in D\,\forall s\in S\,\forall m\in M\,R(s,d,m)\)
  • H: \(\forall m\in M\,\exists d\in D\,\forall s\in S\,R(s,d,m)\)
  1. Translate and evaluate P, Q, and H. Give every allowed day witness for each station in P and each mode in H; check both candidate days for Q.
  2. Negate P and H with negations directly on R. Consider two separate corrections to the original records: correction I changes only R(A,2,n) from T to F; correction II changes only R(B,2,f) from T to F. Evaluate P, Q, H, and both negations in each case. For every true negation, give an outer witness and the necessary failing witnesses for both days.
  3. For arbitrary complete tables on these domains, test four directions: Q implies P, Q implies H, P implies H, and H implies P. Explain each valid direction from the quantifiers. Use the corrected records as complete counterexamples for any failed directions.

The two corrections are separate experiments; each starts from the displayed original tables.

中文提示（不含解答）

P 为每个站点选一天，H 为每种模式选一天；选定的日期分别要满足不同的“所有”要求。两次更正不能叠加。
