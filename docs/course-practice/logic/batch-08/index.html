Module 1 · easy · truth constants inside familiar connectives · 01

Evaluate statements containing a guaranteed value

Let p and q be independent propositions. Consider:

  • A: \(p\land(q\lor\neg q)\)
  • B: \(p\lor(q\land\neg q)\)
  • C: \((p\land\neg p)\to q\)
  • D: \((p\lor\neg p)\to q\)
  1. Make a four-row truth table for A, B, C, and D. Use (p,q) in the order TT, TF, FT, FF.
  2. For each expression, decide whether it always has the same value as p, always has the same value as q, or is always true. Justify using the part inside parentheses.
  3. Which expressions are tautologies? Which are contingencies? Are any contradictions?

A tautology is true on every assignment, a contradiction is false on every assignment, and a contingency has both true and false assignments. “Or” is inclusive.

中文提示（不含解答）

先检查括号内的式子能否随变量改变；再把其结果代入外层运算，特别注意条件句前件为假时的真值。

Module 1 · easy · English translation and inclusive disjunction · 02

Translate a rule with a negative antecedent

Let p mean “The sample is sealed” and q mean “The sample has a label.” The following claims concern one sample; assume no other facts about it.

  • A: If the sample is not sealed, then it has a label.
  • B: The sample is sealed or it has a label, with both allowed.
  • C: The sample is neither sealed nor labeled.
  1. Translate A, B, and C using p and q.
  2. Make a four-row truth table for the three translations, using TT, TF, FT, FF.
  3. Are A and B equivalent? Is C the negation of A? Support both decisions with your table.
  4. Suppose the sample has no label. If A is true, what does that require about whether the sample is sealed?
中文提示（不含解答）

先把“未密封”作为完整的前件；“两者都没有”中的否定需要分别作用于两个命题。

Module 1 · medium · truth tables and distributive equivalence · 03

Check whether an or distributes across an and

For independent propositions p, q, and r, define

\(A=p\lor(q\land r),\qquad B=(p\lor q)\land(p\lor r),\qquad C=(p\lor q)\lor r.\)

  1. Construct a truth table with columns p, q, r, \(q\land r\), \(p\lor q\), \(p\lor r\), A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Decide whether A and B are equivalent and whether A and C are equivalent. For each pair that differs, list every differing assignment.
  3. Classify \(A\leftrightarrow B\), \(A\to C\), and \(C\to A\) as tautologies, contradictions, or contingencies.
  4. Explain the different requirements imposed by A and C when p is false. Then explain what happens to both when p is true.

Every occurrence of “or” is inclusive.

中文提示（不含解答）

先按括号计算，再比较整列；也可以分别固定第一个命题为真、为假，观察其余两个命题需要满足什么。

Module 1 · medium · implication negation and De Morgan laws · 04

Negate a rule without negating its trigger

Let p, q, and r be independent propositions, and define

\(N=\neg[(p\lor\neg q)\to r].\)

A proposed replacement is \(H=\neg p\land q\land\neg r\).

  1. Rewrite N without implication symbols and move every negation directly onto a variable. Show one equivalence at each step.
  2. Give an equivalent expression for N that is an “or” of two conjunctions, with negations only on variables.
  3. Check all eight assignments in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true and every assignment making H true.
  4. Are N and H equivalent? Can they both be true on the same assignment? Explain how their requirements on the entire trigger \(p\lor\neg q\) differ.
中文提示（不含解答）

条件句不成立时，要同时检查它的整个前件和后件；不要把“否定条件句”误写成“否定所有组成部分”。

Module 1 · medium · converse inverse contrapositive and quantified negation · 05

Reverse a rule about complete signed forms

The form domain is exactly \(D=\{a,b,c,d\}\). Let F(x) mean “form x is complete,” S(x) mean “form x is signed,” and H(x) mean “form x is held.” The original claim is

\(O=\forall x\in D\,[(F(x)\land S(x))\to\neg H(x)].\)

The complete records are:

FormFSH
aTTF
bTFT
cFFT
dTTT
  1. Translate O into English. Write its converse, inverse, and contrapositive, keeping the universal quantifier and domain. Move any negation of a compound expression directly onto its predicates.
  2. Evaluate all four universal claims. For each false claim, list every violating form.
  3. Identify the pairs that are equivalent by logical form, regardless of these records.
  4. Write the negation of O with negations only on predicates. Translate it into English and list every witness in D.
中文提示（不含解答）

把“完整且已签名”整体看作前件，把“未被扣留”整体看作后件；交换或否定时都保留这两个部分的完整含义。

Module 1 · medium · premises and compatible counterexamples · 06

Use an alternative report to recover a conditional

Let p mean “The archive job runs,” q mean “A backup is created,” and r mean “The exception flag is on.” The only premises are

\((p\to q)\lor r,\qquad\neg r.\)

  1. Check all eight assignments to p, q, and r, using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each proposed conclusion \(p\to q\), q, and \(\neg p\), decide whether it follows. For every conclusion that does not follow, list every compatible counterexample.
  3. A reliable additional report says \(\neg q\). Determine p and r, and decide whether all three premises can be true together.
  4. Explain why establishing the conditional \(p\to q\) does not, by itself, establish that a backup was created.

A conclusion follows exactly when no assignment makes every premise true and the conclusion false. “Or” is inclusive; assume no other facts about the archive system.

中文提示（不含解答）

先筛掉不符合已知否定信息的行，再处理外层的“或”；一个条件句为真，并不直接指定前件或后件各自的真值。

Module 1 · medium · predicates biconditionals and quantifier scope · 07

Compare agreement at an element with agreement of summaries

The domain is exactly \(D=\{-1,0,1,2\}\). Define \(P(x):x>0\) and \(Q(x):x^2=1\). Consider:

  • A: \(\forall x\in D\,[P(x)\leftrightarrow Q(x)]\)
  • B: \(\exists x\in D\,[P(x)\leftrightarrow Q(x)]\)
  • C: \((\forall x\in D\,P(x))\leftrightarrow(\forall x\in D\,Q(x))\)
  • E: \((\exists x\in D\,P(x))\leftrightarrow(\exists x\in D\,Q(x))\)
  1. Make a table for P(x), Q(x), and \(P(x)\leftrightarrow Q(x)\) at every element.
  2. Translate and evaluate all four statements. List every counterexample to A and every witness for B. For C and E, show the values of the two quantified statements being compared.
  3. Must a witness for B satisfy both P and Q? Explain using every witness in this table.
  4. Negate A, removing the biconditional and placing negations only on P or Q. List every witness for the resulting existential claim.
  5. Do C and E being true in this table establish that A is true? Explain what information their separate summaries do and do not compare.
中文提示（不含解答）

双条件比较的是两边是否同真同假；注意逐个元素比较谓词，与先计算两个量化命题再比较，是不同的作用范围。

Module 1 · medium · explicit-domain nested quantifiers and witnesses · 08

Compare weak and strict order on a finite domain

Both x and y range over exactly \(D=\{0,1,2\}\). Initially, R(x,y) means \(x\le y\). Consider:

  • A: \(\forall x\in D\,\exists y\in D\,R(x,y)\)
  • B: \(\exists y\in D\,\forall x\in D\,R(x,y)\)
  • C: \(\forall y\in D\,\exists x\in D\,R(x,y)\)
  • E: \(\exists x\in D\,\forall y\in D\,R(x,y)\)
  1. Translate all four statements and construct the complete R table, with rows x and columns y in the order 0, 1, 2.
  2. Evaluate all four statements. For A and C, list every permitted witness for each value of the outer variable. For B and E, list every outer existential witness.
  3. Now redefine R(x,y) to mean \(x<y\), keeping both domains unchanged. Evaluate A, B, C, and E again. Identify a failing outer universal value when appropriate, and explain why every candidate fixed existential witness fails when appropriate.
  4. Negate B with the negation directly on R. Write the corresponding inequality for each definition of R, and evaluate the negation in both settings.

Use ordinary integer order. The two definitions of R are separate settings.

中文提示（不含解答）

先固定量词要求保持不变的数，再寻找另一个数；有限论域的最小值、最大值和对角线都值得单独检查。

Module 1 · synthesis · truth tables biconditionals and one-way consequences · 09

Test an indicator that reports a whole conditional

Let p mean “A request is submitted,” q mean “The request is approved,” and r mean “The rule indicator is on.” The indicator is required to be on exactly when the conditional “If a request is submitted, it is approved” is true. No other relationships are assumed. Thus the full requirement is

\(A=r\leftrightarrow(p\to q).\)

A shorter proposed requirement is \(B=(r\land p)\to q\).

  1. Build a truth table with columns p, q, r, \(p\to q\), A, B, \(A\to B\), and \(B\to A\), using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every assignment satisfying A. Classify \(A\to B\) and \(B\to A\); give every counterexample row for a direction that is not a tautology. Does replacing A by B preserve all the requirements?
  3. Assume A holds and the indicator is off. Determine p and q. Then separately assume A holds and the indicator is on: does p have to be true, and does q have to be true? Use compatible assignments to explain.
  4. Assume A holds, the indicator is on, and the request is not approved. Determine whether these observations are consistent and, if so, determine p.
中文提示（不含解答）

指示灯报告的是整个条件句的真值；先计算条件句，再与灯的状态比较，不要把灯亮直接等同于请求获批。

Module 1 · synthesis · finite table completions nested quantifiers and negation · 10

Complete a storage table under quantified requirements

The folder domain is \(D=\{A,B,C\}\), and the file-type domain is \(K=\{n,d\}\), where n means notes and d means a diagram. R(f,k) means “folder f contains a copy of file type k.” Different folders may contain copies of the same type. The two question marks below are independent unknown truth values; every other entry is fixed.

FolderNotes nDiagram d
ATF
B?T
CF?

Let \(u=R(B,n)\) and \(v=R(C,d)\). Consider:

  • P: \(\forall f\in D\,\exists k\in K\,R(f,k)\)
  • Q: \(\forall k\in K\,\exists f\in D\,R(f,k)\)
  • S: \(\exists f\in D\,\forall k\in K\,R(f,k)\)
  1. Translate P, Q, and S into English.
  2. Examine all four completions (u,v) in TT, TF, FT, FF. For each completion, give the truth values of P, Q, and S, together with witnesses or counterexamples sufficient to justify them.
  3. A storage requirement says “Every folder contains at least one of the two types, but no folder contains both.” Express this using P and S. Find every completion satisfying it and explain why your list is complete.
  4. Negate P and S, moving each negation directly onto R. Translate both negations, and evaluate them for every completion found in part 3. Give the witnesses needed for any true negation.

An unknown entry is not automatically false. There are exactly four permitted completions.

中文提示（不含解答）

把两个问号作为独立选择列出四种情况；逐行检查“每个文件夹”，逐列检查“每种文件”，并分清是否要求同一个文件夹容纳全部类型。
