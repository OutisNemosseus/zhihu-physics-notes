Module 1 · easy · connective evaluation · 01

Evaluate a status report

For this problem, let p = F, q = T, and r = F. Find the truth value of each expression. Show at least one intermediate value for each; keep the parentheses exactly as written.

  1. \(p\lor(q\land\neg r)\)
  2. \((p\lor q)\land r\)
  3. \((p\to r)\land(q\to r)\)
  4. \((p\leftrightarrow r)\lor q\)
Reference / 必要约定与公式\(a\to b\) is false only when a is true and b is false; \(a\leftrightarrow b\) is true when a and b have the same truth value.
中文提示（不含解答）

从最内层括号开始；条件句与双条件句要分别按定义计算。

Module 1 · easy · symbols to English · 02

Read three power claims

Let p mean “The battery supplies power,” q mean “The wall adapter supplies power,” and r mean “The display turns on.” Translate each formula into a complete English sentence without using logical symbols. Interpret “or” inclusively.

  1. \(\neg p\land q\)
  2. \((p\lor q)\to r\)
  3. \(r\leftrightarrow(p\lor q)\)

What extra requirement does statement 3 impose beyond statement 2?

Reference / 必要约定与公式\(A\leftrightarrow B\) means “A if and only if B.”
中文提示（不含解答）

双条件句包含两个方向；保留括号中整个条件的含义。

Module 1 · medium · truth-table equivalence · 03

Two routes to one implication

Compare \(A=(p\lor q)\to r\) and \(B=(p\to r)\land(q\to r)\).

  1. Build a truth table with columns p, q, r, \(p\lor q\), \(p\to r\), \(q\to r\), A, B, and \(A\leftrightarrow B\).
  2. Use the table to decide whether A and B are logically equivalent.
  3. Classify \(A\leftrightarrow B\) as a tautology, contradiction, or contingency.

Use the row order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.

Reference / 必要约定与公式\(U\to V\equiv\neg U\lor V\).
中文提示（不含解答）

先分别计算 A 与 B；等价性要检查全部八种赋值。

Module 1 · medium · De Morgan error analysis · 04

Audit a negation shortcut

A proposed shortcut claims

\(\neg[p\land(q\lor\neg r)]\equiv\neg p\land(\neg q\lor r).\)

  1. Starting from the left side, derive a correct equivalent expression in which every negation applies only to p, q, or r. Show one equivalence at a time.
  2. Find a truth assignment on which the two sides of the proposed shortcut differ. Evaluate both sides on that assignment.
  3. Identify the connective changes that the shortcut failed to make.
Reference / 必要约定与公式\(\neg(U\land V)\equiv\neg U\lor\neg V\); \(\neg(U\lor V)\equiv\neg U\land\neg V\).
中文提示（不含解答）

外层和内层的德摩根变换分别处理；给反例时同时列出两边的真假。

Module 1 · medium · implication families · 05

Match four real-number claims

Every claim below is universally quantified over all real numbers x.

  1. If \(x^2>9\), then \(x>3\).
  2. If \(x\le3\), then \(x^2\le9\).
  3. If \(x>3\), then \(x^2>9\).
  4. If \(x^2\le9\), then \(x\le3\).
  1. Taking A as the original implication, match B, C, and D to its converse, inverse, and contrapositive.
  2. Determine whether each universal claim is true. For each false claim, give a real-number counterexample; for each true claim, give a brief mathematical justification.
  3. Identify the pairs that are logically equivalent by their connective form, independent of the arithmetic predicates.
中文提示（不含解答）

先把两个基本条件临时记为 p、q；平方不保留原数的正负号。

Module 1 · medium · argument validity · 06

Check both alarm routes

Let p mean “The temperature warning is active,” q mean “The pressure warning is active,” and r mean “The alarm sounds.” Consider the premises

\(p\lor q,\qquad p\to r,\qquad q\to r.\)

  1. Does the conclusion r follow? Justify using truth assignments or a truth table, without assuming that either particular warning is active.
  2. Now remove the premise \(q\to r\). Test the conclusion again. If it no longer follows, give an assignment making every remaining premise true and r false.
  3. Explain what the removed premise contributes to the original argument.
Reference / 必要约定与公式An argument is valid when no assignment makes every premise true and the conclusion false.
中文提示（不含解答）

有效性只看所有前提同时为真的情况；删除前提后要重新检查。

Module 1 · medium · shared versus separate witnesses · 07

Can quantifiers move outward?

Use exactly the domain \(D=\{-2,3\}\). Define \(P(x):x\le0\) and \(Q(x):x\ge0\). Determine the truth value of each statement and justify it using the elements of D.

  1. \(\forall x\in D\,[P(x)\lor Q(x)]\)
  2. \((\forall x\in D\,P(x))\lor(\forall x\in D\,Q(x))\)
  3. \(\exists x\in D\,[P(x)\land Q(x)]\)
  4. \((\exists x\in D\,P(x))\land(\exists x\in D\,Q(x))\)

Based on your results, is statement 1 logically equivalent to statement 2 in general? Is statement 3 logically equivalent to statement 4 in general? Explain the role of a shared witness in the second pair.

中文提示（不含解答）

不能使用论域以外的数；分别记录每个量词所对应的变量和见证。

Module 1 · medium · conditional quantified statements · 08

Negate a selected-box policy

The box domain is \(W=\{a,b,c\}\), and the test domain is \(T=\{1,2\}\). Let S(w) mean “box w is selected,” P(t) mean “test t has passed calibration,” and R(w,t) mean “test t was used on box w.” Consider the policy

\(\forall w\in W\,[S(w)\to\exists t\in T\,(P(t)\land R(w,t))].\)

  1. Translate the policy into plain English.
  2. Negate the whole policy. Remove all implication symbols and move every negation directly onto S, P, or R.
  3. Translate your negation into plain English.
  4. If no box is selected, is the original policy true or false, regardless of calibration and use records? Explain using the conditional.
Reference / 必要约定与公式\(\neg\forall x\,F\equiv\exists x\,\neg F\); \(\neg\exists x\,F\equiv\forall x\,\neg F\); \(U\to V\equiv\neg U\lor V\).
中文提示（不含解答）

先处理最外层量词，再处理条件句；论域也包含未被选中的盒子。

Module 1 · synthesis · consistency and consequences · 09

Recover all possible device states

Let p mean “The primary module runs,” q mean “The backup module runs,” and r mean “The alarm lights.” A device must obey all three rules:

  • At least one of the primary and backup modules runs.
  • If the primary module runs, the backup module does not run.
  • The alarm lights if and only if the primary module does not run.
  1. Translate all three rules into propositional formulas.
  2. Check all eight assignments to p, q, r and list every assignment compatible with all the rules. Are the rules consistent?
  3. For each of \(q\leftrightarrow r\), \(p\land q\), and p, decide whether it must be true, must be false, or can vary among compatible assignments. Justify each classification.
  4. A new observation says the alarm lights. Determine what this forces about both modules, and whether the observation is consistent with the rules.
Reference / 必要约定与公式A compatible assignment makes every rule true; a set of rules is consistent if at least one compatible assignment exists.
中文提示（不含解答）

先保留满足全部规则的行，再判断哪些结论固定、哪些仍可变化。

Module 1 · synthesis · finite relations and nested quantifiers · 10

Repair a robot reachability table

The robot domain is \(X=\{A,B,C\}\), and the station domain is \(Y=\{1,2,3\}\). R(x,y) means “robot x can reach station y.” The complete relation is given below; T and F are truth values.

Robot / station123
ATFF
BFTF
CTTF

Consider the statements

  • I: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • II: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  • III: \(\forall y\in Y\,\exists x\in X\,R(x,y)\)
  1. Translate each statement into English and determine its truth value in the original table. Give witnesses or counterexamples as appropriate.
  2. Negate statement I, moving the negation directly onto R, and translate the result into English.
  3. You may change exactly one F entry to T and leave every other entry unchanged. Find every possible change that makes II true while III remains false. Explain why your list is complete.
中文提示（不含解答）

先确认每个量词是在检查行还是列；修改后要同时检查两个要求。
