Module 1 · easy · implication and partial information · 01

Separate fixed outputs from unknown inputs

The propositions p and q describe two independent status indicators. The value of p has not been reported. First assume that q is true.

  1. For each expression \(p\to q\), \(q\to p\), \(p\land q\), and \(p\lor q\), say whether its value is forced to be T, forced to be F, or still depends on p.
  2. Justify every answer by checking both allowed values of p.
  3. Repeat parts 1 and 2 when q is false instead.

The two cases for q are separate cases. A missing report does not mean that p is false. Use inclusive “or.”

中文提示（不含解答）

把未知的 p 分别设为真和假；只有两种情况下结果相同，才能从现有信息确定整个式子的真值。

Module 1 · easy · conditionals and precise English · 02

Translate necessary and sufficient conditions

Let p mean “A file is compressed” and q mean “The file can be uploaded.” Analyze these three claims as logical statements; do not assume any other facts about the upload system.

  • A: Being compressed is sufficient for the file to be uploadable.
  • B: Being compressed is necessary for the file to be uploadable.
  • C: Being compressed is both necessary and sufficient for the file to be uploadable.
  1. Translate A, B, and C into symbols.
  2. For each claim, list every ordered pair (p, q) that violates it. Check the four pairs TT, TF, FT, FF.
  3. Suppose the file is uploadable but is not compressed. Which claims does that observation disprove, and which claim remains true for this file?

“A is sufficient for B” means that A guarantees B. “A is necessary for B” means that B cannot be true without A.

中文提示（不含解答）

先分清哪一个条件提供保证、哪一个条件是必须具备的；检验条件句时关注前件与后件各自的值。

Module 1 · medium · truth tables and logical equivalence · 03

Require both outcomes of one condition

Compare these expressions:

\(A=p\to(q\land r),\qquad B=(p\to q)\land(p\to r),\qquad C=(p\to q)\lor(p\to r).\)

  1. Build a truth table with columns p, q, r, \(q\land r\), \(p\to q\), \(p\to r\), A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Are A and B equivalent? Are A and C equivalent? For any pair that is not equivalent, list every row on which it differs.
  3. Classify \(A\leftrightarrow B\) and \(A\leftrightarrow C\) as tautologies, contradictions, or contingencies.
  4. When p is true, explain in words the difference between requiring B and requiring C.
中文提示（不含解答）

先算两个较短的条件句，再用外层的“且”或“或”组合它们；不要把这两个外层运算混为一谈。

Module 1 · medium · De Morgan laws and compound negation · 04

Negate two overlapping ways to qualify

A qualification condition is \(S=(p\land q)\lor(q\land r)\), where p, q, and r are independent propositions.

  1. Negate the whole condition S. Use De Morgan’s laws to obtain an equivalent expression in which every negation applies directly to p, q, or r. Show each step.
  2. A student proposes \(H=\neg q\lor(\neg p\land\neg r)\) as a shorter expression for \(\neg S\). Check all eight assignments to decide whether this proposal is correct.
  3. List every assignment that makes S false. Explain how those assignments are described by H.

Use the row order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF when checking assignments.

中文提示（不含解答）

否定整个式子时，从最外层运算开始；两个分支都含有同一个命题，可以分情况检查它的值。

Module 1 · medium · converse inverse and contrapositive · 05

Transform a parcel-screening rule

The parcel domain is exactly \(W=\{A,B,C,D\}\). Let U(x) mean “parcel x is urgent,” O(x) mean “parcel x is oversized,” and M(x) mean “parcel x receives manual review.” The original claim is:

\(\forall x\in W\,[(U(x)\lor O(x))\to M(x)].\)

The complete records are:

ParcelUOM
AFFF
BTFT
CTTT
DFTF
  1. Write the converse, inverse, and contrapositive, keeping the same universal quantifier and domain. Move each negation directly onto a predicate.
  2. Translate the contrapositive into English.
  3. Determine the truth value of all four universal claims from the records. For each false claim, list every parcel that violates it.
  4. Identify the pairs that are equivalent by logical form, regardless of these records.
中文提示（不含解答）

把“加急或超大”作为一个整体前件进行变换；否定这个整体时，再处理其中的“或”。

Module 1 · medium · biconditional premises and counterexamples · 06

Infer what a failed readiness report permits

Let p mean “The unit is ready,” q mean “The cable is connected,” and r mean “The battery is charged.” The only premises are

\(p\leftrightarrow(q\land r),\qquad\neg p.\)

  1. List every assignment to p, q, r satisfying both premises. Check the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. For each proposed conclusion \(\neg q\), \(\neg r\), and \(\neg q\lor\neg r\), decide whether it follows from the premises. Give every compatible counterexample assignment for a conclusion that does not follow.
  3. An additional reliable report says q is true. Determine the values of p and r, and state whether all three premises can be true together.

A conclusion follows exactly when no assignment makes all the premises true and the conclusion false. Assume no physical relationships beyond the stated premises.

中文提示（不含解答）

先筛出满足全部前提的行，再检验结论；“并非两者都成立”与“某一个指定的条件不成立”需要分开判断。

Module 1 · medium · restricted claims and existential witnesses · 07

Choose the connective inside a quantifier

The domain is exactly \(D=\{1,2,3,4,5\}\). Let E(x) mean “x is even,” and H(x) mean “x is greater than 3.” Consider:

  • A: \(\forall x\in D\,[E(x)\to H(x)]\)
  • B: \(\exists x\in D\,[E(x)\land H(x)]\)
  • C: \(\exists x\in D\,[E(x)\to H(x)]\)
  1. Make a table with columns x, E(x), H(x), \(E(x)\to H(x)\), and \(E(x)\land H(x)\).
  2. Translate A, B, and C into English, and evaluate them. List every counterexample to A and every witness for B and C.
  3. Which formula, B or C, expresses “Some even number in D is greater than 3”? Explain why the other formula can use a number that is not even as its witness.
  4. Negate A, with negations directly on predicates, and identify every witness for the negation.
中文提示（不含解答）

存在量词只要求括号中的整个式子为真；检查一个条件句为真时，是否一定需要它的前件为真。

Module 1 · medium · nested quantifiers and a common witness · 08

Find neighbors within a three-number domain

Both x and y range over exactly \(D=\{0,1,2\}\). Define \(R(x,y)\) to mean \(|x-y|=1\), where absolute value is the ordinary distance between the two integers. Consider

\(A=\forall x\in D\,\exists y\in D\,R(x,y),\qquad B=\exists y\in D\,\forall x\in D\,R(x,y).\)

  1. Complete the three-by-three truth table for R, with rows indexed by x and columns by y, both in the order 0, 1, 2.
  2. Translate A and B into English and determine their truth values. For A, list every allowed y for each x. For B, check each candidate fixed y and give a failing x whenever it does not work.
  3. Negate A and B, moving each negation directly onto R. Translate the negations into English and evaluate them.
  4. Explain how the diagonal entries R(0,0), R(1,1), and R(2,2) help you test B.
中文提示（不含解答）

逐行找见证与寻找一个适用于所有行的固定列，是两种不同的检查；变量可以取相同的值。

Module 1 · synthesis · parentheses equivalence and an added premise · 09

Check whether a condition makes two reports agree

For independent propositions p, q, and r, two reports use

\(A=(p\land q)\lor r,\qquad B=p\land(q\lor r).\)

  1. Build a truth table with columns p, q, r, A, B, \(A\to B\), and \(B\to A\), using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every row where A and B differ. Classify each directional implication as a tautology, contradiction, or contingency.
  3. A reliable extra condition says \(r\to p\). On assignments satisfying that condition, must A and B agree? Check all permitted rows and explain what the extra condition rules out.
  4. Write \(\neg A\) with every negation directly on a variable, and verify it using your A column.

All uses of “or” are inclusive. The extra condition in part 3 applies only in that part.

中文提示（不含解答）

先比较没有额外条件时的所有行，再筛选满足新条件的行；只在筛选后的行上相同，并不自动代表原来的两个式子全局等价。

Module 1 · synthesis · quantified conditions and witness restrictions · 10

Separate required tests from an optional common test

The device domain is \(D=\{A,B,C\}\), and the test domain is \(T=\{1,2,3\}\). Let K(t) mean “test t is required,” and R(d,t) mean “device d passes test t.” Tests 1 and 3 are required; test 2 is optional. These are the complete pass records:

DeviceTest 1Test 2Test 3
ATTF
BFTT
CTTT

Consider:

  • P: \(\forall d\in D\,\forall t\in T\,[K(t)\to R(d,t)]\)
  • Q: \(\forall d\in D\,\exists t\in T\,[K(t)\land R(d,t)]\)
  • S: \(\exists t\in T\,[K(t)\land\forall d\in D\,R(d,t)]\)
  1. Translate P, Q, and S into English and evaluate them. For Q, list every permitted witness test for each device. For each false statement, identify the entries or candidate witnesses that explain its failure.
  2. Negate P, remove the implication, and move negations directly onto predicates. List every pair (d,t) that witnesses this negation.
  3. Every device passes test 2. Explain why that fact does or does not provide a witness for S.
  4. Suppose any or all entries in the test-2 column change, while every required-test record remains unchanged. Could the truth value of P, Q, or S change? Justify your answer from their formulas.
中文提示（不含解答）

先检查一个测试是否属于必考项目，再判断它能否作为存在量词的见证；全称条件句中的前件也会限制哪些记录真正影响结论。
