Module 1 · easy · reasoning backward from connectives · 01

Recover missing truth values

The truth values of propositions p and q are missing from a report. The report does give these two facts:

  • \(p\lor q\) is true.
  • \(p\land q\) is false.
  1. List every ordered pair of truth values (p, q) compatible with both facts. Explain why the other pairs are excluded.
  2. A third fact is recovered: \(p\to q\) is true. Which of your pairs remain possible?
  3. Using all three facts, determine the truth values of \(\neg p\lor q\) and \(p\leftrightarrow q\).

Throughout this problem, “or” is inclusive.

Reference / 必要约定与公式\(p\to q\) is false only when p is true and q is false; \(p\leftrightarrow q\) is true when p and q have the same truth value.
中文提示（不含解答）

先检查四种赋值，保留同时满足已知信息的行；新信息只能进一步筛选。

Module 1 · easy · English-to-symbol direction checks · 02

Distinguish if, only if, and unless

Let p mean “The demonstration starts,” q mean “The safety check passes,” and r mean “The supervisor is present.” Translate each statement into symbols:

  1. The demonstration starts only if the safety check passes.
  2. The demonstration starts if the supervisor is present.
  3. Unless the safety check passes, the demonstration does not start.

For this exercise, “A unless B” means “If B is false, then A”; it does not assert the reverse implication.

  1. Which two of your translations are logically equivalent? Explain by using the meanings of implication and negation.
  2. Consider the different claim “If the safety check passes, the demonstration starts.” Give truth values for p and q that make statement 1 true and this different claim false.
中文提示（不含解答）

“only if”后面的是必要条件；按题目给出的约定翻译“unless”，不要自行添加反方向。

Module 1 · medium · truth tables and parentheses · 03

Test how an implication is grouped

Let \(A=(p\to q)\to r\) and \(B=p\to(q\to r)\).

  1. Build a truth table with columns p, q, r, \(p\to q\), \(q\to r\), A, B, \(A\to B\), and \(B\to A\).
  2. List every assignment on which A and B differ. Are they logically equivalent?
  3. Classify each of \(A\to B\) and \(B\to A\) as a tautology, contradiction, or contingency.
  4. Explain why deleting the parentheses from a chain of implication symbols can change its meaning.

Use the row order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Do not assume implication is associative.

Reference / 必要约定与公式\(U\to V\equiv\neg U\lor V\).
中文提示（不含解答）

两个式子最外层的前件不同；先算括号中的条件句，再算外层条件句。

Module 1 · medium · implication removal and De Morgan · 04

Simplify a compound denial

Consider the statement

\(N=\neg\bigl[(p\to q)\lor(r\land\neg q)\bigr].\)

  1. Rewrite N without implication symbols, then move every negation directly onto p, q, or r. Show one equivalence at each step.
  2. Simplify further to an equivalent conjunction of three literals. A literal is one variable or its negation.
  3. List every assignment to p, q, r that makes N true, and check your list against the original expression.
Reference / 必要约定与公式\(\neg(U\lor V)\equiv\neg U\land\neg V\); \(\neg(U\land V)\equiv\neg U\lor\neg V\).
中文提示（不含解答）

先改写条件句，再逐层使用德摩根律；化简时留意已经要求为假的变量。

Module 1 · medium · vacuous implication and related forms · 05

Examine an impossible integer condition

The domain is all integers. Consider this universal claim:

“For every integer n, if \(0<n<1\), then \(n=7\).”

  1. Write its converse, inverse, and contrapositive as complete universally quantified statements over the same integer domain.
  2. Determine the truth value of all four claims. Give an integer counterexample for each false claim and a short explanation for each true claim.
  3. Identify the pairs that are equivalent by logical form.
  4. Now change the domain to all real numbers, leaving the original predicates unchanged. Is the original universal claim still true? Justify your answer.

When negating \(0<n<1\), negate the entire compound condition.

中文提示（不含解答）

先检查论域中是否存在满足前件的数；条件句不要求前件本身为真。

Module 1 · medium · semantic argument validity · 06

Keep the condition in a conclusion

Let p mean “The inspection is requested,” q mean “The indoor team is available,” and r mean “The outdoor team is available.” Assume only these premises:

\(p\to(q\lor r),\qquad\neg q.\)

  1. Test the proposed conclusion \(p\to r\). Is there any assignment making both premises true and this conclusion false? Justify using truth assignments or a full truth table.
  2. Test the stronger proposed conclusion r. If it does not follow, give an assignment making both premises true and r false.
  3. Suppose p is added as a third premise. Does r now follow? Explain what this additional premise changes.

Interpret “or” inclusively. You may reason from truth values; no formal proof system is required.

Reference / 必要约定与公式An argument is valid exactly when no assignment makes every premise true and the conclusion false.
中文提示（不含解答）

把条件式结论与单独的结论区分开；前件未被保证为真时，也要保留它为假的情况。

Module 1 · medium · finite two-variable predicates · 07

Find the available witnesses

Both variables range over exactly \(D=\{0,1,2,3\}\). Define \(R(x,y)\) to mean \(x+2y=3\).

  1. List all ordered pairs (x, y) in this domain for which R is true.
  2. Determine the truth value of each statement:
    • \(\forall x\in D\,\exists y\in D\,R(x,y)\)
    • \(\exists x\in D\,\forall y\in D\,R(x,y)\)
    • \(\forall y\in D\,\exists x\in D\,R(x,y)\)
    • \(\exists x\in D\,\exists y\in D\,R(x,y)\)
    Give witnesses or counterexamples sufficient to justify each result.
  3. Negate the first statement, moving the negation directly onto R, and identify a value that witnesses your negation.

The order of an ordered pair matters: its first coordinate is x and its second is y.

中文提示（不含解答）

先完整列出满足等式的有序对，再分别检查“每个 x”和“每个 y”；不能使用论域外的见证。

Module 1 · medium · quantifiers and biconditional negation · 08

Negate an exact-review claim

The reviewer domain is \(U=\{A,B\}\), and the draft domain is \(D=\{1,2\}\). Let R(u,d) mean “reviewer u reviewed draft d,” and F(d) mean “draft d is final.” Consider

\(C=\exists u\in U\,\forall d\in D\,[R(u,d)\leftrightarrow F(d)].\)

  1. Translate C into plain English. State clearly both requirements imposed by the biconditional.
  2. Negate C. Remove all biconditional and implication symbols, and leave every negation directly on R or F.
  3. Translate your negation into plain English.
  4. Assume F(1) is true and F(2) is false. Someone claims that C follows if each reviewer has reviewed at least one final draft. Test that claim by giving a complete two-by-two table of R values in which each reviewer has reviewed a final draft but C is false, or explain why no such table exists.

All claims concern only the reviewers and drafts in the stated domains.

Reference / 必要约定与公式\(A\leftrightarrow B\) is true exactly when A and B have the same truth value.
中文提示（不含解答）

双条件句失败有两种不匹配情况；“审阅过一份最终稿”不等于对全部稿件满足同一个精确条件。

Module 1 · synthesis · consistency and single-rule repairs · 09

Find the rules behind a conflict

Let p, q, and r be propositions. A specification requires all five numbered rules to hold:

  1. \(p\to q\)
  2. \(q\to r\)
  3. p
  4. \(\neg r\)
  5. \(p\lor r\)
  1. Check all eight assignments to p, q, r. Is the full specification consistent?
  2. You may remove exactly one numbered rule, while keeping every other rule unchanged. Find every rule whose removal makes the remaining specification consistent. For each successful removal, list every compatible assignment.
  3. Explain why removing rule 3 alone does or does not repair the conflict. Account explicitly for rule 5.
  4. Rule 5 is already guaranteed whenever rule 3 holds. Explain why this does not mean rule 5 can be ignored when evaluating the proposed removal of rule 3.

Use the row order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. A specification is consistent if at least one assignment satisfies all its remaining rules.

中文提示（不含解答）

分别检查五种删除方案；某条规则在原系统中是多余的，不代表删除另一条规则后它仍然多余。

Module 1 · synthesis · three nested quantifiers and minimal changes · 10

Choose inspectors across shifts

The inspector domain is \(I=\{A,B\}\), the machine domain is \(M=\{1,2\}\), and the shift domain is \(S=\{\mathrm{day},\mathrm{night}\}\). Let R(i,m,s) mean “inspector i can inspect machine m during shift s.” These tables give all eight truth values:

Day shiftMachine 1Machine 2
Inspector ATF
Inspector BFT
Night shiftMachine 1Machine 2
Inspector AFT
Inspector BTF

Consider:

  • P: \(\forall m\in M\,\exists i\in I\,\forall s\in S\,R(i,m,s)\)
  • Q: \(\forall m\in M\,\forall s\in S\,\exists i\in I\,R(i,m,s)\)
  • H: \(\exists i\in I\,\forall m\in M\,\exists s\in S\,R(i,m,s)\)
  • K: \(\forall s\in S\,\exists i\in I\,\forall m\in M\,R(i,m,s)\)
  1. Translate each statement into English and determine its truth value in the original tables. Give witnesses or counterexamples with the relevant quantifier order.
  2. Negate P, moving the negation directly onto R, and translate the result into English.
  3. You may change F entries to T and may not change any T entry to F. Find the minimum number of changes needed to make P true. List every set of changes of that minimum size, identifying each changed entry by (inspector, machine, shift), and justify completeness.
  4. For each minimum-size change set, determine whether K is true in the modified tables.
中文提示（不含解答）

把“同一个检查员跨两个班次”与“每个班次可另选检查员”分开；最少修改需给出下界与达到下界的方案。
