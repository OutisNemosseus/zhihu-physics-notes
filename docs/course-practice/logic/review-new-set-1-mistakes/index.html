原题 Q5(c) · 逻辑表达订正

1. No student both speaks German and writes Verilog.

你当时填写的原答案：for any X G(x) intersect V(x) = empty set

The domain is all students. G(x): “x speaks German”; V(x): “x writes Verilog.” Use predicates, quantifiers, and connectives.

  1. No student both speaks German and writes Verilog.
查看正确答案与解析

∀x ¬(G(x) ∧ V(x))，等价于 ¬∃x (G(x) ∧ V(x))。

G(x)、V(x) 是命题，连接用 ∧；∩ 和 ∅ 用于集合。这里应说“没有任何学生同时满足两个性质”。你前两空意思正确：∃x(V(x) ∧ ¬G(x))；∀x(G(x) → V(x))。

原题 Q6(b) · 存在量词真值集

2. Existential integer truth set

你当时填写的原答案：1<x<17

All variables range over ℤ. Find the truth set of each predicate as a set of x-values.

  1. Q(x): ∃y [(|y| < 4) ∧ (x = y² + 1)]
查看正确答案与解析

{1, 2, 5, 10}

y 是整数且 |y| < 4，所以 y 只能是 −3, −2, −1, 0, 1, 2, 3。逐个计算 y²+1 得 10, 5, 2, 1, 2, 5, 10，去重即 {1,2,5,10}。这些是离散值，不能写成连续区间。

原题 Q6(c) · 全称量词真值集

3. Universal integer truth set

你当时填写的原答案：+ inf>x>2

All variables range over ℤ. Find the truth set of each predicate as a set of x-values.

  1. R(x): ∀y (x < y² + 2)
查看正确答案与解析

{x ∈ ℤ : x < 2} = {…, −2, −1, 0, 1}

要求 x 小于每一个 y²+2。右边最小值是 2（y=0），所以必须 x<2；反过来，x<2 时也必定小于所有 y²+2。你的不等号方向写反了。

原题 Q7(e) · 空集与真子集

4. Empty set and proper subset

你当时填写的原答案：F

Let E = ∅ and S = {∅, 2}. Enter T or F. Here ⊊ means proper subset.

  1. E ⊊ S
查看正确答案与解析

T（真）

E=∅ 是任何集合的子集，且 S={∅,2} 非空，因此 E≠S，所以 E⊊S 为真。注意 E∈S 与 E⊊S 可以同时为真，两个符号表达不同关系。
