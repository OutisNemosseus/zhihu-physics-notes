Module 1 · easy · truth tables and absorption · 01

Check whether a repeated condition adds information

Let p and q be independent propositions. Define

\(A=p\land(p\lor q),\qquad B=p\lor(p\land q),\qquad C=p\land q.\)

  1. Make a truth table with columns p, q, \(p\lor q\), C, A, and B. Use (p,q) in the order TT, TF, FT, FF.
  2. Which of A, B, and C are equivalent to p? Which pairs among A, B, and C are equivalent? Give every differing assignment for each pair that is not equivalent.
  3. Explain the effect of q on A and B by considering p true and p false separately.
  4. Classify A, B, and \(A\leftrightarrow B\) as tautologies, contradictions, or contingencies.

A tautology is true on every assignment; a contradiction is false on every assignment; a contingency has both true and false assignments. “Or” is inclusive.

中文提示（不含解答）

先算内层的“且”和“或”，再检查外层；不要因为式子更长，就认为它一定提出了更多要求。

Module 1 · easy · English translation and negation scope · 02

Distinguish three ways to deny a two-part report

Let p mean “The file was copied” and q mean “The file was verified.” The following claims concern one file; assume no other facts about it.

  • A: It is not the case that the file was both copied and verified.
  • B: The file was not copied, and it was verified.
  • C: The file was neither copied nor verified.
  1. Translate A, B, and C into symbols, making the scope of each negation clear.
  2. Make a four-row table for the translations, using TT, TF, FT, FF.
  3. For each of the four directions B implies A, C implies A, A implies B, and A implies C, decide whether the implication is always true. Give every counterexample pair for a direction that fails.
  4. If A is true, must at least one of p and q be true? Must at least one of them be false? Explain using the permitted pairs.
中文提示（不含解答）

“并非两者都成立”否定的是整个合取；“未复制且已验证”和“两者都没有”则分别规定各个命题的值。

Module 1 · medium · truth-table equivalence and conditional strength · 03

Join two conditional reports with or

For independent propositions p, q, and r, define

\(A=(p\to r)\lor(q\to r),\qquad B=(p\land q)\to r,\qquad C=(p\lor q)\to r.\)

  1. Construct a truth table with columns p, q, r, \(p\to r\), \(q\to r\), A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Are A and B equivalent? Are A and C equivalent? For any pair that is not equivalent, list every differing assignment.
  3. Classify \(A\leftrightarrow B\), \(A\to C\), and \(C\to A\) as tautologies, contradictions, or contingencies. Give every counterexample row for a direction that is not a tautology.
  4. Suppose r is false. Describe exactly what A requires about p and q, and what C requires about p and q. Explain why joining two conditionals with “or” differs from joining them with “and.”

Every occurrence of “or” is inclusive.

中文提示（不含解答）

分别计算两个条件句，再处理它们之间的“或”；把后件固定为假时，前件的要求会更容易看清。

Module 1 · medium · De Morgan laws and case analysis · 04

Negate two clauses that use opposite conditions

For independent propositions p, q, and r, consider

\(S=(p\lor q)\land(\neg p\lor r),\qquad N=\neg S.\)

A proposed expression for N is \(K=(\neg p\land\neg q)\lor(p\land\neg r)\).

  1. Starting from N, apply De Morgan’s laws and double negation to move every negation directly onto p, q, or r. Show one equivalence at each step.
  2. Make a truth table for S, N, and K using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Decide whether the proposed expression is equivalent to N.
  3. List every assignment making N true. Is it possible for both conjunctions in K to be true on the same assignment? Explain.
  4. When p is true, simplify S and N separately. Repeat when p is false. Describe which of q and r controls the result in each case.
中文提示（不含解答）

否定外层“且”之后，需要继续否定每个括号内的“或”；同一行中，p 与它的否定不可能同时为真。

Module 1 · medium · converse inverse contrapositive and finite predicates · 05

Reverse a claim about the parity of a sum

Both x and y range independently over exactly \(D=\{0,1,2\}\). Let O(n) mean “n is odd,” using ordinary integer arithmetic. The original claim is

\(L=\forall x\in D\,\forall y\in D\,[O(x+y)\to(O(x)\lor O(y))].\)

The sum x+y is evaluated normally, even when the sum is outside D. An integer is odd exactly when it is not divisible by 2; 0 is even. “Or” is inclusive.

  1. Translate L into English. Write its converse, inverse, and contrapositive over the same two domains. Move negations of compound expressions directly onto O.
  2. Evaluate the four claims by checking all nine ordered pairs (x,y). For each false universal claim, list every violating pair, always writing x first.
  3. Identify the pairs that are equivalent by logical form, independently of arithmetic.
  4. Negate L using existential quantifiers and negations only on O. Translate this negation and list all its witnesses, or explain why there are none.
  5. Does L guarantee that an odd value of x or an odd value of y makes their sum odd? Explain using the converse.
中文提示（不含解答）

先按九个有序对计算奇偶性；“至少一个是奇数”允许两者都是奇数，因此不要把“或”读成“恰好一个”。

Module 1 · medium · compatible assignments and valid consequences · 06

Determine what incompatible triggers allow

Let p mean “The heating request is active,” q mean “The heating mode is on,” and r mean “The cooling request is active.” The only premises are

\(p\to q,\qquad r\to\neg q.\)

  1. Check all eight assignments to p, q, and r, using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each proposed conclusion \(\neg(p\land r)\), \(p\lor r\), and \(q\to\neg r\), decide whether it follows. For every conclusion that does not follow, list every compatible counterexample.
  3. Add a reliable observation \(\neg q\). Determine which values of p and r are forced and which can still vary. List every compatible assignment.
  4. In addition to \(\neg q\), now add \(p\lor r\). Are all four claims consistent? Determine every remaining assignment.

A conclusion follows exactly when no assignment makes all premises true and the conclusion false. Assume no other relationships between the requests and the mode. “Or” is inclusive.

中文提示（不含解答）

每条条件句只排除“前件真、后件假”的情况；加入一个新观察后，重新筛选原来允许的行，不要默认请求一定有一个启动。

Module 1 · medium · finite predicates and quantifier distribution · 07

Expand quantifiers across matching connectives

The domain is exactly \(D=\{-2,-1,0,1\}\). Define \(P(x):x<0\) and \(Q(x):x^2=1\). Consider:

  • A: \(\forall x\in D\,[P(x)\land Q(x)]\)
  • B: \((\forall x\in D\,P(x))\land(\forall x\in D\,Q(x))\)
  • C: \(\exists x\in D\,[P(x)\lor Q(x)]\)
  • E: \((\exists x\in D\,P(x))\lor(\exists x\in D\,Q(x))\)
  1. Make a table for P(x), Q(x), \(P(x)\land Q(x)\), and \(P(x)\lor Q(x)\) at each element.
  2. Translate and evaluate all four claims. List every counterexample to A, every witness for C, and the truth values of each separately quantified part of B and E.
  3. Expand A and B using the eight instances P(-2), P(-1), P(0), P(1), Q(-2), Q(-1), Q(0), Q(1), with no quantifiers. Do the same for C and E. Use the expansions to decide whether A and B must agree for any replacement predicates on D, and whether C and E must agree.
  4. Negate C, moving the negations directly onto predicates. Translate the result and evaluate it for the stated P and Q.

Every “or” is inclusive. A replacement predicate may assign any truth values on the same four-element domain.

中文提示（不含解答）

有限论域上的“所有”可展开为合取，“存在”可展开为析取；比较展开式时保留全部谓词实例，再观察括号和顺序。

Module 1 · medium · nested quantifiers and changing witness domains · 08

Choose multipliers within the stated domains

Initially both x and y range over exactly \(D=\{0,1,2\}\). Define R(x,y) to mean \(xy=x\), using ordinary multiplication. Consider:

  • A: \(\forall x\in D\,\exists y\in D\,R(x,y)\)
  • B: \(\exists y\in D\,\forall x\in D\,R(x,y)\)
  • C: \(\forall y\in D\,\exists x\in D\,R(x,y)\)
  • E: \(\exists x\in D\,\forall y\in D\,R(x,y)\)
  1. Translate all four claims and construct the complete R table with rows x and columns y in the order 0, 1, 2.
  2. Evaluate A, B, C, and E. For A and C, list every allowed witness for each outer universal value. For B and E, list every outer existential witness.
  3. In a separate setting, x still ranges over D, but y now ranges over exactly \(H=\{0,2\}\). Replace each quantifier over y by the corresponding quantifier over H. Reevaluate all four claims, giving witnesses or counterexamples sufficient to explain each result.
  4. Negate B in both settings, with the negation directly on R, and then write the arithmetic inequality replacing that negated predicate. Evaluate both negations. When a negation is true, give a permitted x for each y.

Only y’s domain changes in part 3. The multiplication rule and x’s domain stay fixed.

中文提示（不含解答）

注意 0 与非零数相乘时的不同情况；固定见证必须满足所有被量化的另一变量，且见证必须属于当前指定的论域。

Module 1 · synthesis · report consistency and exhaustive truth-table cases · 09

Locate the false report without assuming its identity

Let p mean “The first input is active,” q mean “The second input is active,” and r mean “The output is active.” Three reports about one system state say:

  • R1: At least one of the two inputs is active.
  • R2: If the first input is active, the output is active.
  • R3: If the second input is active, the output is active.

You are told that exactly one of the three reports is false, and the other two are true. You are not told which report is false. No other system rules are assumed.

  1. Translate the three reports and express the exactly-one-false requirement using R1, R2, R3, \(\neg,\land,\lor\).
  2. Construct an eight-row table with columns p, q, r, R1, R2, R3, and the number of false reports. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment consistent with the requirement, identifying its false report.
  3. Suppose r is additionally reported true. Determine all possible p and q values and identify the false report. Then separately suppose r is reported false: list all compatible input pairs and identify the false report in each case.
  4. Return to the original requirement. If R1 is confirmed true, what must be true about r and the relationship between p and q? Can you identify which of R2 and R3 is false without another observation? Justify using every remaining assignment.

“At least one” permits both inputs to be active. The truth values of the three reports must be computed from the same p, q, and r.

中文提示（不含解答）

先由同一组输入和输出计算三个报告，再统计假报告的个数；“恰好一份为假”不预先指定是哪一份。

Module 1 · synthesis · nested quantifiers and pair-dependent witnesses · 10

Compare a shared option for each pair with one for everyone

The participant domain is \(U=\{A,B,C\}\), and the time-slot domain is \(K=\{1,2,3\}\). R(u,k) means “participant u is available in slot k.” These are the complete availability records:

PersonSlot 1Slot 2Slot 3
ATTF
BFTT
CTFT

Both u and v range over U, and they are allowed to be the same person. Consider:

  • P: \(\forall u\in U\,\forall v\in U\,\exists k\in K\,[R(u,k)\land R(v,k)]\)
  • S: \(\exists k\in K\,\forall u\in U\,R(u,k)\)
  • H: \(\forall u\in U\,\exists k\in K\,R(u,k)\)
  1. Translate and evaluate P, S, and H. For P, list every allowed witness slot for each of the nine ordered pairs (u,v). For S and H, give witnesses or counterexamples sufficient to justify the results.
  2. Negate P and move every negation directly onto R. Translate this negation and evaluate it in the original table.
  3. A corrected record changes only R(C,3) from T to F. Reevaluate P, S, H, and the negation of P. List every ordered pair (u,v) that witnesses the negation.
  4. For arbitrary complete availability tables on these same domains, decide which of S implies P, P implies S, P implies H, and H implies P always hold. Explain each valid direction from the quantifiers. For each failed direction, identify a complete counterexample table from this exercise.

A witness slot for one pair may differ from the witness slot for another pair. A table change in part 3 changes no other entry.

中文提示（不含解答）

同一对参与者必须共享一个时段，但不同的参与者对可以选不同的时段；检查 u 与 v 相同的有序对时，也要按原公式计算。
