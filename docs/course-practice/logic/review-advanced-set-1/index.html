  4. Use ‘necessary’.

2. Converse, contrapositive, and inverse

Let p, q, and r be propositions. I: (p ∧ ¬q) → r; II: p → (q ∨ ¬r); III: (p ∨ q) → (r ∧ ¬p). Simplify negations using De Morgan’s laws and double negation.

  1. I: converse
  2. I: contrapositive
  3. I: inverse
  4. II: converse
  5. II: contrapositive
  6. II: inverse
  7. III: converse
  8. III: contrapositive
  9. III: inverse

3. Negate a quantified statement

Let D be an arbitrary nonempty domain, and R, S, T arbitrary binary predicates on D. All quantifiers range over D. Which option is logically equivalent to the negation of ∀x ∃y [R(x,y) ∧ ∀z (S(y,z) → T(x,z))]?

  1. ∃x ∀y [¬R(x,y) ∧ ∃z (S(y,z) ∧ ¬T(x,z))]
  2. ∃x ∃y [¬R(x,y) ∨ ∃z (S(y,z) ∧ ¬T(x,z))]
  3. ∃x ∀y [¬R(x,y) ∨ ∃z (S(y,z) ∧ ¬T(x,z))]
  4. ∃x ∀y [¬R(x,y) ∨ ∀z (S(y,z) ∧ ¬T(x,z))]
  1. Enter the letter of the correct option.

4. Classify compound propositions

Let p, q, and r be arbitrary propositions. Classify each expression as a tautology, a contradiction, or a contingency. Here ↔ is the biconditional and → is material implication.

  1. [(p → q) ∧ (q → r)] → (p → r)
  2. (p ∨ q) ∧ ¬p ∧ ¬q
  3. (p → q) ↔ (q → p)
  4. [(p ∨ q) ∧ ¬p] → q
  5. (p ↔ q) ∧ (p ↔ ¬q)

6. Integer truth sets

The free variable x ranges over all integers ℤ. Each bound variable has the finite range written beside its quantifier. List each truth set of x in roster notation; use ∅ if empty. |a| means absolute value; xy means multiplication.

  1. ∀y ∈ {−1, 1} ∃z ∈ {−2, 0, 2}: x + y = z
  2. ∃y ∈ {−2, 2} ∀z ∈ {−1, 0, 1}: |x − y| ≤ 2 − |z|
  3. ∀y ∈ {−1, 0, 1} ∃z ∈ {−1, 0, 1}: xy + z = 1

7. Membership versus inclusion

Treat 0 as an atomic object, not a set. Let A = {0, ∅, {0}}, B = {∅, A, {∅}}, and C = {A, {0}, {{∅}}}. Enter True or False. The symbol ⊆ allows equality.

  1. ∅ ∈ B
  2. {∅} ⊆ A
  3. {∅} ∈ A
  4. {{∅}} ⊆ B
  5. {{∅}} ∈ B
  6. A ⊆ B
  7. A ∈ B
  8. {A} ⊆ C
  9. {A} ∈ C
  10. B ⊆ C
  11. {{∅}} ∈ C
  12. {{∅}} ⊆ C

8. Eight Venn regions

Let U = {1, 2, …, 16}. Define A = {n ∈ U : n divides 24}, B = {n ∈ U : n is even}, and C = {n ∈ U : n = 5k + 1 or n = 5k + 2 for some integer k}. List the elements in each indicated region. Complements are relative to U.

  1. A ∩ Bᶜ ∩ Cᶜ
  2. Aᶜ ∩ B ∩ Cᶜ
  3. Aᶜ ∩ Bᶜ ∩ C
  4. A ∩ B ∩ Cᶜ
  5. A ∩ Bᶜ ∩ C
  6. Aᶜ ∩ B ∩ C
  7. A ∩ B ∩ C
  8. Aᶜ ∩ Bᶜ ∩ Cᶜ

9. Equivalent set expression

Let A, B, C be arbitrary subsets of a universal set U. Complements are relative to U; ∖ denotes set difference. Let E = ((A ∖ B) ∪ (A ∩ C)) ∖ ((A ∩ C) ∖ B).

  1. A ∖ (B ∩ C)
  2. (A ∖ (B ∪ C)) ∪ (A ∩ B ∩ C)
  3. (A ∩ B) ∖ C
  4. A ∩ (B ∪ C)
  1. Select the one option that equals E for every choice of A, B, and C.

12. Nested sets and Cartesian products

Let A = {0,1}, B = {1,{0}}, C = {∅,0,1,{0},A,B}, and D = {∅,{∅},A,C}. Treat numbers as distinct from sets; in particular, 0 ≠ ∅. Cartesian products use ordered pairs; named sets may be left unexpanded inside pairs. Candidates in the last two parts are ∅, A, B, C, D.

  1. Find |A|.
  2. Find |B|.
  3. Find |C|.
  4. Find |D|.
  5. Find |A × B| and list every element of A × B.
  6. Find |B × A| and list every element of B × A.
  7. Which candidate sets are elements of C?
  8. Which candidate sets are subsets of C? Include C itself if appropriate.

15. Tarski-style world

The domain is exactly the eight labeled objects in the diagram and table. Rows run from 1 at the top to 5 at the bottom; columns from 1 at the left to 5 at the right. Triangle(x), Square(x), and Circle(x) specify shape. LeftOf(x,y) means x has a strictly smaller column number than y; Above(x,y) means x has a strictly smaller row number than y. SameRow and SameColor have their literal meanings. State True or False and give a brief reason, witness, or counterexample.

16. Translate statements about people

The domain is all people attending a workshop. M(x) means x is a mentor; N(x) means x is a newcomer; H(x,y) means x helped y. Constants a and b denote Ava and Ben. Do not assume mentor and newcomer are disjoint categories or help is symmetric. Use quantifiers, connectives, and equality; do not use ∃!. Write one formula per part.

  1. Every newcomer was helped by a mentor other than themselves.
  2. Some mentor helped every newcomer other than themselves. This says nothing about whether that mentor helped themselves.
  3. No two distinct newcomers helped each other.
  4. Everyone who helped Ava was helped by Ben.
  5. Someone helped exactly two distinct newcomers.
  6. Every mentor helped a newcomer whom no other mentor helped.
