Module 1 · easy · conjunction and implication · 01

Retain the premise beside its conditional

Let p and q be independent propositions. Define

\(A=p\land(p\to q),\qquad B=p\land q,\qquad C=p\to(p\land q).\)

  1. Make a truth table with columns p, q, A, B, and C. Use TT, TF, FT, FF.
  2. Which expressions are equivalent? List every input pair where A and C differ. Rewrite C without an implication symbol and simplify it.
  3. Classify A, \(A\leftrightarrow B\), and \(A\land\neg q\) as tautologies, contradictions, or contingencies.

A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

把 p 与条件句用“且”连接时，p 必须成立；把 p 放在条件句的前件中则不同。

Module 1 · easy · English translation and biconditionals · 02

Separate the two directions of a completion report

Let p mean “The export is complete,” q mean “The summary is saved,” and r mean “The image is saved.” Consider:

  • A: The export is complete if and only if both the summary and the image are saved.
  • B: If the export is complete, both the summary and the image are saved.
  • C: If both the summary and the image are saved, the export is complete.
  1. Translate A, B, and C into symbols. Keep “both files are saved” together as one compound condition.
  2. Is A equivalent to \(B\land C\)? Does B alone imply A? Does C alone imply A? Give an assignment for each failed implication.
  3. Suppose the export is incomplete even though both files are saved. Evaluate A, B, and C. Identify exactly which direction of A this observation violates.

Assume no software rules beyond the claims being tested.

中文提示（不含解答）

“当且仅当”包含两个方向；即使前件不成立，一个单向条件句仍可能为真。

Module 1 · medium · conditional equivalence and truth tables · 03

Recognize an alternative shared by both sides

For independent propositions p, q, and r, define

\(A=(p\lor q)\to(p\lor r),\qquad B=q\to(p\lor r),\qquad C=q\to r.\)

  1. Build a truth table with columns p, q, r, A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Are A and B equivalent? Are A and C equivalent? List every differing assignment for a pair that is not equivalent.
  3. Classify \(A\leftrightarrow B\), \(A\to C\), and \(C\to A\) as tautologies, contradictions, or contingencies. Give every counterexample to a direction that is not a tautology, and explain what p being true does to A and B.

All uses of “or” are inclusive.

中文提示（不含解答）

先分别看 p 为真和为假的情况；前后两边都出现 p，不等于可以同时直接删掉它。

Module 1 · medium · De Morgan laws and case analysis · 04

Deny a choice between two complete branches

Let p, q, and r be independent propositions. Define

\(S=(p\land q)\lor(\neg p\land\neg r),\qquad N=\neg S.\)

A proposed expression for N is \(K=(p\land\neg q)\lor(\neg p\land r)\).

  1. Apply De Morgan’s laws to N until each negation is directly on a variable. Show one equivalence at each step.
  2. Make a truth table with columns p, q, r, S, N, and K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true and decide whether K is equivalent to N.
  3. When p is true, simplify S, N, and K separately. Repeat when p is false. Explain why the same branch variable p is used in K rather than reversing its value.
中文提示（不含解答）

先否定整个“或”，再否定各个“且”；最后按 p 的真假检查哪一条分支仍可能成立。

Module 1 · medium · converse inverse contrapositive and finite predicates · 05

Reverse a rule that fails at a negative input

The domain is exactly \(D=\{-3,-1,0,2,3\}\). Define P(x) to mean \(x<0\), and Q(x) to mean \(x^2\ge4\). The original claim is

\(O=\forall x\in D\,[P(x)\to Q(x)].\)

  1. Translate O into English. Write its converse, inverse, and contrapositive over D, replacing negated arithmetic predicates by inequalities.
  2. Make a table for P(x), Q(x), and the four conditional instances. Evaluate all four universal claims and list every violating x for each false claim. Identify the pairs equivalent by logical form.
  3. Negate O using an existential quantifier and no implication symbol. Translate and evaluate this negation, listing every witness. If exactly one element is removed from D, which removal makes O true? With that removal, is the converse true?

All arithmetic uses ordinary integers, and a domain change removes an element from every quantified claim being reconsidered.

中文提示（不含解答）

逐个检查负数和平方条件；原命题的反例与逆命题的反例可能来自不同的元素。

Module 1 · medium · compatible assignments and valid conclusions · 06

Infer a state when two routes cannot coexist

Let p mean “The service is active,” q mean “The direct route is available,” and r mean “The relay route is available.” The only premises are

\(p\leftrightarrow(q\lor r),\qquad\neg(q\land r).\)

  1. Check all eight assignments to p, q, and r in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each conclusion \(q\to\neg r\), \(p\to q\), and \(\neg p\to\neg r\), decide whether it follows. List every compatible counterexample to a conclusion that does not follow.
  3. First add the observation \(\neg q\). Then, in a separate case, add q to the original premises. For each case, list every compatible assignment and state which of p and r are forced. If they can vary, describe the relationship they must still satisfy.

A conclusion follows exactly when no assignment makes both premises true and the conclusion false. “Or” is inclusive.

中文提示（不含解答）

先保留满足两条前提的行；至少一条路线可用与两条路线同时可用是不同条件。

Module 1 · medium · quantified conditionals and different witnesses · 07

Compare a local rule with a whole-domain consequence

The domain is exactly \(D=\{0,1,2\}\). Define P(x) to mean \(x=1\), and Q(x) to mean \(x\ge1\). Consider:

  • A: \(\forall x\in D\,[P(x)\to Q(x)]\)
  • B: \((\exists x\in D\,P(x))\to(\forall y\in D\,Q(y))\)
  1. Make a table for P(x), Q(x), and \(P(x)\to Q(x)\). Translate and evaluate A and B. List all P witnesses and all elements at which Q is false.
  2. Negate A and B, using no implication symbols and placing negations directly on P or Q. Evaluate both negations. For any true negation, give all witness choices and explain whether the two predicates must concern the same element.
  3. For arbitrary replacements of P and Q on this same domain, does B imply A? Does A imply B? Explain any valid direction and use the given predicates as a counterexample where possible. Then suppose P is false everywhere: evaluate A and B for any Q.

A replacement predicate may assign any truth values to the three domain elements. The letters x and y are bound separately in B.

中文提示（不含解答）

A 在同一个元素上检查条件句；B 只要有一个 P 成立，就对整个论域的 Q 提出要求。

Module 1 · medium · finite relations and nested quantifiers · 08

Remove a possible shared nearby witness

Initially, the domains are exactly \(X=\{0,1,2\}\) and \(Y=\{0,1,2\}\). Define R(x,y) to mean \(|x-y|\le1\), where the bars denote absolute value. Compare:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  1. Construct the complete R table, with rows x and columns y in increasing order. Translate and evaluate A and B. For A, list every y witness for each x; for B, check every candidate fixed y.
  2. Now replace only Y by \(Y'=\{0,2\}\), keeping X and the relation unchanged. Rewrite and reevaluate A and B. List every allowed witness and explain whether a different y for each x is still sufficient.
  3. Negate B in both settings, moving the negation directly onto R, and then express the negated relation as an inequality. Evaluate both negations. For a true negation, list every x witness for each permitted y.

A removed value may still belong to X; only the second variable’s domain changes.

中文提示（不含解答）

共享见证必须对每个 x 都有效；删去一列后，每一行仍有真值，并不保证存在全为真的列。

Module 1 · synthesis · report truth values and consistency · 09

Reconcile two agreeing reports with a third opposing report

Let p mean “The gate is open,” q mean “The beam is on,” and r mean “The beacon is on.” Three reports describe one state:

  • R1: If the gate is open, the beam is on.
  • R2: The beam or the beacon is on.
  • R3: If the beacon is on, the gate is open.

R1 and R2 have the same truth value. R3 has the opposite truth value. Neither of the two agreeing reports is assumed true.

  1. Translate the reports. Express the required pattern using only R1, R2, R3, \(\neg,\land,\lor\); call this expression K. Make a table with short column labels p, q, r, R1, R2, R3, K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every assignment satisfying K and give the three report truth values for each. Can the two agreeing reports both be false? Can they both be true?
  3. First suppose the beam is off. Then, separately, suppose it is on. In each case, list the permitted assignments and determine any forced values of p and r. If p and r can vary, describe the relationship they must satisfy.

Interpret “or” inclusively. No additional physical rules are assumed.

中文提示（不含解答）

“两份报告一致”不代表两份都为真；第三份报告必须与它们的共同真值相反。

Module 1 · synthesis · three nested quantifiers and witness dependence · 10

Choose a band per sender or one band for all senders

The sender domain is \(S=\{A,B\}\), the receiver domain is \(D=\{1,2\}\), and the band domain is \(F=\{l,h\}\), for low and high bands. R(s,d,f) means “sender s can reach receiver d on band f.” These are all eight records:

Low l12
ATT
BFF
High h12
AFF
BTT

Consider:

  • P: \(\forall s\in S\,\exists f\in F\,\forall d\in D\,R(s,d,f)\)
  • Q: \(\exists f\in F\,\forall s\in S\,\exists d\in D\,R(s,d,f)\)
  • H: \(\forall s\in S\,\forall d\in D\,\exists f\in F\,R(s,d,f)\)
  1. Translate and evaluate P, Q, and H. Give every band witness for each sender in P and each sender-receiver pair in H. For Q, check each band and the receiver choices available to both senders.
  2. Negate P and Q with negations directly on R. A single corrected dataset changes exactly two records: R(A,2,l) changes from T to F, and R(A,2,h) changes from F to T. Reevaluate P, Q, H, and both negations. For each true negation in either dataset, give the necessary witnesses in quantifier order.
  3. For arbitrary complete tables on these domains, test four directions: P implies H, H implies P, P implies Q, and Q implies P. Explain each valid direction from the quantifiers. Use the original or corrected records as complete counterexamples for any failed directions.

The two listed changes are made together; every other record stays unchanged.

中文提示（不含解答）

P 为每个发送端选能覆盖全部接收端的频段；Q 先选一个公用频段，但各发送端可以选择不同的接收端。
