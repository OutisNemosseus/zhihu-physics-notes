Module 1 · easy · connectives and truth values · 01

Repeat one input in an agreement test

Let p and q be independent propositions. Define

\(A=(p\leftrightarrow q)\leftrightarrow p,\qquad B=p\leftrightarrow(q\leftrightarrow p).\)

  1. Make a truth table with short columns p, q, A, and B. Use TT, TF, FT, FF, and compute each inner biconditional before the outer one.
  2. Compare A and B with p and with q. Which input, if either, always has the same value as A? If p changes while q stays fixed, can A change? Check both possible values of q.
  3. Classify A, \(A\leftrightarrow q\), and \(A\land\neg q\) as tautologies, contradictions, or contingencies. Explain why a repeated occurrence of p must use the same truth value each time.

A biconditional is true exactly when its two inputs agree. A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

同一个字母每次出现都代表同一个真值；先算内层，再比较外层的两个输入。

Module 1 · easy · English translation and inclusive or · 02

Compare a pairwise rule with a minimum count

Let p, q, and r mean that lamps P, Q, and R are on. The lamps are independent. Consider:

  • M: At least two of the three lamps are on.
  • E: Exactly two of the three lamps are on.
  • J: In each pair of lamps, at least one lamp is on.
  1. Translate M and E using only \(\neg,\land,\lor\). Translate J as a conjunction of three clauses, one for each pair P–Q, P–R, and Q–R. “At least one” allows both members of a pair to be on.
  2. Make a table with columns p, q, r, M, E, J. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Which claims are equivalent? List every assignment where M and E differ.
  3. Write \(\neg M\) using only \(\neg,\land,\lor\), with every negation directly on a variable. If r is false, describe exactly what M requires about p and q. Repeat when r is true.
中文提示（不含解答）

逐一列出三对灯；“每一对至少亮一盏”与“指定一对都亮”不是同一句话。

Module 1 · medium · truth tables and equivalence · 03

Decide whether a third alternative adds anything

For independent propositions p, q, and r, define

\(A=(p\land q)\lor(\neg p\land r)\lor(q\land r),\)

\(B=(p\land q)\lor(\neg p\land r),\qquad C=(p\land q)\lor(q\land r).\)

  1. Build a truth table with columns p, q, r, A, B, C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment where A and B differ and every assignment where A and C differ.
  2. Suppose \(q\land r\) is true. Check p true and p false separately: in each case, must one of the other two alternatives in A already be true? Use this to decide whether the third alternative can be removed without changing A.
  3. Can the first alternative \(p\land q\) be removed from A instead? Can the second alternative \(\neg p\land r\) be removed instead? For each proposed removal, give every assignment where the shortened expression differs from A. Classify \(A\to C\) and \(C\to A\).

Use the classifications tautology, contradiction, and contingency. “Or” is inclusive.

中文提示（不含解答）

某一项能删掉，要证明它为真时其余项已经足够；分别检查 p 的两个取值。

Module 1 · medium · De Morgan laws and compound negation · 04

Deny either a conditional or an agreement

Let p, q, r, and s be four independent propositions. Define

\(S=(p\to q)\lor(r\leftrightarrow s),\qquad N=\neg S.\)

A proposed replacement is \(K=p\land\neg q\land(r\lor s)\).

  1. Rewrite N using only \(\neg,\land,\lor\), with each negation directly on a variable. Show the steps for the outer “or,” the conditional, and the biconditional.
  2. Make a sixteen-row table with short columns p, q, r, s, N, K. Use pq in the order TT, TF, FT, FF; within each pq block, use rs in the order TT, TF, FT, FF. List every assignment making N true and every assignment where N and K differ.
  3. Classify \(N\to K\) and \(K\to N\), giving all counterexamples to any failed direction. When p is true and q is false, explain the difference between what N requires of r and s and what K requires.
中文提示（不含解答）

否定“条件句或双条件”时，两部分都必须失败；双条件失败要分成两种不一致的情况。

Module 1 · medium · converse inverse and quantified consequents · 05

Reverse a certification rule covering every format

The profile domain is exactly \(D=\{a,b,c\}\), and the format domain is exactly \(F=\{s,l\}\). P(x) means “profile x is certified.” R(x,f) means “profile x supports format f.” These are all the records:

xPsl
aTTT
bFTT
cTTF

The original claim is \(O=\forall x\in D\,[P(x)\to(\forall f\in F\,R(x,f))]\).

  1. Translate O into English. Write its converse, inverse, and contrapositive, keeping the outer quantifier over D. Wherever the whole “supports every format” statement is negated, move the negation through its quantifier. Leave negations directly on P or R.
  2. Evaluate all four universal claims. For every false claim, list all violating profiles and give the format evidence needed to explain each violation. Identify the pairs equivalent by logical form.
  3. Negate O with no implication and with negations directly on predicates. List every ordered pair (x,f) witnessing this negation. Then change only R(c,l) from F to T and reevaluate the four claims and the negation of O.

The format columns show R; certification is a separate record, so no unstated relationship is assumed.

中文提示（不含解答）

把“支持每种格式”看作整个后件；它的否定是存在一种不支持的格式。

Module 1 · medium · compatible assignments and valid conclusions · 06

Reason from a conditional used as a trigger

Let p mean “A request is active,” q mean “The request is accepted,” and r mean “A review is running.” The only premises are

\((p\to q)\to r,\qquad\neg(r\land q).\)

  1. Check all eight assignments in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Use short columns p, q, r, A, B, where A and B are the two premises in order. List every assignment satisfying both premises.
  2. Test each proposed conclusion \(\neg q\), \(p\lor r\), and \(p\to r\). Say which follow, and list every compatible counterexample for a conclusion that fails.
  3. First add \(\neg p\). Then, in a separate case, add \(\neg r\) to the original premises. For each case list every remaining assignment, determine all forced values, and check consistency.

A conclusion follows when no assignment makes both premises true and the conclusion false. The entire conditional \(p\to q\) is the first premise’s trigger; do not replace that premise by \(p\to(q\to r)\).

中文提示（不含解答）

第一个前件本身是一个条件句；先求这个条件句的真值，再判断它是否触发 r。

Module 1 · medium · finite predicates and quantifier scope · 07

Compare agreement with everyone to agreement with someone

The domain is exactly \(D=\{a,b,c\}\). P(x) means “sample x passes,” with P(a) = T, P(b) = F, and P(c) = F. Both x and y range over D and may be the same sample. Consider:

  • A: \(\forall x\in D\,\forall y\in D\,[P(x)\to P(y)]\)
  • B: \((\forall x\in D\,P(x))\lor(\forall x\in D\,\neg P(x))\)
  • C: \(\forall x\in D\,\exists y\in D\,[P(x)\leftrightarrow P(y)]\)
  • E: \(\exists y\in D\,\forall x\in D\,[P(x)\leftrightarrow P(y)]\)
  1. Translate and evaluate all four statements. For C, list every y witness for each x; for E, check each fixed candidate y. For A, list every ordered pair violating its conditional.
  2. Negate A with no implication and with negations directly on P. List every witness pair. Does the negation say that all samples fail, or that passing and failing samples both exist? Explain the roles of x and y.
  3. Now allow any replacement of the three P values. Must A, B, and E always agree? Must C always be true? Justify your answers for an all-pass dataset, an all-fail dataset, and a dataset containing both outcomes.

The “or” in B is inclusive. Choosing y = x is allowed.

中文提示（不含解答）

比较不同量词的取值顺序；不要遗漏 x 与 y 可以指同一个样本这一点。

Module 1 · medium · arithmetic relations and nested quantifiers · 08

Restrict one domain in an even-sum relation

The domains are initially \(X=\{0,1,2,3\}\) and \(Y=\{0,1,2\}\). R(x,y) means “x + y is even,” using ordinary integer addition; 0 is even. Consider:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists x\in X\,\forall y\in Y\,R(x,y)\)
  • C: \(\forall y\in Y\,\exists x\in X\,R(x,y)\)
  1. Construct the complete R table with rows x and columns y in increasing order. Translate and evaluate A, B, C. For A and C, list all witnesses for each outer universal value; for B, test every fixed x.
  2. Replace only Y by \(Y'=\{0,2\}\), keeping X and R unchanged. Rewrite and reevaluate the three statements. Give all allowed witnesses, or counterexamples sufficient to explain each failure. Explain why removing one y can affect A and B differently.
  3. Negate A and B with negations directly on R. Express \(\neg R(x,y)\) in arithmetic words. Evaluate both negations in both settings and list all required witnesses for each true negation.

The sum need not belong to either domain. Removing a value from Y does not remove it from X.

中文提示（不含解答）

先根据和的奇偶性填写表格，再分别看“每行有一个真”和“存在一行全真”。

Module 1 · synthesis · truth tables and constrained inference · 09

Find the wrong input in a transcribed state

Three input values were copied as p = T, q = F, r = T. Exactly one of those three copied values is wrong; the other two are correct. Separately, three correctly functioning tests compute

\(A=(p\land q)\lor r,\qquad B=p\to(q\land r),\qquad C=q\leftrightarrow r.\)

All tests use the same actual input state, not the copied values.

  1. Write a formula H using only \(p,q,r,\neg,\land,\lor\) that says exactly one copied value is wrong. Check all eight actual states and make a table with short columns p, q, r, H, A, B, C. List all states allowed by H before any test output is known.
  2. The verified test outputs are A = T and B = T. List every actual state compatible with these outputs and H. For each state, identify the incorrectly copied input. Can r be the incorrectly copied value?
  3. First suppose the additional verified output is C = T. Then, separately, suppose C = F. In each case determine every actual input value and identify the copying error, or explain why no compatible state exists.

Exactly one error refers only to the three copied input values. None of the verified test outputs is allowed to be wrong.

中文提示（不含解答）

“复制错了”要与记录的 T、F、T 分别比较；测试公式始终代入真实输入。

Module 1 · synthesis · three nested quantifiers and witness dependence · 10

Choose a profile per encoder or per clip

The encoder domain is \(E=\{A,B,C\}\), the clip domain is \(D=\{1,2\}\), and the profile domain is \(F=\{s,l\}\). R(e,d,f) means “encoder e can process clip d using profile f.” These are all twelve records:

s12
ATT
BTF
CTF
l12
AFT
BTT
CFT

Consider:

  • U: \(\forall e\in E\,\exists f\in F\,\forall d\in D\,R(e,d,f)\)
  • V: \(\forall d\in D\,\exists f\in F\,\forall e\in E\,R(e,d,f)\)
  • W: \(\exists f\in F\,\forall e\in E\,\forall d\in D\,R(e,d,f)\)
  1. Translate and evaluate U, V, and W. List every profile witness for each encoder in U and each clip in V; for W, check each candidate fixed profile. Negate U and V with negations directly on R, and give all required witnesses for each true negation.
  2. Make two cumulative corrections. Stage I changes only R(C,2,s) from F to T. Stage II keeps that change and also changes R(B,1,s) from T to F. Evaluate U, V, W, and the two negations at each stage. Give witnesses or counterexamples explaining every result.
  3. For arbitrary complete tables on these same domains, test U implies V, V implies U, W implies U, W implies V, and \((U\land V)\) implies W. Explain any valid direction from the quantifiers. Use the original, Stage I, or Stage II table as a complete counterexample for each failed direction.

The corrections are cumulative: Stage II includes both listed changes. No other record changes.

中文提示（不含解答）

U 可随编码器选择配置，V 可随片段选择配置；第二阶段保留第一阶段的修改。
