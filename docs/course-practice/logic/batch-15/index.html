Module 1 · easy · conditionals and truth values · 01

Require one arrow to hold and its reverse to fail

Let p and q be independent propositions. Define

\(A=(p\to q)\land\neg(q\to p),\qquad B=\neg p\land q,\qquad C=(p\to q)\lor(q\to p).\)

  1. Make a truth table with columns p, q, \(p\to q\), \(q\to p\), A, B, and C. Use TT, TF, FT, FF.
  2. Are A and B equivalent? If A is true, determine both input values. Can both arrows be false on the same input pair? Explain from the requirements for a false conditional.
  3. Classify A, C, and \(A\land p\) as tautologies, contradictions, or contingencies. Explain why requiring an arrow to be false gives more information than requiring it to be true.

A conditional is false exactly when its antecedent is true and its consequent is false. A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

先找出逆方向的条件句何时为假，再检查正方向；两个条件句使用同一组 p、q。

Module 1 · easy · English translation and compound conditions · 02

Use exactly one failure as the trigger

Let p mean “The warning is displayed,” q mean “Check 1 fails,” and r mean “Check 2 fails.” Consider three claims about one run:

  • A: If exactly one of the two checks fails, the warning is displayed.
  • B: The warning is displayed only if exactly one of the two checks fails.
  • C: If at least one of the two checks fails, the warning is displayed.
  1. Translate A, B, and C into symbols. Express “exactly one” using \(\neg,\land,\lor\); “at least one” allows both checks to fail.
  2. Evaluate all three claims when both checks fail and no warning is displayed. Then evaluate them when both checks pass and a warning is displayed. Identify which claims each observation violates.
  3. Which formula expresses “The warning is displayed if and only if exactly one check fails,” using only the labels A and B and one connective? Does C always imply A? Does A always imply C? Give an assignment for any failed direction.

There are no additional rules connecting the checks and the warning. Each claim is tested against the stated observations, even when an observation violates it.

中文提示（不含解答）

“恰好一个失败”是整个前件或后件；两项都失败时，这个复合条件反而为假。

Module 1 · medium · truth tables and equivalence · 03

Compare two inputs through opposite masking operations

For independent propositions p, q, and r, define

\(A=(p\lor r)\leftrightarrow(q\lor r),\qquad B=(p\land r)\leftrightarrow(q\land r),\qquad C=p\leftrightarrow q.\)

  1. Build a truth table with short columns p, q, r, A, B, C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment where A differs from C and every assignment where B differs from C.
  2. First set r to T and simplify A and B separately. Then set r to F and repeat. Use these two cases to compare \(A\land B\) with C and to classify \(A\lor B\).
  3. Classify \(A\to C\), \(B\to C\), and \((A\land B)\to C\), giving every counterexample to any direction that is not a tautology. If both tests A and B return T but r is unknown, what can be concluded about p and q? Must either input be T?

A biconditional is true when its two complete inputs agree, including when both are false. Use the classifications tautology, contradiction, and contingency.

中文提示（不含解答）

r 为真时，or 会掩盖输入差异；r 为假时，and 会掩盖差异。分别检查两个测试。

Module 1 · medium · De Morgan laws and compound negation · 04

Negate a rule whose outcome requires agreement

Let p, q, and r be independent propositions. Define

\(S=(p\lor q)\to(q\leftrightarrow r),\qquad N=\neg S.\)

A proposed replacement is \(K=(p\lor q)\land(q\lor r)\).

  1. Rewrite N using only \(\neg,\land,\lor\), with every negation directly on a variable. Show how you negate the outer conditional and the inner biconditional.
  2. Make a truth table with columns p, q, r, S, N, K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true and every assignment where N and K differ.
  3. Classify \(N\to K\) and \(K\to N\), giving every counterexample to any failed direction. Simplify N separately when q is T and when q is F. Explain why “q or r” alone does not express failure of their agreement.

All uses of “or” are inclusive. Use the classifications tautology, contradiction, and contingency.

中文提示（不含解答）

否定整个条件句时，前件必须成立、后件必须失败；双条件失败需要两个真值不同。

Module 1 · medium · converse inverse and finite integer domains · 05

Reverse a rule about equal squares

Initially, x and y both range independently over exactly \(D=\{-2,0,2\}\). The original claim is

\(O=\forall x\in D\,\forall y\in D\,[(x^2=y^2)\to(x=y)].\)

  1. Translate O into English. Write its converse, inverse, and contrapositive over these domains, expressing negated equalities with \(\ne\). Identify the pairs equivalent by logical form.
  2. Check all nine ordered pairs (x,y). Evaluate all four universal claims and list every violating pair for each false claim. Negate O with existential quantifiers and no implication, then list every witness pair.
  3. Consider two separate domain changes from the original setting. In Case I, only x is restricted to \(D'=\{0,2\}\), while y still ranges over D. In Case II, both x and y range over D'. Rewrite O with the correct domains and reevaluate all four claims in each case. List every remaining violation and explain why restricting only x may leave a problem involving the sign of y.

Pairs may have equal coordinates. Squaring uses ordinary integer arithmetic, and a negative number and its positive opposite have the same square.

中文提示（不含解答）

平方相等不一定原数相等；分别记录 x、y 的论域，不能把只限制 x 当作同时限制两者。

Module 1 · medium · compatible assignments and valid conclusions · 06

Combine a conditional indicator with a reverse rule

Let p mean “A request is submitted,” q mean “The request is accepted,” and r mean “The rule indicator is on.” The only premises are

\(r\leftrightarrow(p\to q),\qquad q\to p.\)

  1. Check all eight assignments in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Use columns p, q, r, A, B, where A and B are the two premises in order. List every assignment satisfying both premises.
  2. Test the conclusions \(p\lor r\), \(r\to q\), and \(\neg r\to p\). State which follow, and give every compatible counterexample for a conclusion that fails.
  3. First add the observation \(\neg r\). Then, separately, add r to the original premises. In each case list all remaining assignments and all forced input values. In the r case, describe the relationship between p and q and decide whether acceptance is guaranteed.

A conclusion follows when no assignment makes both premises true and the conclusion false. The indicator reports the truth of the entire conditional, including when no request is submitted.

中文提示（不含解答）

指示灯报告整个条件句的真值；另外还必须满足 q 推出 p 的独立规则。

Module 1 · medium · finite predicates and excluded witnesses · 07

Require a passing witness other than the object itself

The domain is exactly \(D=\{a,b,c\}\). P(x) means “specimen x passes.” Initially P(a) = T, P(b) = F, and P(c) = F. Both x and y range over D. Consider:

  • A: \(\forall x\in D\,\exists y\in D\,[(y\ne x)\land P(y)]\)
  • B: \(\exists y\in D\,P(y)\)
  • C: \(\exists y\in D\,\forall x\in D\,[(y\ne x)\land P(y)]\)
  1. Translate and evaluate A, B, C. For A, list every allowed y witness for each x, including an empty list when none exists. For C, test every fixed candidate y and give an x showing why it fails, if it fails.
  2. Negate A, moving the negation through both quantifiers and directly onto P; write the negation of disequality as equality. List every outer witness x for the true negation and explain what it requires for each possible y.
  3. Change only P(b) from F to T and reevaluate A, B, C and the negation of A. List the new witnesses for A. For arbitrary replacements of P on the same domain, does one passing specimen guarantee A? Do two distinct passing specimens guarantee A? Could C ever be true? Explain without assuming that y may equal x.

In A, the witness y may depend on x, but the displayed disequality must always hold. In C, one y must work for every x.

中文提示（不含解答）

不能选择标本自身当作见证；有一个合格标本时，还要检查它自己能否找到另一个合格标本。

Module 1 · medium · arithmetic predicates and changing witness domains · 08

Separate an unavailable square root from an impossible one

Initially, \(X=\{-1,0,1,4\}\) and \(Y=\{-2,0,2\}\). Define R(x,y) to mean \(y^2=x\), using ordinary integer arithmetic. Consider:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  • C: \(\forall y\in Y\,\exists x\in X\,R(x,y)\)
  1. Construct the complete initial R table with increasing row and column labels. Translate and evaluate A, B, C. List all y witnesses for each x in A and all x witnesses for each y in C; test every fixed y for B.
  2. Make two cumulative domain changes. Stage I replaces Y by \(Y'=\{-2,-1,0,1,2\}\), keeping X unchanged. Stage II keeps Y' and also removes -1 from X, giving \(X'=\{0,1,4\}\). Rewrite and reevaluate A, B, C at both stages. Give all witnesses for A and C and explain why every fixed candidate for B succeeds or fails.
  3. Negate A with the negation directly on R, and replace the negated relation by an arithmetic disequality. Evaluate this negation in all three settings and list every outer x witness when it is true. Explain why adding -1 and 1 to the y domain can fix one original failed x but cannot fix the other.

Only listed domain elements may be chosen. A negative integer may be a square-root witness for a positive x; the square itself is computed normally.

中文提示（不含解答）

先区分“平方根存在但没列进论域”和“整数平方不可能得到该数”；第二阶段保留第一阶段的扩充。

Module 1 · synthesis · truth tables and identifying an unknown formula · 09

Choose tests that distinguish four candidate rules

A device implements exactly one of the four candidate formulas below. The choice is fixed across all trials, its outputs are correct, and there are no other candidates:

\(F_1=p\lor q,\qquad F_2=p\lor(q\land r),\)

\(F_3=(p\lor q)\land r,\qquad F_4=(p\land r)\lor q.\)

In a trial you choose all three input truth values and observe the one output. You may use any of the eight input assignments.

  1. Make a table with columns p, q, r, F1, F2, F3, F4. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Identify every trial on which all four candidates return the same value.
  2. Before seeing any outputs, choose a fixed collection of distinct trials that guarantees identification of the formula. Find the minimum number of trials and every collection of that size. For each minimum collection, give the output list for each candidate in the table's row order. Justify why fewer trials cannot work and why your list is complete.
  3. A different plan starts with the trial TTF. If its output is F, identify every remaining candidate. If its output is T, identify every remaining candidate and decide whether one additional trial can guarantee identification, even if that trial is chosen after seeing T. Explain any unavoidable ambiguity using the candidate output columns.

A collection guarantees identification only when different candidates give different output lists. Trial order does not make two collections different. All uses of “or” are inclusive.

中文提示（不含解答）

把每个候选公式在所选测试上的输出排成一列；只有候选输出列互不相同，才保证辨认成功。

Module 1 · synthesis · three nested quantifiers and comparison witnesses · 10

Distinguish each specimen with one test or several comparisons

The specimen domain is \(D=\{A,B,C\}\), and the test domain is \(T=\{1,2,3\}\). R(a,t) means “specimen a passes test t.” Every record is known:

Specimen123
ATFF
BFTF
CFFT

Both a and b range over D. Consider:

  • P: \(\forall a\in D\,\forall b\in D\,[(a\ne b)\to\exists t\in T\,\neg(R(a,t)\leftrightarrow R(b,t))]\)
  • U: \(\forall a\in D\,\exists t\in T\,\forall b\in D\,[(b\ne a)\to\neg(R(a,t)\leftrightarrow R(b,t))]\)
  • V: \(\exists t\in T\,\forall a\in D\,\forall b\in D\,[(a\ne b)\to\neg(R(a,t)\leftrightarrow R(b,t))]\)
  1. Translate and evaluate P, U, V. For P, list every distinguishing test for each of the six ordered pairs with a different from b. For U, list every allowed test for each specimen. For V, check every fixed test and exhibit a pair of distinct specimens that prevents it from working, if it fails.
  2. Negate U with no implication or biconditional symbols and with negations only on R; simplify the equality conditions as needed. Correct exactly two records together: R(A,3) changes from F to T, and R(B,3) changes from F to T. Reevaluate P, U, V and the negation of U. For each specimen a, list its allowed tests for U after the correction; for every outer witness to the true negation, list all possible b witnesses for each test.
  3. For arbitrary complete records on these same domains, test U implies P, V implies U, P implies U, and U implies V. Explain any valid direction from the quantifiers and use the original or corrected records as counterexamples to failed directions. Could V ever be true with three specimens but only T/F outcomes on any one test? Explain by comparing the three outcomes on that test.

The changes in part 2 are made together. Agreement includes both passing and both failing. A conditional with a = b is true without imposing a comparison requirement.

中文提示（不含解答）

逐对比较时测试可以随一对标本改变；U 要给某个标本选一个测试，同时与其他所有标本区分。
