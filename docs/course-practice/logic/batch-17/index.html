Module 1 · easy · nested connectives and classification · 01

Compare a variable with two reversed conditionals

Let p and q be independent propositions. Define

\(A=p\leftrightarrow(p\to q),\qquad B=p\leftrightarrow(q\to p).\)

  1. Make a truth table with columns p, q, \(p\to q\), \(q\to p\), A, and B. Use TT, TF, FT, FF. Compute each conditional before the outer biconditional.
  2. Compare A and B with \(p\land q\) and \(p\lor q\). Identify an equivalent expression for each. If A is true, determine both inputs; separately, if B is false, determine both inputs.
  3. Classify A, B, \(A\to B\), and \(A\land\neg B\) as tautologies, contradictions, or contingencies. Are A and B equivalent? Give every input pair where they differ.

A biconditional is true when its two complete inputs agree. A tautology is always true, a contradiction is always false, and a contingency has both true and false assignments.

中文提示（不含解答）

先计算括号里的条件句，再把它与同一行的 p 比较；两处 p 的真值不能改变。

Module 1 · easy · English translation and unless · 02

Combine two opposite exceptions to the same warning

Let p mean “The warning sounds,” and q mean “The override is active.” Consider two claims about the same moment:

  • A: The warning sounds unless the override is active.
  • B: The warning sounds unless the override is inactive.
  1. Translate A and B into symbols. For this exercise, “U unless V” means “If V is false, then U.” Make a truth table with columns p, q, A, B, \(A\land B\), and \(A\lor B\), using TT, TF, FT, FF.
  2. Suppose the warning is silent. If A holds, what value of q is required? Separately, if B holds, what value of q is required? Can both claims hold during silence?
  3. Is requiring both A and B equivalent to requiring p? Is it possible for both A and B to be false at the same moment? Explain using all four rows and describe what requiring at least one of A and B adds.

No additional relationship between the override and warning is assumed. “At least one” permits both claims to hold.

中文提示（不含解答）

两句的例外正好相反；先分别翻译，不要把 unless 当成双条件。

Module 1 · medium · truth tables and equivalence · 03

Compare agreement between alternative and joint conditions

For independent propositions p, q, and r, define

\(A=(p\lor q)\leftrightarrow(q\land r),\qquad B=(p\leftrightarrow q)\land r.\)

  1. Build a truth table with columns p, q, r, \(p\lor q\), \(q\land r\), A, and B. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment where A and B differ.
  2. Classify \(A\to B\), \(B\to A\), and \(A\leftrightarrow B\). Give every counterexample to either directional implication that is not a tautology.
  3. First set q to T and simplify A and B separately. Then set q to F and repeat. In each case, describe exactly what requiring A says about p and r, and do the same for B. Does adding r to A always make A and B agree? Give a counterexample if it does not.

Use the classifications tautology, contradiction, and contingency. All uses of “or” are inclusive.

中文提示（不含解答）

先分别算“或”和“且”，再比较两个整体；第三部分固定的是 q。

Module 1 · medium · compound negation and repair · 04

Deny agreement between an arrow and a conjunction

For independent propositions p, q, and r, define

\(S=(p\to q)\leftrightarrow(p\land r),\qquad N=\neg S.\)

A proposed expression for N is \(K=\neg p\lor(\neg q\land\neg r)\).

  1. Rewrite N using only \(\neg,\land,\lor\), with every negation directly on a variable. Show both ways the two inputs of the biconditional can disagree.
  2. Make a truth table with columns p, q, r, S, N, and K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment where N and K differ, and give every counterexample to \(N\to K\) and to \(K\to N\).
  3. Simplify N when p is F and when p is T. Use these two cases to replace only the parenthesized term in K with an expression in q and r, using \(\neg,\land,\lor\), so the repaired expression is equivalent to N. Explain what the replacement says about q and r.
中文提示（不含解答）

双条件为假时，一个完整输入真、另一个假；不要把“两个输入不同”误写成“两者都假”。

Module 1 · medium · converse inverse and finite predicates · 05

Reverse an odd-number rule and remove its violations

The integer domain is exactly \(D=\{-3,-1,0,1,2,4\}\). P(n) means “n is odd,” and Q(n) means \(n^2\ne1\). The original claim is

\(O=\forall n\in D\,[P(n)\to Q(n)].\)

  1. Translate O into English. Write its converse, inverse, and contrapositive over D. Express each negated predicate in ordinary arithmetic language and identify the pairs equivalent by logical form.
  2. Make a table for P(n), Q(n), and all four conditional instances. Evaluate all four universal claims and list every violating n for each false claim. Negate O using an existential quantifier and no implication, and list every witness.
  3. You may remove elements from D but may not alter either predicate. Can removing exactly one element make O true? Find the minimum number of removals and every collection of that size that works. On the resulting domain, reevaluate the four claims, listing every remaining violation. Does the repaired original have a true antecedent anywhere?

An odd integer is an integer not divisible by 2; negative odd integers are allowed, and 0 is even. All arithmetic uses ordinary integers. Every domain change applies to all four claims.

中文提示（不含解答）

先找出所有“奇数但平方等于 1”的违例；删一个元素只会去掉该元素的那一行。

Module 1 · medium · compatible assignments and consequences · 06

Trigger a backup with agreement but forbid a joint state

Let p mean “The first indicator is on,” q mean “The second indicator is on,” and r mean “The backup is on.” The only premises are

\((p\leftrightarrow q)\to r,\qquad r\to\neg p.\)

  1. Check all eight assignments in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Use columns p, q, r, A, and B, where A and B are the two premises in order. List every assignment satisfying both premises.
  2. Test the conclusions \(p\to\neg q\), \(p\lor q\), and \(q\to r\). State which follow and give every compatible counterexample for each failed conclusion.
  3. First add r to the original premises. Then, separately, add \(\neg r\). List every remaining assignment in each case, state all forced input values, and describe any relationship still required between p and q. Does an off backup force either particular indicator to be on?

A conclusion follows exactly when no assignment makes both premises true and the conclusion false. No other relationships are assumed.

中文提示（不含解答）

第一个前件是两个指示灯“真值相同”，包括两个都关闭；结论只在同时满足两条前提的行中检查。

Module 1 · medium · uniqueness and quantifier scope · 07

Separate one passing object from at most one

The domain is exactly \(D=\{a,b,c\}\). P(x) means “object x passes.” Initially P(a) = T, P(b) = F, and P(c) = T. Both x and y range over D. Consider:

  • U: \(\exists x\in D\,\forall y\in D\,[P(y)\leftrightarrow(y=x)]\)
  • V: \(\forall x\in D\,\forall y\in D\,[(P(x)\land P(y))\to(x=y)]\)
  • H: \(\exists x\in D\,P(x)\)
  1. Translate and evaluate U, V, and H. For U, check every candidate x and list every y at which its biconditional fails. For V, list every violating ordered pair (x,y). List every witness for H.
  2. Negate V with existential quantifiers, no implication, and the negation of equality written as disequality. List every witness pair. Change only P(c) from T to F and reevaluate U, V, H, and the negation of V, giving the relevant witnesses or failures.
  3. Now consider arbitrary replacements of P on the same domain. Is U always equivalent to \(V\land H\)? Explain separately when zero objects pass, exactly one passes, and at least two pass. In particular, does V alone assert that an object passes?

The variables x and y may denote the same object. All three original predicate values are known.

中文提示（不含解答）

U 的双条件要求选中的 x 通过、其他对象都不通过；V 的条件句也要检查 x 与 y 不同的情况。

Module 1 · medium · arithmetic relations and nested quantifiers · 08

Restrict square-based upper witnesses

Initially, the domains are exactly \(X=\{-1,0,2,5\}\) and \(Y=\{-2,0,3\}\). Define R(x,y) to mean \(x<y^2\), using ordinary integer arithmetic. Consider:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  • C: \(\forall y\in Y\,\exists x\in X\,R(x,y)\)
  1. Construct the complete R table with increasing row and column labels. Translate and evaluate A, B, and C. List every y witness for each x in A, every fixed y witness for B, and every x witness for each y in C.
  2. Replace only Y by \(Y^{\prime}=\{-2,0\}\), keeping X and R unchanged. Rewrite and reevaluate all three claims. Give all available witnesses or all failing outer values and explain why each candidate for B works or fails.
  3. Negate A and B, moving each negation directly onto R, and then replace the negated relation by an inequality. Evaluate both negations in both settings. For every true negation, list all required witness choices in quantifier order. Does a negative y automatically make \(x<y^2\) false? Explain from the data.

The squared value need not belong to either domain. Only the quantified witnesses must come from their displayed domains.

中文提示（不含解答）

先对 y 求平方，再比较大小；删除的是 y 的候选值，不能把同一个数字从 X 自动删除。

Module 1 · synthesis · truth tables and uncertain observations · 09

Locate a copied output error before inspecting inputs

Three correctly functioning tests use the same fixed but unknown inputs p, q, and r:

\(A=p\land q,\qquad B=q\lor r,\qquad C=p\leftrightarrow r.\)

Their outputs were copied as A = T, B = T, C = F. Exactly one of these three copied output values is wrong; the other two are correct. The error is in the copied report, not in the tests or the input values.

  1. Express the exactly-one-copying-error condition using A, B, C, \(\neg,\land,\lor\); call it K. Make a truth table with columns p, q, r, A, B, C, and K, using TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every compatible actual input state, its actual output triple, and which copied output is wrong. Which input values, if any, are forced before an input is inspected? Can the copied B value be the error? Explain.
  3. You may inspect the actual value of any of p, q, and r, with a perfectly reliable result. For each possible first choice of input, list the compatible states under each possible result, including impossible results. Can any one fixed input inspection guarantee identification of the actual state? Find every smallest fixed collection of input inspections that does guarantee identification, and justify completeness.

A fixed collection is chosen before seeing inspection results. Inspections reveal input values only, and do not alter them. “Or” is inclusive.

中文提示（不含解答）

先计算真实输出，再与记录的 T、T、F 逐项比较；恰好错一项不等于恰好一个测试输出为假。

Module 1 · synthesis · nested witnesses and complement profiles · 10

Find whole opposite profiles or separate opposite entries

The profile domain is \(D=\{A,B,C,D\}\), and the feature domain is \(T=\{1,2,3\}\). R(a,t) means “profile a has feature t.” All twelve records are known:

Profile123
ATTT
BTFF
CFFT
DTFT

Both a and b range over D. Consider:

  • U: \(\forall a\in D\,\exists b\in D\,\forall t\in T\,\neg(R(a,t)\leftrightarrow R(b,t))\)
  • V: \(\forall a\in D\,\forall t\in T\,\exists b\in D\,\neg(R(a,t)\leftrightarrow R(b,t))\)
  • W: \(\exists a\in D\,\exists b\in D\,\forall t\in T\,\neg(R(a,t)\leftrightarrow R(b,t))\)
  1. Translate and evaluate U, V, and W. List every whole-profile b witness for each a in U, every b witness for each (a,t) in V, and every ordered pair (a,b) witnessing W. Explain whether a profile can be its own opposite.
  2. Negate U, moving all negations directly onto R and eliminating biconditionals. For every outer a witnessing this negation, give one permitted feature t for each b. Then change only R(C,3) from T to F. Reevaluate U, V, W, and the negation of U. Give the new whole-profile witness lists and, for each outer witness to the true negation, one permitted t for each b.
  3. For arbitrary complete records on these same domains, test U implies W, W implies V, V implies W, and W implies U. Explain each valid direction using the quantifiers and the two possible T/F outcomes. Use the original or corrected complete records as counterexamples to failed directions.

The variables a and b are not required in advance to be distinct; whether they can be equal is determined by the displayed formula. In U the chosen b may depend on a, while in V it may depend on both a and t.

中文提示（不含解答）

“整份资料相反”要求同一个 b 在三项上都与 a 不同；“逐项相反”允许每一项选不同的 b。
