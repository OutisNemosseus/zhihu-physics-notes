Module 1 · easy · biconditionals and truth values · 01

Negate the inputs of an agreement test

Let p and q be independent propositions. Define

\(A=p\leftrightarrow q,\qquad B=\neg p\leftrightarrow\neg q,\qquad C=p\leftrightarrow\neg q.\)

  1. Make a truth table with columns p, q, A, B, and C. Use TT, TF, FT, FF.
  2. Which of B and C is equivalent to A? Which is equivalent to \(\neg A\)? Explain by comparing the inputs of each biconditional.
  3. Classify A, \(A\leftrightarrow B\), and \(A\land C\) as tautologies, contradictions, or contingencies.

A biconditional is true exactly when its two inputs have the same truth value. A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

分别算出每个双条件句的两个输入；同时取反与只取反其中一个输入，需要分开检查。

Module 1 · easy · English translation and implication direction · 02

Keep the full condition after only if

Let p mean “The charger is connected,” q mean “The battery is charging,” and r mean “The battery is full.” Consider these claims about one moment:

  • A: The battery is charging or full only if the charger is connected.
  • B: The charger is connected if the battery is charging or full.
  • C: If the charger is connected, the battery is charging or full.
  1. Translate all three claims into symbols. Treat “charging or full” as one compound condition, and interpret “or” inclusively.
  2. Which claims are equivalent? Give one assignment to p, q, and r that distinguishes any remaining claim from them.
  3. Suppose the charger is connected, but the battery is neither charging nor full. Evaluate A, B, and C for this observation.

Assume no physical relationships beyond the stated claims.

中文提示（不含解答）

“A only if B”要求 A 成立时 B 也成立；先把完整的“正在充电或已充满”圈作一个条件，再判断箭头方向。

Module 1 · medium · truth-table equivalence and conditional scope · 03

Move a missing alternative into the trigger

For independent propositions p, q, and r, define

\(A=p\to(q\lor r),\qquad B=(p\land\neg q)\to r,\qquad C=(p\land q)\to r.\)

  1. Build a truth table with columns p, q, r, \(q\lor r\), A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Are A and B equivalent? Are A and C equivalent? List every differing assignment for a pair that is not equivalent.
  3. Classify \(A\leftrightarrow B\), \(A\to C\), and \(C\to A\). Give every counterexample to a direction that is not a tautology.
  4. When p is true and q is false, simplify A, B, and C. Explain why the negation on q in B matters.

“Or” is inclusive. Use the classifications tautology, contradiction, and contingency.

中文提示（不含解答）

当 q 已经为真时，后件的“或”可能已被满足；当 q 为假时，检查 r 还需要承担什么条件。

Module 1 · medium · De Morgan laws and negated implications · 04

Describe every way a two-link chain can fail

For independent propositions p, q, and r, let

\(S=(p\to q)\land(q\to r),\qquad N=\neg S.\)

A proposed replacement for N is \(K=p\land\neg r\).

  1. Remove the implications from N and apply De Morgan’s laws until every negation is directly on a variable. Show one equivalence at each step.
  2. Make a truth table for S, N, and K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true.
  3. Is K equivalent to N? Test both \(K\to N\) and \(N\to K\), giving every counterexample to a direction that fails.
  4. Can both component implications in S be false on the same assignment? Explain using the required value of q.
中文提示（不含解答）

整个链条失效，只需要其中一条条件句失效；分别写出每条条件句为假的情况，再用正确的连接词组合。

Module 1 · medium · converse inverse contrapositive and finite records · 05

Reverse a rule with a negative starting condition

The device domain is exactly \(D=\{a,b,c,d\}\). F(x) means “device x is flagged,” R(x) means “device x was rechecked,” and Q(x) means “device x is quarantined.” The original claim is

\(O=\forall x\in D\,[\neg F(x)\to(R(x)\lor Q(x))].\)

These are the complete records:

DeviceFRQ
aFTF
bFFF
cTFT
dTFF
  1. Translate O into English. Write its converse, inverse, and contrapositive over D. Move negations of compound expressions directly onto predicates.
  2. Evaluate all four universal claims and list every violating device for each false claim.
  3. Identify the pairs equivalent by logical form, regardless of the records.
  4. Negate O, using an existential quantifier and negations only on predicates. Translate the result and list all witnesses.

No relationships between these records are assumed beyond the table. “Or” is inclusive.

中文提示（不含解答）

原条件的前件已经是否定命题；写逆命题或逆否命题时，先把整个前件和整个后件分别标出，再处理双重否定。

Module 1 · medium · compatible assignments and valid consequences · 06

Recover an agreement from two one-way rules

Let p mean “The manual request is active,” q mean “The automatic request is active,” and r mean “The service is running.” The only premises are

\((p\lor q)\to r,\qquad r\to q.\)

  1. Check all eight assignments to p, q, and r in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each conclusion \(q\leftrightarrow r\), p, and \(q\to p\), decide whether it follows. List every compatible counterexample for a conclusion that does not follow.
  3. Add the observation \(\neg q\). Determine p and r, and check consistency.
  4. Return to the original two premises and instead add p. Determine q and r, and check consistency.

A conclusion follows exactly when no assignment makes both premises true and the conclusion false. The observations in parts 3 and 4 are separate cases. “Or” is inclusive.

中文提示（不含解答）

先保留同时满足两条规则的行，再检查结论；“至少一个请求”与“指定的手动请求”表达的条件不同。

Module 1 · medium · finite predicates and quantifier scope · 07

Compare an existential condition with quantified summaries

The domain is exactly \(D=\{0,1,2\}\). Define P(x) to mean “x is even,” and Q(x) to mean \(x>2\). Zero is even. Consider:

  • A: \(\exists x\in D\,[P(x)\to Q(x)]\)
  • B: \((\forall x\in D\,P(x))\to(\exists x\in D\,Q(x))\)
  • C: \((\exists x\in D\,P(x))\to(\exists x\in D\,Q(x))\)
  1. Make a table for P(x), Q(x), and \(P(x)\to Q(x)\). Translate and evaluate A, B, and C, and list every witness for A.
  2. Expand A and B without quantifiers. Remove implication symbols and apply De Morgan’s laws as needed. Must A and B agree for any replacement predicates on this same domain?
  3. Do the stated P and Q give a counterexample to A implying C, or to C implying A? For the other direction, determine whether it holds for every replacement of P and Q on D, and explain.

A replacement predicate may assign any truth values to the three domain elements.

中文提示（不含解答）

存在量词可以由条件句前件为假的元素作见证；展开有限论域时，“所有”使用合取，“存在”使用析取。

Module 1 · medium · nested quantifiers and changing universal domains · 08

Find a fixed different number after restricting one domain

Initially x and y both range over exactly \(D=\{0,1,2\}\). Define R(x,y) to mean \(x\ne y\). Compare:

  • A: \(\forall x\in D\,\exists y\in D\,R(x,y)\)
  • B: \(\exists y\in D\,\forall x\in D\,R(x,y)\)
  1. Translate A and B and construct the complete R table, with rows x and columns y in the order 0, 1, 2. Evaluate both claims. List every witness y for each x in A; for B, check every candidate fixed y.
  2. Now restrict only x to \(H=\{0,1\}\), while y still ranges over D. Rewrite and reevaluate A and B. List all permitted witnesses, including every fixed witness for B.
  3. Negate B in both settings, placing the negation directly on R, and then replace the negated predicate by an equality. Evaluate both negations and give the witness choices for any true negation.

The two settings use the same relation. A value excluded from x’s domain may still belong to y’s domain.

中文提示（不含解答）

固定的 y 需要不同于每一个允许的 x；改变 x 的论域后，不要同时改变 y 的选择范围。

Module 1 · synthesis · biconditionals report counts and consistency · 09

Count consistent reports of pairwise agreement

Let p, q, and r record whether three independent lamps are on. Three reports say:

  • R1: The first and second lamps have the same on/off status.
  • R2: The second and third lamps have the same on/off status.
  • R3: The first and third lamps have the same on/off status.

Each report is evaluated from the same lamp states; no report is assumed true in advance.

  1. Translate the three reports. Build a table with columns p, q, r, R1, R2, R3, and the number of true reports. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Can exactly two reports be true? Can all three be false? Justify both answers from the table and explain why any two true agreement reports force the third to be true.
  3. Express “At least two reports are true” using the report labels and \(\land,\lor\). List every compatible lamp assignment. Does this condition force any particular lamp to be on?
  4. Instead suppose exactly one report is true and p is true. List every compatible assignment and identify its true report. Are q and r individually determined?
中文提示（不含解答）

先计算同一组三个灯的状态所产生的报告，再统计真报告数量；不要把三份报告当作能独立取值的命题。

Module 1 · synthesis · three nested quantifiers and shared witnesses · 10

Keep a shared version fixed for each document

The library domain is \(L=\{A,B\}\), the document domain is \(D=\{1,2\}\), and the version domain is \(V=\{o,n\}\), where o means old and n means new. R(l,d,v) means “library l holds version v of document d.” A library may hold both versions. These tables give all eight records:

Old version oDocument 1Document 2
Library ATF
Library BTF
New version nDocument 1Document 2
Library AFT
Library BTT

Consider:

  • P: \(\forall d\in D\,\exists v\in V\,\forall l\in L\,R(l,d,v)\)
  • Q: \(\exists v\in V\,\forall d\in D\,\forall l\in L\,R(l,d,v)\)
  • H: \(\forall l\in L\,\forall d\in D\,\exists v\in V\,R(l,d,v)\)
  1. Translate and evaluate P, Q, and H. For P, give every shared witness version for each document; for H, give every witness version for each library-document pair. Explain why each candidate fixed version succeeds or fails for Q.
  2. Negate P, moving the negation directly onto R. Translate and evaluate the result.
  3. A correction changes only R(B,1,o) from T to F. Reevaluate P, Q, H, and the negation of P. For a true negation, give a document witness and a failing library for each version.
  4. For arbitrary complete tables on these domains, decide whether Q implies P and whether P implies H. Explain any valid directions using the quantifiers. Use the original or corrected records to test the reverse directions.
中文提示（不含解答）

P 允许不同文件选不同版本，但同一文件的版本要供两座图书馆共同持有；H 则允许每个“图书馆与文件”组合分别选择版本。
