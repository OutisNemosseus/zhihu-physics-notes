Module 1 · easy · connectives and truth values · 01

Compare a test against one of its inputs

Let p and q be independent propositions. Define

\(A=(p\lor q)\leftrightarrow q,\qquad B=(p\land q)\leftrightarrow q.\)

  1. Make a truth table with columns p, q, A, B, \(A\lor B\), and \(A\land B\). Use TT, TF, FT, FF.
  2. Are A and B equivalent? List every pair where they differ. When q is true, simplify A and B separately; repeat when q is false.
  3. Compare A with \(p\to q\) and B with \(q\to p\) on all four rows. Classify \(A\lor B\), \(A\land B\), and \(A\land\neg(p\to q)\) as tautologies, contradictions, or contingencies.

A biconditional compares the truth values of its two complete inputs. A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

先算括号内的值，再与 q 比较；不要把双条件符号当成“且”。

Module 1 · easy · English translation and compound conditions · 02

Require exactly one input only while a screen is on

Let p mean “The screen is on,” q mean “Input 1 is selected,” and r mean “Input 2 is selected.” Consider:

  • A: If the screen is on, exactly one of the two inputs is selected.
  • B: If the screen is on and input 1 is selected, input 2 is not selected.
  • C: If the screen is on, at least one of the two inputs is selected.
  1. Translate A, B, and C into symbols. Express “exactly one” using \(\neg,\land,\lor\), rather than introducing a new connective.
  2. Is A equivalent to \(B\land C\)? Does B alone imply A? Does C alone imply A? Justify by checking assignments and give a counterexample for each failed direction.
  3. Suppose the screen is off and both inputs are selected. Evaluate A, B, and C. Does A require exactly one selected input even when the screen is off? Explain from its conditional form.

Interpret “or” inclusively unless “exactly one” is explicitly stated. Assume no additional rules about the equipment.

中文提示（不含解答）

把“至少一个”和“不能同时两个”分开处理，并保留屏幕开启这个条件。

Module 1 · medium · truth tables and conditional equivalence · 03

Compare two reports with the same trigger

For independent propositions p, q, and r, define

\(A=(p\to q)\leftrightarrow(p\to r),\qquad B=p\to(q\leftrightarrow r),\qquad C=q\leftrightarrow r.\)

  1. Build a truth table with columns p, q, r, A, B, and C. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. Are A and B equivalent? Are A and C equivalent? List every differing assignment for a pair that is not equivalent.
  3. Classify \(A\leftrightarrow B\), \(A\to C\), and \(C\to A\) as tautologies, contradictions, or contingencies. Give every counterexample to a direction that is not a tautology. Explain separately what A requires when p is true and when p is false.
中文提示（不含解答）

比较两个条件句的真值，不等于直接比较它们的后件；先看共同前件 p。

Module 1 · medium · De Morgan laws and biconditional negation · 04

Deny an agreement or an override

Let p, q, and r be independent propositions. Define

\(S=(p\leftrightarrow q)\lor r,\qquad N=\neg S.\)

A proposed expression for N is \(K=(p\lor q)\land(\neg p\lor\neg q)\land\neg r\).

  1. Rewrite N using only \(\neg,\land,\lor\), with every negation directly on a variable. Expand the biconditional and show the De Morgan steps.
  2. Make a truth table with columns p, q, r, S, N, and K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true and decide whether K is equivalent to N.
  3. When r is true, simplify S, N, and K. Repeat when r is false. In the second case, explain what N requires about whether p and q agree.

All uses of “or” are inclusive.

中文提示（不含解答）

先否定最外层的“或”；双条件为假时，要检查两个输入不一致的两种情况。

Module 1 · medium · converse inverse contrapositive and finite predicates · 05

Reverse a divisibility rule that includes zero

The domain is exactly \(D=\{-6,-2,0,3,5\}\). Define P(n) to mean “n is divisible by 3,” and Q(n) to mean \(n\ne0\). The original claim is

\(O=\forall n\in D\,[P(n)\to Q(n)].\)

  1. Translate O into English. Write its converse, inverse, and contrapositive over D. Express each negated predicate in ordinary arithmetic language.
  2. Make a table for P(n), Q(n), and the four conditional instances. Evaluate all four universal claims and list every violating n for each false claim. Identify the pairs equivalent by logical form.
  3. Negate O using an existential quantifier and no implication symbol. Translate and evaluate the negation, listing every witness. Explain why a number for which P is false cannot violate O, even when Q is also false.

Divisible by 3 means equal to 3k for some integer k; in particular, 0 is divisible by 3. The quantified variable n still ranges only over D.

中文提示（不含解答）

0 也满足被 3 整除的条件；判断条件句的反例时，要同时检查前件与后件。

Module 1 · medium · compatible assignments and valid conclusions · 06

Allow disagreement only under a separate flag

Let p mean “The first indicator is on,” q mean “The second indicator is on,” and r mean “The exception flag is on.” The only premises are

\((p\leftrightarrow q)\lor r,\qquad\neg(p\land r).\)

  1. Check all eight assignments to p, q, and r in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment satisfying both premises.
  2. For each conclusion \(p\to q\), \(q\to p\), and \(r\to\neg p\), decide whether it follows. List every compatible counterexample to a conclusion that does not follow.
  3. First add the observation \(\neg q\). Then, in a separate case, add q to the original premises. In each case list every compatible assignment and determine which values of p and r are forced. If both can vary, state the relationship they must satisfy.

A conclusion follows exactly when no assignment makes both premises true and the conclusion false. “Or” is inclusive; an active exception flag does not itself assert that the indicators disagree.

中文提示（不含解答）

先保留满足两条前提的行；“允许不一致”不代表“一定不一致”。

Module 1 · medium · fixed propositions and finite quantifier scope · 07

Keep a fixed switch outside a sample quantifier

The sample domain is exactly \(D=\{a,b,c\}\). P(x) means “sample x passes,” with P(a) = T, P(b) = F, and P(c) = T. The proposition p means “The bypass switch is on.” Its value is the same for every sample and is independent of the pass records. Compare:

  • A: \(\forall x\in D\,[p\lor P(x)]\)
  • B: \(p\lor(\forall x\in D\,P(x))\)
  • C: \(\exists x\in D\,[p\land P(x)]\)
  • E: \(p\land(\exists x\in D\,P(x))\)
  1. Translate all four statements into English. Evaluate A, B, C, and E first when p is true and then when p is false. List every sample witness for C in each case.
  2. Expand A, B, C, and E using only p, P(a), P(b), P(c), \(\land\), and \(\lor\). Must A and B agree for every replacement of P on D? Must C and E agree? Explain from the expansions.
  3. Negate A with the negation moved through the quantifier and directly onto p or P. Evaluate this negation for both values of p and list its witnesses when true. In a separate setting, let every sample fail: reevaluate all four original statements for both values of p.

A replacement P can assign any pass/fail values on the same nonempty domain; it does not change the single value of p.

中文提示（不含解答）

p 没有变量 x，对所有样本都取同一个真值；先把有限量词展开成“且”或“或”。

Module 1 · medium · arithmetic relations and nested quantifiers · 08

Stay at a number or move one step forward

Initially, the domains are exactly \(X=\{0,1,2\}\) and \(Y=\{0,1,2\}\). Define R(x,y) to mean \((x\le y)\land(y\le x+1)\), using ordinary integer order. Consider:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  • C: \(\forall y\in Y\,\exists x\in X\,R(x,y)\)
  1. Construct the complete R table, with rows x and columns y in increasing order. Translate and evaluate A, B, and C. For A and C, list every witness for each outer universal value; for B, check each candidate fixed y.
  2. Negate A and B with negations directly on R, then express the negated relation using inequalities. Evaluate both negations and give all witness choices needed for each true negation.
  3. Now replace only Y by \(Y'=\{0,1\}\), keeping X and the relation unchanged. Rewrite and reevaluate A, B, C, and the two negations. Give witnesses or counterexamples sufficient to justify every result.

The two inequalities defining R must both hold. A value removed from Y may still belong to X.

中文提示（不含解答）

分别检查不等式的两个方向；R(x,y) 与 R(y,x) 不必有相同真值。

Module 1 · synthesis · report truth values and consistency · 09

Require a mixture of accurate and inaccurate reports

Let p mean “Switch 1 is on,” q mean “Switch 2 is on,” and r mean “The motor is on.” Three reports describe one state:

  • R1: Both switches are on.
  • R2: If switch 2 is on, the motor is on.
  • R3: Switch 1 or the motor is on.

At least one report is true and at least one report is false. The reports are all evaluated from the same p, q, and r.

  1. Translate the reports and express the required mixture using R1, R2, R3, \(\neg,\land,\lor\); call it K. Make a table with short column labels p, q, r, R1, R2, R3, K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF.
  2. List every assignment satisfying K and its three report truth values. Identify every excluded assignment and say whether all three reports are true or all three are false there.
  3. First suppose switch 2 is off. Then, separately, suppose it is on. For each case list all permitted assignments and determine what, if anything, is forced about p and r or the relationship between them.

“Or” is inclusive, and no additional physical rules are assumed. The mixture requirement does not specify how many of the reports are true beyond the stated limits.

中文提示（不含解答）

排除三份全真和三份全假的情况，但不要预先指定哪一份报告有误。

Module 1 · synthesis · three nested quantifiers and witness dependence · 10

Fix a printer or choose one separately for each document

The printer domain is \(P=\{A,B\}\), the document domain is \(D=\{1,2\}\), and the format domain is \(F=\{s,l\}\), for small and large formats. R(p,d,f) means “printer p can print document d in format f.” These are all eight records:

Small s12
ATT
BFT
Large l12
AFT
BTF

Consider:

  • U: \(\exists p\in P\,\forall d\in D\,\exists f\in F\,R(p,d,f)\)
  • V: \(\forall d\in D\,\exists p\in P\,\forall f\in F\,R(p,d,f)\)
  • W: \(\forall d\in D\,\forall f\in F\,\exists p\in P\,R(p,d,f)\)
  1. Translate and evaluate U, V, and W. For U, check each fixed printer and list its format choices for each document. For V, list every printer that works for each document; for W, list every printer witness for each document-format pair.
  2. Negate U and V with negations directly on R. A single corrected dataset changes exactly three records: R(B,1,s) changes from F to T, R(A,1,s) changes from T to F, and R(B,2,s) changes from T to F. Reevaluate U, V, W, and both negations. For every true negation in either dataset, give all required witnesses in quantifier order.
  3. For arbitrary complete tables on these domains, test four directions: U implies V, V implies U, V implies W, and W implies V. Explain any valid direction from the quantifiers. Use the original or corrected records as complete counterexamples for each failed direction.

The three corrections are made together; all other entries stay unchanged. The variable p in this question denotes a printer, not a propositional truth value.

中文提示（不含解答）

U 先固定一台打印机，格式可以随文档改变；V 为每份文档选一台能处理所有格式的打印机。
