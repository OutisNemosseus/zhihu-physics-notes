Module 1 · easy · conditionals and classification · 01

Ask a statement to imply its own denial

Let p be a proposition. Define

\(A=p\to\neg p,\qquad B=\neg p\to p.\)

  1. Make a two-row truth table with columns p, A, B, \(A\land B\), and \(A\lor B\). Use p = T followed by p = F.
  2. Which of p and \(\neg p\) is equivalent to A? Which is equivalent to B? If A is true, determine p; then separately determine p if B is true.
  3. Classify A, B, \(A\land B\), and \(A\lor B\) as tautologies, contradictions, or contingencies. Explain why the two conditionals cannot both be true on one assignment.

A conditional is false exactly when its antecedent is true and its consequent is false. A tautology is always true; a contradiction is always false; a contingency has both true and false assignments.

中文提示（不含解答）

同一个 p 的两次出现必须使用同一真值；先判断前件，再判断整个条件句。

Module 1 · easy · English translation and unless · 02

Read an exception requiring both checks

Let p mean “The package is held,” q mean “The identity check passes,” and r mean “The address check passes.” Consider claims about one package:

  • A: The package is held unless both checks pass.
  • B: If the package is not held, both checks pass.
  • C: If both checks pass, the package is not held.
  1. Translate A, B, and C into symbols. For this exercise, “U unless V” means “If V is false, then U”; it does not assert a reverse implication.
  2. Evaluate all three claims in two separate observations: first, both checks pass and the package is held; second, only the identity check passes and the package is not held. Identify every claim violated by each observation.
  3. Which two claims are logically equivalent? Explain using a contrapositive. Write a formula using only the labels A and C and one connective that expresses “The package is held if and only if at least one check fails.”

There are no additional rules connecting the check results and the hold decision. “At least one check fails” includes both failing.

中文提示（不含解答）

unless 后面的例外是“两项都通过”这个整体；否定它时，不要只否定其中一项。

Module 1 · medium · truth tables and grouping · 03

Change where an agreement test ends

Let p, q, and r be independent propositions. Define

\(A=p\leftrightarrow(q\to r),\qquad B=(p\leftrightarrow q)\to r.\)

  1. Build a truth table with columns p, q, r, \(q\to r\), \(p\leftrightarrow q\), A, and B. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment where A and B differ.
  2. Classify \(A\to B\), \(B\to A\), and \(A\leftrightarrow B\) as tautologies, contradictions, or contingencies. Give every counterexample to either directional implication that is not a tautology.
  3. Set r to F and simplify A and B separately. Then set r to T and repeat. In each case, describe precisely what requiring A to be true says about p and q, and do the same for B.

A biconditional is true when its two complete inputs agree. Parentheses determine which operation is performed first.

中文提示（不含解答）

A 的最外层是双条件，B 的最外层是条件句；先分清两个完整输入，再逐行计算。

Module 1 · medium · De Morgan laws and compound negation · 04

Find a missing way an agreement rule can fail

For independent propositions p, q, and r, define

\(S=(p\leftrightarrow q)\land(q\to r),\qquad N=\neg S.\)

A proposed expression for N is \(K=(p\land\neg q)\lor(q\land\neg r)\).

  1. Rewrite N using only \(\neg,\land,\lor\), with every negation directly on a variable. Show the steps for the outer conjunction, the biconditional, and the conditional.
  2. Make a truth table with columns p, q, r, S, N, and K. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. List every assignment making N true and every assignment where N and K differ.
  3. Test \(K\to N\) and \(N\to K\), giving every counterexample to a failed direction. Add one conjunction of literals to K with “or” to obtain an expression equivalent to N. Explain which direction of disagreement the added conjunction represents.

A literal is a variable or its negation. The added conjunction may be true on rows that already make K true, provided the resulting expression agrees with N on every row.

中文提示（不含解答）

一个双条件失败有两个方向；检查提议的式子是否把两个方向都包括了。

Module 1 · medium · converse inverse and finite domains · 05

Reverse an order rule with a sum condition

Initially, x and y both range independently over exactly \(D=\{-1,1,2\}\). The original claim is

\(O=\forall x\in D\,\forall y\in D\,[(x<y)\to(x+y<2)].\)

  1. Translate O into English. Write its converse, inverse, and contrapositive with the same quantifiers and domains. Replace negated inequalities with ordinary inequalities, and identify the pairs equivalent by logical form.
  2. Check all nine ordered pairs (x,y). Evaluate all four universal claims and list every violating pair for each false claim. Negate O using existential quantifiers and no implication, then list every witness pair.
  3. Restrict only y to \(Y=\{-1,1\}\), keeping x in D. Rewrite O with the correct domains and reevaluate all four claims. List every remaining violation. Does the restricted original claim have any instances with a true antecedent? List them and explain why its truth is not solely due to false antecedents.

Pairs may have equal coordinates. Addition and order use ordinary integer arithmetic. Removing 2 from y’s domain does not remove it from x’s domain.

中文提示（不含解答）

每一对数分别计算“小于”和“和小于 2”；第三部分只删掉 y = 2 那一列。

Module 1 · medium · compatible assignments and conclusions · 06

Allow either route without requiring the job

Let p mean “The job is requested,” q mean “The primary route is available,” and r mean “The alternate route is available.” The only premises are

\((p\to q)\lor r,\qquad\neg(q\land r).\)

  1. Check all eight assignments in the order TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Use columns p, q, r, A, B, where A and B are the two premises in order. List every assignment satisfying both premises.
  2. Test the conclusions \(p\to\neg(q\leftrightarrow r)\), \(q\to\neg r\), and \(r\to p\). State which follow, and give every compatible counterexample for a conclusion that fails.
  3. First add p to the original premises. Then, separately, add \(\neg p\). In each case list all remaining assignments and describe exactly which combinations of route availability are permitted. Does having an available route force the job to be requested?

A conclusion follows when no assignment makes both premises true and the conclusion false. All uses of “or” are inclusive. No other connection between requests and route availability is assumed.

中文提示（不含解答）

第二条规则始终禁止两条路线同时可用；第一条规则是否增加要求，要分别看 p 为真和为假。

Module 1 · medium · separated predicates and quantifier scope · 07

Check a special case where mixed quantifiers agree

The item domain is \(X=\{a,b\}\), and the test domain is \(Y=\{1,2,3\}\). P(x) means “item x is selected,” with P(a) = T and P(b) = F. Q(y) means “test y is calibrated,” with Q(1) = F, Q(2) = T, and Q(3) = F. Consider:

  • U: \(\exists x\in X\,\forall y\in Y\,[P(x)\to Q(y)]\)
  • V: \(\forall y\in Y\,\exists x\in X\,[P(x)\to Q(y)]\)
  • W: \(\forall x\in X\,\exists y\in Y\,[P(x)\to Q(y)]\)
  1. Construct the two-by-three table for \(P(x)\to Q(y)\). Translate and evaluate U, V, and W. List every fixed x witness for U, every x witness for each y in V, and every y witness for each x in W.
  2. Negate U with no implication and with negations directly on P or Q. Change only P(b) from F to T. Reevaluate U, V, W, and the negation of U. For each x, list the y witnesses required by the true negation, if it is true.
  3. Now permit any replacement of the P and Q values on these same nonempty domains. Must U and V always agree? Explain separately when some x makes P false and when every x makes P true. Does your reasoning show that mixed quantifiers can be swapped for every two-variable predicate, or does it use the particular form \(P(x)\to Q(y)\)? Explain.

P depends only on x, and Q depends only on y. There are no missing predicate values.

中文提示（不含解答）

先找是否有 P 为假的对象：同一个对象能让整行条件句成立。若没有，再检查所有 Q 值。

Module 1 · medium · arithmetic predicates and witness domains · 08

Use zero as a common multiple witness

The divisor domain is \(X=\{2,3,5\}\), and initially the multiple domain is \(Y=\{0,6,10,15\}\). Define R(x,y) to mean “y is divisible by x”: there is an integer k with \(y=xk\). Zero is divisible by each listed divisor. Consider:

  • A: \(\forall x\in X\,\exists y\in Y\,R(x,y)\)
  • B: \(\exists y\in Y\,\forall x\in X\,R(x,y)\)
  • C: \(\forall y\in Y\,\exists x\in X\,R(x,y)\)
  1. Construct the complete R table with increasing row and column labels. Translate and evaluate A, B, and C. List every y witness for each x in A, every fixed y witness for B, and every x witness for each y in C.
  2. Replace only Y by \(Y'=\{6,10,15\}\), keeping X unchanged. Rewrite and reevaluate A, B, and C, giving the permitted witnesses or the failures that explain each result.
  3. Negate B with the negation directly on R and translate it into ordinary divisibility language. Evaluate this negation in both settings. For every y in a setting where the negation is true, list every allowed x that witnesses its failure of divisibility. Explain why three different useful multiples need not provide one common witness.

The integer k in the definition of divisibility need not belong to X or Y. Only the witnesses for the displayed quantified claims must come from their displayed domains.

中文提示（不含解答）

“每个除数都有一个倍数”和“有一个数同时是所有除数的倍数”不同；0 被移除后要重新检查固定见证。

Module 1 · synthesis · truth tables and shared hidden values · 09

Recover hidden inputs from two controlled runs

A device has two hidden inputs p and q that remain fixed across all runs. You choose the control input r. Its correctly functioning main indicator computes

\(F=(p\leftrightarrow r)\land q.\)

A separate correctly functioning check computes \(H=p\to q\). Write F0 for the output when r = F and F1 for the output when r = T, with the same hidden p and q in both runs.

  1. Make a truth table with columns p, q, r, F, and H. Use TTT, TTF, TFT, TFF, FTT, FTF, FFT, FFF. Then give the ordered output pair (F0, F1) for each hidden pair (p,q) in TT, TF, FT, FF.
  2. For each possible observed output pair TT, TF, FT, FF, list every compatible hidden pair or explain why it is impossible. Which observations determine both hidden inputs, and which leave an input undetermined? Explain why the two runs must use the same hidden values.
  3. The observed pair is FF. First suppose H is then observed T; separately suppose H is observed F. Determine the hidden inputs in each case. Does observing (F0, F1, H) always identify both hidden inputs when all outputs are correct? Justify by listing the output triple for every hidden pair.

The subscripts 0 and 1 label the chosen false and true values of r; they are not additional propositions. No indicator output or hidden input changes incorrectly during the trials.

中文提示（不含解答）

先按同一组 p、q 配对两次运行的输出；不能把一次运行的 p、q 换成另一组再配对。

Module 1 · synthesis · nested quantifiers and fixed witnesses · 10

Cover another profile with one replacement or several

The profile domain is \(D=\{A,B,C,D\}\), and the feature domain is \(T=\{1,2\}\). R(a,t) means “profile a supports feature t.” Every record is known:

Profile12
ATT
BTF
CFT
DFT

Both a and b range over D. Consider:

  • U: \(\exists a\in D\,\forall b\in D\,\forall t\in T\,[R(b,t)\to R(a,t)]\)
  • V: \(\forall b\in D\,\exists a\in D\,\forall t\in T\,[(a\ne b)\land(R(b,t)\to R(a,t))]\)
  • W: \(\forall b\in D\,\forall t\in T\,\exists a\in D\,[(a\ne b)\land(R(b,t)\to R(a,t))]\)
  1. Translate and evaluate U, V, and W. List every fixed a witness for U, every a witness for each b in V, and every a witness for each (b,t) in W. Explain how a false value of R(b,t) affects the conditional without removing the separate requirement \(a\ne b\).
  2. Negate V, moving all negations directly onto R and expressing the negation of disequality as equality. For every outer b witness to the true negation, list the permitted t witnesses for each a. Then change only R(A,2) from T to F. Reevaluate U, V, W, and the negation of V, with witnesses or counterexamples explaining each result.
  3. For arbitrary complete records on these same domains, test V implies W, W implies V, U implies V, and V implies U. Explain any valid direction directly from the quantifiers. Use the original or corrected complete records as a counterexample for each failed direction.

In V one replacement profile must work for both features of a given b. In W the replacement may change with the feature. U does not require its chosen profile to differ from b.

中文提示（不含解答）

替代者必须与被替代者不同；V 要固定同一个替代者处理两项功能，W 可以逐项更换。
